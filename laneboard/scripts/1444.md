## Steps

1. From the sidebar open System > Messaging > Chatbot Console; choose the contact from Setup 6.
2. Send: `i have an idea, the price tag should show promo price in red`
3. Open the link in the reply (as USER A: Logout, then pick USER A in the "Sign in as" list).
4. Back in the console (as the admin), send: `promo price on price tags should be red so customers stop asking`
5. If step 4 showed a numbered list, send the number of an idea in it. Otherwise skip.
6. Send the step 4 message again; if a list appears, send `NEW`.
7. Send: `I have an idea`
8. Send: `ok i want to submit one`
9. Send: `want to submit idea`, then `we should show stock age on the product page` (straight after step 8; a short message while an ask is open counts as its answer, see Expected 7)
10. Send: `boleh saya hantar idea`
11. Send: `i think we should implemnt production line`
12. Send step 2's message in Malay: `saya ada idea, tanda harga patut tunjuk harga promosi warna merah`
13. As USER A, open Ideas from the sidebar. Click My ideas, then All ideas, then browser Back. Refresh on My ideas.
14. As USER A, open an idea USER A submitted, click Edit, change Impact, Save. Then open an idea someone else submitted.
15. Unlink the contact from USER A (or pick a contact with no linked user) and send step 2's message again.

## Expected

1. The console opens with the contact selected.
2. One reply, three lines: `Idea IDEA-<number> is in: <short title>`, `Open it to add what I didn't catch: <fields>.` (only the fields the message did not give, among Proposed solution, Impact, Department; "Photos or files" always last), then `<test copy>/ideas/<id>`. No photo menu, no "Submit this idea?".
3. The link opens that idea's CRM page, never the public portal. (If ss hides test ideas from the embed, a console idea shows as not found; a real WhatsApp idea opens.)
4. EITHER `You already have ideas like this:` + numbered `<title> - <link>` lines (at most 3, USER A's own ideas only) + `Reply a number to edit that one, or NEW to log this as a new idea.` and nothing created, OR a new idea as in Expected 2. Which one depends on ss's similarity score: ss#111 compares the message with the stored, AI-rewritten problem (a cloud pass measured 0.26 against the 0.3 threshold for these two messages); a follow-up asks ss to also compare with the original message.
5. `Open IDEA-<number> to add this: <that idea's link>`; nothing created.
6. If a list appears, `NEW` creates a new idea from the step 4 text (not from the word "new"), reply as in Expected 2.
7. `Sure, what's your idea? Tell me what you'd like changed, in one message.`; nothing created; never "couldn't save" or "isn't set up correctly" (no ss call is made). While this ask is open, any short reply (3 words or fewer, no `?`, e.g. `hi`) counts as the answer, as in every ask through the shared helper: it gets Expected 8's closing line.
8. `I still couldn't find an idea in that. When you're ready, send your idea in one message, for example what you'd like changed.`; nothing created, and this ask is closed. A following `hi` is not read as an answer: the chat is still on ideas, so it may get a fresh ask-back (Expected 7), never this closing line.
9. The ask-back, then the second message creates an idea (as in Expected 2) about showing stock age.
10. `Boleh! Apakah idea anda? Beritahu saya apa yang anda mahu ubah, dalam satu mesej.`; nothing created.
11. Created, title like "Own production line"; the CRM page shows a problem like "We need our own production line."
12. Malay sentences (`Idea IDEA-<n> sudah diterima: ...`, `Buka untuk menambah apa yang saya tidak tangkap: ...`); idea number, link and field names exactly as in English; or the similar list with Malay sentences if ss scores it similar.
13. The toolbar shows `My ideas | All ideas` after `Active | Archived`, All ideas selected by default; My ideas adds `?view=mine` and shows only USER A's ideas; Back returns to My ideas (the previous view); refresh keeps My ideas.
14. Edit is shown and saves on USER A's own idea; on someone else's idea there is no Edit, no attachment upload, no Move, Archive, Delete or options menu.
15. `You need a CRM login with Ideas access to submit ideas here. Please ask your Sorento contact for one.`; nothing created.
16. If any save answers `Idea capture isn't set up correctly here, so I couldn't save that. Please let your Sorento contact know.`, that is the copy's ss config (Setup 2), not the lane: the backend log line `ideation <step> refused by ss: status=<n> code=<code>` names it. `Sorry, I couldn't save that idea just now. Please try again in a moment.` means the ss copy is not reachable.
17. Please read the Malay and Chinese wording (`chatbot_reply_copy.py`, `ideation_capture_*`); those translations are the lane's.
