# Hand test: PR #2249 CERT-LINK-CLEANUP (certificate links to check: verdicts, Confirm, Remove)

A report of every certificate-product link, each judged against the certificate PDF's own text: Found,
Check (a person decides), Not found, Scanned, No file, or Checking (not read yet). The page opens on AI
links that are Not found or Check. Confirm makes a link manual; Remove deletes it after a countdown.
Dev's file storage has no SPAN PDFs, so the SPAN certificates read No file on dev: these steps use PPS
2-11250086, whose PDF dev can read.

## URL
crew test copy

## Setup
1. Already done on dev: the migration SQL, the worker on this branch, and verdicts reset.
2. Sign in with a login that holds `master_data.certificates.edit` (for example an admin).

## Steps
1. From the home page, open the sidebar: Products > Reference Data > Certificate Links.
2. Wait for "Checking" to settle (the page refreshes itself every 5 s, for up to 10 minutes).
3. Open Filters and read the counts next to each verdict.
4. Set Source to "AI and manual" and read the counts again, then set Source back to AI.
5. In Filters > Certificate, pick PPS 2-11250086.
6. Clear the verdict filter so every verdict shows.
7. Tick one Not found row (for example SRTWC6010) and click Remove, then click Cancel before the countdown ends.
8. Tick the same row again and click Remove; let the countdown run out.
9. Tick the Check row SRTWC286-SH and click Confirm.
10. Clear the verdict filter, then set Source to "Manual or confirmed".
11. Open Products, find the product you removed in step 8, and open its Audit Trail.

## Expected
- Step 3: with Source = AI the counts add up to 8,272 (Sorento scope on dev). "Checking" reads 0 once settled.
- Step 4: with "AI and manual" they add up to 8,275.
- Step 6: PPS 2-11250086 shows 207 Found, 32 Check (for example SRTWC286-SH, through the printed `WC 286`) and
  10 Not found (SRTWC6010 to SRTWC6015). The Check badge reads "Check".
- Step 7: the toast reads "Removing in 3s" with Cancel; after Cancel the row stays, not dimmed.
- Step 8: the row disappears after about 5 s, and the certificate's detail page no longer lists that product.
- Step 9: the toast reads "1 link confirmed"; the row leaves the AI view.
- Step 10: SRTWC286-SH shows Source "Manual" and verdict Found (a confirmed link counts like a typed code). The
  verdict filter must be cleared first, or the Found row is filtered out.
- Step 11: an audit row "Certificate product ... removed" with your name.
- The BRD7711CP towel-rail case is not linked on dev. To try it, add BRD7711CP to a certificate by hand on the
  certificate's detail page first; it then reads under Source "Manual or confirmed".
