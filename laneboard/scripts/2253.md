# Hand test: PR #2253 AGENT-BULK-W3-AGENTS (pasted table assigns sales agents to customers)

A row = company + customer code (or name) + agent (code or person name). The customer is matched by its exact
code in the row's company; a name only makes the row WAIT with that company's accounts. The agent is matched by
its exact code first, then its exact person name; a person with several tier codes makes the row WAIT with those
codes. Nothing is picked until you reply. Clearing an agent is not done here. Nothing is sent to AutoCount.
