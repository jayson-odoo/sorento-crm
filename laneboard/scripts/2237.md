# Hand test: PR #2237 PRICETAG-ACCESSORY-DESIGNER (accessory card layout designed inside the Tag Template designer)

One card layout per Accessories box, designed in place on the tag template canvas (double-click the box). Each
accessory fills the card's slots from its own data: colour dots only where an accessory has colours, empty slots
close up. Accessories get several pictures with colours, rich spec lines and a remark; a product or combo list entry
can override picture and text for that list only. A box design can be saved as an accessories template, reused in any
tag template (live link, Detach) and managed under Dealer Kit > Accessory Templates. Old boxes print as before.

crew test copy

## Setup
1. Apply the `crew-migration:` SQL from PR #2237 to the test copy's DB (additive, idempotent).
2. Sign in as a user who can edit products and manage tag templates.
3. Master Data > Products > Accessories: make sure CHOPPING BOARD, COLANDER, DRAINER and PULL OUT DRAINER exist (the
   accessories lane's migration or `scripts/seed_accessories_handtest.py --apply` creates the last three).
4. Product SRTKS7846, Overview, "Accessories included": CHOPPING BOARD, COLANDER, DRAINER in that order.
5. Have two small pictures ready on your computer (any black and any grey colander photo).
6. Pick one published tag template that already has an Accessories box (call it Template A) and one more tag template
   (Template B). Note how Template A's box looks in preview with SRTKS7846 before you start.

## Steps
1. Master Data > Products > Accessories, open COLANDER.
2. Add picture: upload the black photo; set its colour to Black.
3. Add picture: upload the grey photo; set its colour to Grey.
4. Spec lines: type `390x200x140`, Enter, `Depth: 160mm`, make `160mm` bold. Save.
5. Open DRAINER: set its existing picture's colour to Black, add any second picture with colour Grey. Save.
6. Dealer Kit > Tag Templates, open Template A, preview SRTKS7846. Look at the Accessories box (do not edit yet).
7. Click the Accessories box once, then double-click it.
8. In the blue toolbar click Colour dots.
9. Drag the dots under the picture of card 1 until the pink guide appears; let go.
10. Drag the dots' bottom-right corner handle outward a little.
11. Press Delete once with nothing selected inside the card (click empty card space first).
12. Click Done.
13. With the box selected, tick "Footer note", click Edit footer, click Text, type
    `* Accessories Color Follow Kitchen Sink Color`, click Colour dots, drag the dots to the right of the text, Done.
14. Drag the box's bottom edge up until the cards get smaller, then further until fewer cards fit.
15. Drag it back down so all three fit. Click "Save as accessories template", name it `Dealer Kit included`, Save.
16. Open Template B. Click the Accessories toolbar button, pick `Dealer Kit included`. Move the box where you like.
17. In Template B double-click the new box, select the Name text, make it red, Done. Wait for the autosave.
18. Go back to Template A (reload the page).
19. In Template A select the box, click Detach. In Template B change the Name colour back to black, Done.
20. Reload Template A.
21. Product SRTKS7846, "Accessories included", click the pencil on COLANDER. Picture choice: the grey one. Name:
    `COLANDER (GREY)`. Save.
22. Back in Template A, preview SRTKS7846 again.
23. Dealer Kit > Accessory Templates.
24. Open the row menu of `Dealer Kit included`, Rename to `Dealer Kit included v2`, Save.
25. Open a tag template that has an Accessories box nobody edited in this test (or Template A's history from before
    step 7 if no other exists) and preview it.
26. Dealer Kit > Accessory Templates: Delete `Dealer Kit included v2`, let the countdown finish. Open Template B.
