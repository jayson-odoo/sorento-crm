# PR 2330 hand test: duplicate a quote line, see and filter the lines below the default price

## URL
crew test copy

## Setup
- Sign in as a user who can edit project quotations (sales or admin).
- Q is a project quotation with two or more area tabs where at least two tabs each hold a line
  priced below its default price. Crew's ready-made one: QT-2026-0002 on test project "ZZT outcome
  2197 A". No dev quotation is in that state by itself, so to make one on any quotation with two or
  more tabs: open it, gear > Edit quotation (Revise first if asked); on the first tab type a rate a
  little below the current rate of one line that shows no pill; do the same on a second tab (a line
  whose rate equals its series or list price); press Save. The banner then reads "... N lines are
  priced below the default price ...". Note the banner's numbers.
- Pick an area tab in Q with column groups (for example "Type A - 1 BH" with 1 BH / Kitchen / Yard /
  Balcony). Call it T.
- No migration and no SQL is needed.

## Steps
1. From the home page, open Project Sales in the sidebar, open the project, then open Q.
2. Look at the lines on each area tab.
3. Click the number in "N lines are priced below the default price" in the banner.
4. Click the other area tabs one by one.
5. Click the number in "N lines are outside the project's series" in the banner.
6. Open the Flags filter beside "Search lines" and look at the counts, then clear it.
7. Open the gear and choose Edit quotation (Revise first if asked).
8. On tab T, right-click a line with quantities in several areas and choose "Duplicate line".
9. Without clicking anywhere, type part of a different product code (the picker opens with what you
   type) and pick that product.
10. Right-click any other line, choose "Duplicate line", and leave its product as it is.
11. On any line that has no pill, type a rate a little below its current rate.
12. Set the Flags filter to "Below default price", then type a much lower rate into one of the shown lines.
13. Open the row's "..." menu on any line and look at the items.
14. Clear the filter. Right-click any line and choose "Remove line".
15. Press the Undo button (curved arrow left of Columns), then press Redo, then click an empty part
    of the grid and press Cmd+Z (Ctrl+Z on Windows).
16. Click into a rate, type 3 digits, click outside it, then press the Undo button once.
17. Press "Discard draft" to leave the edit without saving.
18. Repeat steps 2 to 4 with the browser window narrowed to phone width (about 375px).

## Expected
- Step 2: every line priced below its default price shows a grey "Below default price" pill under
  the product code, styled like "Non-standard" (it wraps in the narrow column). A line below the minimum price shows the red
  "Below minimum price RM x" in the Rate cell and no "Below default price" pill. Across all tabs, the
  number of "Below default price" pills equals the banner's "priced below the default price"
  number.
- Step 3: the page opens the first area tab that holds such a line, and only those lines show. Item
  numbers keep their original values (for example 3, 7, 12), and the total does not change. The
  Flags filter reads "Below default price".
- Step 4: the filter stays on: each tab shows only its lines below the default price, or "No line
  matches these flags." when it has none.
- Step 5: the filter switches to "Non-standard" and the first tab with a Non-standard line opens.
- Step 6: three options, Non-standard / Below default price / Below minimum price, each with the
  number of matching lines on the open tab.
- Step 8: a copy appears directly below the line with the same product, rate, description, notes
  and the same quantity in every area of every column group. The copy's product picker has the
  caret.
- Step 9: the copy now shows the new product's description, brand and UOM. Its rate is the series
  price for that product, or blank when the series does not name it. The source line is unchanged.
- Step 10: an exact copy right below, same product and rate.
- Step 11: about half a second after typing stops, "Below default price" appears under that line's
  product code (or "Below minimum price RM x" in Rate if the rate is also below the minimum). Nothing is
  saved.
- Step 12: the line stays on screen and keeps the caret while you type, even when it turns into
  "Below minimum price" instead; it only leaves when the filter is changed.
- Step 13: Insert a line below, Duplicate line, Insert a section above, Remove line.
- Step 14: the line disappears at once; no struck-through row, no "Removed on save", no question.
  The total drops by its amount.
- Step 15: Undo puts the line back in the same place; Redo takes it out again; Cmd+Z puts it back.
- Step 16: one Undo returns the rate to what it was before the 3 digits (one step, not three).
- Step 17: the button counts down (5 s, with Cancel); when it lapses the copies and the typed rates are
  gone, and the quotation reads as before the edit.
- Step 18: the filter, the pills and the banner links work the same; nothing is cut off and the page
  does not scroll sideways (the lines grid scrolls inside its own box).
