# Hand test #1479 (CHAT-PRODUCT-LABELS)

## URL
crew test copy

## Setup

1. Sign in as an admin who can open System > Messaging > Chatbot Console and System > Configuration > Translations.
2. Use the office contact crew set up for this test (Respond.io id 487555417).
3. Crew has already seeded the Translations rows on dev (Malay and Chinese, AI). There is no command for you to run.
4. Products used: MAB7755 (Mocha basin, with a description, list price 495, dimensions and an IKRAM certificate) and MA0100 (no dimensions).

## Steps

1. From the sidebar open System > Messaging > Chatbot Console and pick the contact.
2. Send `Boleh saya dapat maklumat produk MAB7755?` and read the reply.
3. Send `Boleh saya dapat maklumat produk MA0100?` and read the reply.
4. Send `MAB7755 的产品资料` and read the reply.
5. Send `Boleh saya dapat sijil untuk produk MAB7755?` and read the reply.
6. Send `product info MAB7755` and read the reply.
7. From the sidebar open System > Configuration > Translations, filter target language Malay and search `List Price`.
8. Edit the Malay `List Price` row to `Harga Katalog` and save.
9. Back in the Chatbot Console, send `Boleh saya dapat maklumat produk MAB7755?` again.
10. In Translations, filter target language Chinese and search `Dimensions`.

## Expected

1. The console opens with the contact selected.
2. The reply opens with `Berikut ialah produk yang sepadan.` and its labels read `*Kod Barang:*` (dev holds a staff edit of `Product Code`; without it the label is `*Kod Produk:*`), `*Keterangan:*`, `*Harga Senarai:* MYR 495.00`, `*Dimensi:*` with the basin's size and `*Spesifikasi:*` when the product has specs. `*Syarikat:*` shows only when the contact sees more than one company. The description text, product name and the spec names inside Spesifikasi stay exactly as stored, in English.
3. The same Malay labels, and the size line reads `*Dimensi:* Tidak ditetapkan`.
4. The reply opens with `以下是匹配的产品。` and its labels read `*产品代码:*`, `*描述:*`, `*标价:* MYR 495.00`, `*尺寸:*` and `*规格:*` when the product has specs (`*公司:*` for multi-company contacts only).
5. The reply opens with `Saya telah melampirkan fail di bawah.` (the IKRAM certificate is attached) and its labels read `*Jenis Lampiran:*`, `*Nama Fail:*`, `*No. Sijil:*`, `*Sah Sehingga:*` and `*Kesahan:*`. The validity value reads `Sah` (valid), `Akan tamat tempoh`, `Tamat tempoh`, `Belum sah` or `Tidak diketahui`. A file with no link instead opens with `Berikut ialah fail produk yang saya temui.` and shows `*Pautan Fail:* (pautan fail tidak tersedia buat masa ini)`. The attachment type name, file name and certificate number stay as stored.
6. The English reply is unchanged from before this PR: `Here are the matching products.`, `*Description:*`, `*List Price:* MYR 495.00`, `*Dimensions:*`, `*Specs:*`.
7. A `List Price` row exists for Malay with `Harga Senarai`, source AI.
8. The row saves and shows as manual.
9. The price line now reads `*Harga Katalog:* MYR 495.00`. Every other label is as in step 2.
10. A `Dimensions` row exists for Chinese with `尺寸`, source AI.
