# Hand test: PR #1613 SEAT-AS-PRODUCT ("seat cover for <WC>" is a product resolution)

A seat-cover ask only decides WHICH products the message is about: the WC code becomes its linked
seat-cover code(s), and the bot answers exactly as if those codes had been typed (same stock, ETA,
file and product replies, same dealer rules). No seat-cover reply of its own.
