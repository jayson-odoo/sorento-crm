# Hand test: PR #2287 TAG-ACC-CARD-RESIZE (accessories box: small box keeps its cards, resizable cards, card text fields and style)

A small accessories box keeps drawing its cards (smaller), never the blank "Accessories" placeholder; the editor
marks cards that no longer fit with a "+N" chip. In Edit card mode the white card frame resizes. A card Text can
hold the same fields as a normal text layer (price tag description, list price, ...), read per item, on Free
items and Upgrades cards, and styles like the header (background, padding, corner radius).

## URL
crew test copy

## Setup
1. Sign in with your own login.
2. IMPORTANT: the designer saves as you go. Never edit a real template; work on a Duplicate only.
3. Sidebar: Dealer Kit > Room Designer > Tag Templates. On "Kitchen sink combo" (Live v3), use Duplicate, and
   open the copy. Every step below is on that copy.
4. Combo used throughout: SRTKS8547 (6 upgrades, 2 free items, real price tag descriptions).

## Steps
1. In the copy, pick SRTKS8547 in "Preview combo".
2. Click the Free items accessories box on the canvas; note its W (mm) and H (mm) in the Inspector.
3. In the Inspector, type W (mm) = 20 and H (mm) = 12, then click on empty canvas.
4. Look at the box on the canvas.
5. Put W (mm) and H (mm) back to the values they had before step 3.
6. With the Free items box selected, click "Edit card".
7. Click empty space inside card 1 (no element selected).
8. Drag the card frame's right handle to the left by about a third.
9. Read "Card width (mm)" and "Card height (mm)" in the Inspector.
10. Set Card fill to Transparent, look at the cards, then set it back to white (#ffffff).
11. Click "Text" in the Editing card toolbar to add a text element.
12. In the Inspector, clear "Shows" (the x in the field); it reads "Fixed text".
13. Click "Insert field", choose "Price tag description", click Done.
14. Click in the Text box after the last character, type a space and `LP {{product.list_price}}`.
15. Set Background to any colour, Padding Left = 1 and Top = 0.5, Corner Radius = 1.
16. Click Done (card editing).
17. If the copy has no Upgrades box: toolbar "Add Accessories" > Default box, then in the Inspector set
    List: Upgrades.
18. Select the Upgrades box, click "Edit card", add a Text element (steps 11 to 13) with "Price tag description".
19. Select the "TOPUP" element (if the card has one), set Background to any colour and Corner Radius = 1.
20. Click Done (card editing).
21. Click Publish on the copy.
22. Sidebar: Products > open SRTKS8547 > Combos tab > Price tag templates: link the copy.
23. Open Tag preview for that combo with the copy, then Open (the same renderer the PDF uses).

## Expected
- Step 4: the box still draws its cards, smaller; never the dashed "Accessories" placeholder. An orange "+N" chip
  in the box corner counts the cards that no longer fit. (At 20 x 12 mm the white card can cover the box's right
  and bottom border; cosmetic, noted.)
- Step 8: every card in the box gets narrower, white background included; the elements keep their place.
- Step 9: the fields show the new size.
- Step 10: the card background disappears with Transparent and comes back with white.
- Step 13: each card shows its own item's price tag description (bold or other formatting kept).
- Step 14: after the description, "LP" and that item's list price. An item with no description prints nothing
  there and the lines under it move up (no gap).
- In Edit card mode only, card 1 shows the raw `{{product.price_tag_description}}` when its item has no
  description: that is the design-time hint so the element stays visible to place. It never prints.
- Step 15 and 19: the colour sits behind the text with rounded corners; the text is inset by the padding.
- Step 18: each upgrade card shows that upgrade's own price tag description.
- Step 23: the preview matches the canvas: same card size, same texts, same backgrounds; an item with no
  description shows nothing there (no raw `{{...}}`); no "+N" chip.
- Templates you did not edit look exactly as before.
