# Hand test #2360 (FILES-MOVE-DUPLICATE)

## URL
crew test copy

## Setup
- Sign in as a user who may delete files (admin).
- Two folders under Resources > Files: "Folder A" and "Folder B". Upload every file with attachment type "Project Document" (the default "AI assistant attachment" type is private to the uploader and never shows in Files).
- Folder B: `photo.jpg`, `invoice.pdf`, `scan 1.pdf`, `scan 2.pdf`.
- Folder A: different files with the same names `photo.jpg`, `invoice.pdf`, `scan 1.pdf`, `scan 2.pdf`, plus `one.jpg`, `two.jpg`, `three.jpg`, `four.jpg`, `five.jpg`, `six.jpg` (10 files, 4 of them clash with Folder B).

## Steps
1. Open Resources > Files from the sidebar, then open Folder A.
2. Tick all 10 files, Action > Move to... > Folder B > Move here.
3. Read the window, then click Cancel.
4. Open Folder B and Folder A and look at the files.
5. In Folder A tick all 10 files again, Action > Move to... > Folder B > Move here.
6. In the window, tick "Do this for the remaining 3 conflicts", then click Rename.
7. Read the message at the top of the screen, then open Folder B.
8. Upload into Folder A again a file named `photo.jpg` and one named `invoice.pdf`. Tick both, Move to... > Folder B.
9. In the window for photo.jpg type `photo final.jpg` in New name and click Rename; in the window for invoice.pdf click Skip (the two windows can come in either order).
10. Read the message, then open Folder B.
11. Drag `invoice.pdf` from Folder A onto Folder B in the folder tree, then press Esc in the window.
12. Open any file whose name is long (rename one to a 60-character name first) and move it onto a folder holding the same name: look at the window title and the close X at 1280 px and at 375 px wide.

## Expected
- Step 3: the window title names the first clashing file, e.g. "invoice.pdf already exists in Folder B.", it shows "1 of 4", a New name box with that name plus " (1)" (e.g. "invoice (1).pdf"), a tick box "Do this for the remaining 3 conflicts" and buttons Cancel, Skip, Replace, Rename (Rename is the blue one).
- Step 3 after Cancel: message "Move cancelled. Nothing was moved."
- Step 4: Folder A still holds all 10 files; Folder B still holds only its own 4. Nothing moved, not even the 6 files without a clash.
- Step 6: when the box is ticked the New name box disappears; after Rename no other window opens.
- Step 7: "6 moved, 4 renamed." Folder B holds photo.jpg, photo (1).jpg, invoice.pdf, invoice (1).pdf, scan 1.pdf, scan 1 (1).pdf, scan 2.pdf, scan 2 (1).pdf, one.jpg ... six.jpg.
- Step 9: the windows show "1 of 2" and then "2 of 2".
- Step 10: "0 moved, 1 renamed. 1 skipped: invoice.pdf." Folder B now also holds photo final.jpg; invoice.pdf stays in Folder A.
- Step 11: "Move cancelled. Nothing was moved."; invoice.pdf stays in Folder A.
- Step 12: the title wraps to at most two lines and never runs under the close X, at 1280 and at 375 px; the buttons stack on the phone, Rename on top.
