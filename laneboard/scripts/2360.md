# Hand test #2360 (FILES-MOVE-DUPLICATE)

## URL
crew test copy

## Setup
- Sign in as a user who may delete files (admin).
- Two folders under Resources > Files: "Folder A" and "Folder B". Upload every file with attachment type "Project Document" (the default "AI assistant attachment" type is private to the uploader and never shows in Files).
- Folder B: `photo.jpg`, `invoice.pdf`, `scan 1.pdf`, `scan 2.pdf`.
- Folder A: different files with the same names `photo.jpg`, `invoice.pdf`, `scan 1.pdf`, `scan 2.pdf`, plus `one.jpg`, `two.jpg`, `three.jpg`, `four.jpg`, `five.jpg`, `six.jpg` (10 files, 4 of them share a name with a file in Folder B).

## Steps
1. Open Resources > Files from the sidebar, then open Folder A.
2. Tick all 10 files, Action > Move to... > Folder B > Move here. Read the window.
3. Click Cancel. Open Folder A and Folder B.
4. Tick all 10 files in Folder A again, Move to... > Folder B. In the window tick "Apply to all 3 remaining conflicts", read the window, then click Keep all.
5. Read the message, then open Folder B.
6. Upload into Folder A a file named `photo.jpg` and one named `invoice.pdf`. Tick both, Move to... > Folder B. In the window for invoice.pdf click Skip; in the window for photo.jpg leave the suggested name and click Rename (the two windows can come in either order).
7. Read the message.
8. Move `photo (1).jpg` from Folder B to Folder A. Then in Folder B right-click `one.jpg` > Rename, type `photo (1).jpg`, confirm.
9. Move `photo (1).jpg` from Folder A back to Folder B.
10. In the window click Rename (leave the suggested name). Then in Folder B right-click `five.jpg` > Rename, type `six.jpg`, confirm, and in the window click Keep both.
11. In Folder B right-click `two.jpg` > Move to trash. Upload a new `two.jpg` into Folder B. Open Resources > Trash, search "two", tick `two.jpg`, Action > Restore selected. In the window click Rename.
12. Upload into Folder B a file named `three.jpg` (Folder B already holds one). In the upload window click Keep both.
13. Drag `invoice.pdf` from Folder A onto Folder B in the folder tree, then press Esc in the window.
14. Repeat step 2's window at 375 px wide (phone) and look at the window in both tick states.

## Expected
- Step 2: the title names the first file, e.g. "invoice.pdf already exists in Folder B.", it shows "1 of 4", a New name box with "invoice (1).pdf", a tick box "Apply to all 3 remaining conflicts", and buttons Cancel, Skip, Replace, Rename and Keep both (Keep both is the blue one).
- Step 3: "Move cancelled. Nothing was moved." Folder A still holds all 10 files, Folder B only its own 4.
- Step 4: ticked, the New name row stays in place and reads "Rename all adds a number to each name, like (1).", and the buttons read Cancel, Skip all, Replace all, Rename all, Keep all (Keep all is blue). Nothing jumps. After Keep all no other window opens.
- Step 5: "10 moved." Folder B shows photo.jpg, invoice.pdf, scan 1.pdf and scan 2.pdf TWICE each, plus one.jpg ... six.jpg (14 files).
- Step 6: the windows show "1 of 2" and "2 of 2".
- Step 7: "0 moved, 1 renamed. 1 skipped: invoice.pdf." Folder B now also holds photo (1).jpg; invoice.pdf stays in Folder A.
- Step 8: the rename just happens ("Renamed."): at that moment Folder B has no other photo (1).jpg.
- Step 9: the window "photo (1).jpg already exists in Folder B." opens (the move-away-and-back case).
- Step 10: "0 moved, 1 renamed."; Folder B holds photo (1).jpg and photo (2).jpg. The rename of five.jpg opens "six.jpg already exists in Folder B."; after Keep both Folder B shows six.jpg twice.
- Step 11: the window "two.jpg already exists in Folder B." opens; after Rename: "0 restored, 1 renamed."; Folder B holds two.jpg and two (1).jpg.
- Step 12: the upload window "File already exists in this folder" offers Cancel, Keep both, Create copy, Replace existing; after Keep both Folder B shows three.jpg twice.
- Step 13: "Move cancelled. Nothing was moved." invoice.pdf stays in Folder A.
- Step 14: at 375 px the window fits with no sideways scroll; the buttons stack with Keep both (or Keep all) on top.
