# Hand test #2360 (FILES-MOVE-DUPLICATE)

## URL
crew test copy

## Setup
- Sign in as a user who may delete files (admin).
- Two folders under Resources > Files: "Folder A" and "Folder B". Upload every file with attachment type "Project Document" (the default "AI assistant attachment" type is private to the uploader and never shows in Files).
- Folder B: `photo.jpg`, `invoice.pdf`, `scan 1.pdf`, `scan 2.pdf`.
- Folder A: different files with the same names `photo.jpg`, `invoice.pdf`, `scan 1.pdf`, `scan 2.pdf`, plus `one.jpg`, `two.jpg`, `three.jpg`, `four.jpg`, `five.jpg`, `six.jpg` (10 files, 4 of them clash with Folder B).

## Steps
1. Open Resources > Files from the sidebar, then open Folder A.
2. Tick all 10 files, Action > Move to... > Folder B > Move here.
3. Read the window, then click Cancel.
4. Open Folder B and Folder A and look at the files.
5. In Folder A tick all 10 files again, Action > Move to... > Folder B > Move here.
6. In the window, tick "Apply to all 3 remaining conflicts", read the window, untick it, read it again, tick it again, then click Keep both.
7. Read the message at the top of the screen, then open Folder B.
8. Upload into Folder A again a file named `photo.jpg` and one named `invoice.pdf`. Tick both, Move to... > Folder B.
9. In the window for photo.jpg type `photo final.jpg` in New name and click Rename; in the window for invoice.pdf click Skip (the two windows can come in either order).
10. Read the message, then open Folder B.
11. Drag `invoice.pdf` from Folder A onto Folder B in the folder tree, then press Esc in the window.
12. Rename a file in Folder A to a long name (about 60 characters), put a file with the same long name into Folder B, then move the Folder A file to Folder B. Look at the window title and the close X at 1280 px and at 375 px wide.
13. In Folder B, right-click `one.jpg` > Rename, type `two.jpg` (a name already in Folder B), confirm.
14. Move `photo final.jpg` from Folder B to Folder A, then move it back to Folder B.
15. Move `photo final.jpg` to Folder A again. In Folder B rename `photo.jpg` to `photo final.jpg`. Then move `photo final.jpg` from Folder A back to Folder B.

## Expected
- Step 3: the window title names the first clashing file, e.g. "invoice.pdf already exists in Folder B.", it shows "1 of 4", a New name box with that name plus " (1)" (e.g. "invoice (1).pdf"), a tick box "Apply to all 3 remaining conflicts" with clear space above and below it, and buttons Cancel, Skip, Replace, Rename (Rename is the blue one).
- Step 3 after Cancel: message "Move cancelled. Nothing was moved."
- Step 4: Folder A still holds all 10 files; Folder B still holds only its own 4. Nothing moved, not even the 6 files without a clash.
- Step 6: ticked, the New name row stays in place and reads "Each file gets a number added, like (1).", and the buttons read Cancel, Skip all, Replace all, Keep both. Nothing jumps. Unticked, the editable box comes back with "invoice (1).pdf" and the buttons read Skip, Replace, Rename. After Keep both no other window opens.
- Step 7: "6 moved, 4 renamed." Folder B holds photo.jpg, photo (1).jpg, invoice.pdf, invoice (1).pdf, scan 1.pdf, scan 1 (1).pdf, scan 2.pdf, scan 2 (1).pdf, one.jpg ... six.jpg.
- Step 9: the windows show "1 of 2" and then "2 of 2".
- Step 10: "0 moved, 1 renamed. 1 skipped: invoice.pdf." Folder B now also holds photo final.jpg; invoice.pdf stays in Folder A.
- Step 11: "Move cancelled. Nothing was moved."; invoice.pdf stays in Folder A.
- Step 12: the title shows at most two lines (a longer one ends in "...", full text on hover) and never runs under the close X, at 1280 and at 375 px; on the phone the buttons stack, Rename on top.
- Step 13: refused with "two.jpg already exists in Folder B."; one.jpg keeps its name.
- Step 14: both moves go through with "1 moved." (no clash).
- Step 15: the rename in Folder B goes through (at that moment Folder B has no other photo final.jpg). Moving the Folder A file back then opens the window "photo final.jpg already exists in Folder B." (this is the owner's move-away-and-back case). Folder B never shows two rows with the same name.
