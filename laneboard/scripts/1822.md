## Setup

1. Sign in as Teh Jayson (the E2E admin account).
2. No migration and no data step. Read-only check: never press the tick, the x or the pen in any row, never press Send or Confirm.
3. The copy holds OI-2609-0165, whose CB315 line is qty 170 with an open request to reserve 70. Any OI line with an open reserve request works the same way.

## Steps

1. From `/`, open Procurement > Supply Chain > Order Inquiries from the sidebar.
2. Press "Lines" at the top right.
3. Search `CB315` and read the Qty, Reserve requested and Reserved columns of the OI-2609-0165 row, then the Instruction pill.
4. Press "Filters", set Reserve to "Needs reserve", close the panel, and read the same three columns on every row.
5. Clear the search, set Reserve to "Reserved", and read the three columns on every row.
6. Press "Documents", open OI-2609-0165, open its Lines tab and read the CB315 line's SO Qty, Requested, Reserve requested, Reserved and State.
7. Back on the list, open Actions > Export Excel and open the file.
8. Shrink the window to phone width (375px) and repeat steps 3 and 6.
