## Setup

1. Sign in as Teh Jayson (the E2E admin account).
2. No migration and no data step. Read-only check: never press the tick, the x or the pen in any row.
3. The copy needs at least one OI line with an open "Request to reserve" (the CS report of 21 Oct showed one with qty 70). Any such line works.

## Steps

1. From `/`, open Procurement > Supply Chain > Order Inquiries from the sidebar.
2. Press "Lines" at the top right.
3. Press "Filters", set Reserve to "Needs reserve", close the filter panel.
4. Scroll the grid right to the Instruction column and read the amber pill on each row.
5. Open the OI of the first row (its Order inquiry number) and read the State cell of the same line on the detail page.
6. Back on the Lines list, set Reserve to "Reserved" and read the green pill on each row.
7. Shrink the window to phone width (375px) and repeat step 4.

## Expected

- Step 4: every amber pill reads `Request to reserve N` with a number, never a bare `Request to reserve`.
- Step 5: the detail page pill reads the same `Request to reserve N`, same N as the list row.
- Step 6: every green pill reads `Reserved N` with a tick, unchanged from today.
- Step 7: the pill still reads `Request to reserve N` and is not clipped.
