## Setup
1. Sign in to the CRM as yourself (superadmin: you hold `dealer_kit.tag_templates.view` and
   `dealer_kit.library.manage`).
2. Sidebar: Products > Specifications > Product Specifications > `Water supply` > `Choices and words`: `Mixer` carries at
   least one icon (your hot + cold icons from the 5 Nov feature-icon work). If not, click the icon
   button on the `Mixer` row and pick two icons, then Save.
3. Note one product code whose Water supply is `Mixer` (the key's `Products` tab lists them), and one
   whose Water supply is `Cold only`.
4. Optional, for step 9: a CRM user WITHOUT `dealer_kit.tag_templates.view` who can view products.

## Steps
1. Sidebar: Products > Products > All Products. Search the Mixer product code from Setup 3 and open it.
2. Click the `Specifications` tab.
3. Read the `Water supply` row's Value cell.
4. Hover each icon after `Mixer`.
5. Read every other row's Value cell.
6. Click the first icon after `Mixer`.
7. Go back. Click the `Mixer` value text to edit it; then click Cancel.
8. Open the Cold only product from Setup 3, `Specifications` tab, read the `Water supply` row.
9. Optional: sign out, sign in as the Setup 4 user, open the Mixer product's `Specifications` tab.
10. Narrow the browser to phone width (375px) on the Mixer product's `Specifications` tab.

## Expected
1. The product opens on its detail page.
2. The Specifications table reads Specification | Value | Source as before.
3. `Mixer`, then the icons set on `Water supply = Mixer`, small, in the order set on the key's Choices and words tab.
4. Each icon's tooltip is that icon's name as it is named in the Dealer Kit library.
5. A row whose value carries no icon shows only the value, with no gap, placeholder or "no icons" text. No warranty or anti-bac icon appears on any row.
6. The Product Specifications record for `Water supply` opens on its `Choices and words` tab.
7. While editing, the icons are hidden; after Cancel they are back after `Mixer`.
8. `Cold only` followed by only the icon(s) set on `Cold only` (or no icon if none is set).
9. The table shows values only, no icons anywhere; nothing else on the tab changes.
10. The value text shortens with "..." before the icons do; the icons stay whole; the page does not scroll sideways.
