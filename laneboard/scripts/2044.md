# Hand test: PR #2044 PRICETAG-PDF-FIELDS (price tag PDF prints the price tag description)

Owner report on PT-202610-0008 "DIY Tag": the designer shows each tag's price tag description lines
under the product code, the exported PDF did not. The PDF now reads the same tag data the designer
does, so the description lines, the product's currency and a combo tag's own parts all reach the PDF.

## URL
crew test copy

## Setup
Pick a price tag request (Dealer Kit > Price Tag Requests) in Designing or later, whose template has a
text layer showing the price tag description and whose products have a Price tag description filled
in on the product page (PT-202610-0008 "DIY Tag" if the copy has it; any request whose designer shows
description lines under the code works). Note the description text of the first two tags as the
designer shows it.

## Steps
1. Open the request from Dealer Kit > Price Tag Requests and click `Design`.
2. Look at the first two tags on the sheet and note the lines under each product code.
3. Click `Export PDF` and wait for the export to finish.
4. Open the downloaded PDF (for PT-202610-0008, `pt-202610-0008-tags-v1.pdf` or the next version).
5. Compare every tag in the PDF with the same tag in the designer.

## Expected
1. The designer opens on the sheet.
2. Each tag shows its description lines under the product code, for example `Angle Valve`, `S/Steel`, `Gunmetal`.
3. The export completes and the PDF downloads.
4. The PDF opens with the same number of sheets and tags as the designer.
5. Every tag in the PDF shows the same description lines as the designer, in the same place, along with the logo, code, barcode and price it already showed. Prices show the same currency as the designer (RM for a MYR product).
