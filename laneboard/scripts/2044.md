# Hand test: PR #2044 PRICETAG-PDF-FIELDS (price tag PDF prints the price tag description)

Owner report on PT-202610-0008 "DIY Tag": the designer shows each tag's price tag description lines
under the product code, the exported PDF did not. The PDF now reads the same tag data the designer
does, so the description lines, the product's currency and a combo tag's own parts all reach the PDF.

## URL
crew test copy

## Setup
Crew prepared PT-202609-0010 on the copy: template DIY Tag v8 with the price tag description layer,
18 tags, status Approved. Export PDF needs the request Approved or later, so a Designing request will
not do. Sign in as a user who can process price tag requests.

## Steps
1. Open Dealer Kit > Price Tag Requests and open PT-202609-0010.
2. Click `Open design`.
3. Look at the tags on the sheet and note the lines under each product code.
4. Click `Export PDF` and wait for the export to finish.
5. Open the downloaded PDF (`pt-202609-0010-tags-v<N>.pdf`, the newest version).
6. Compare every tag in the PDF with the same tag in the designer.

## Expected
1. The request opens on its detail page with status Approved.
2. The designer opens on the sheet.
3. Each tag shows its description lines under the product code, for example `Angle Valve`, `S/Steel`, `Gunmetal`.
4. The export completes and the PDF downloads.
5. The PDF opens with the same sheets and tags as the designer.
6. Every tag in the PDF shows the same description lines as the designer, in the same place, along with the logo, code, barcode and price it already showed (crew's v12 export of this request showed descriptions on 10 of 10 tags). Prices show the same currency as the designer (RM for a MYR product).
