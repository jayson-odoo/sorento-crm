## Setup

1. Sign in as Teh Jayson (the E2E admin account). No migration.
2. In Products, pick four real products and note their codes and current barcodes:
   A has no barcode, B has a barcode, C has a barcode, D has no barcode. Pick one more product E.
3. Make a small `.xlsx` (or `.csv`) with header row `Item Code` | `Barcode` and these rows:
   - A | `9555123400042`
   - B | a different 13-digit value, e.g. `9555123400059`
   - C | C's current barcode, unchanged
   - `NOT-A-REAL-CODE` | `9555123400066`
   - D | `123456`
   - E | (blank barcode cell)
   A shape reference with demo codes is in `documentation/plans/master-data/evidence/barcode-import/barcode-sample.xlsx`.
4. This writes real barcodes on the test copy only. Afterwards put B's old barcode back by hand if you want the copy clean.

## Steps

1. From `/`, open Products > Products > All Products from the sidebar.
2. Click Actions.
3. Click Import barcodes.
4. Click Download template.
5. Drop the file from Setup step 3 on the drop zone.
6. Click Test.
7. Read the counts and the row table.
8. Click Apply 3 barcodes.
9. Close the dialog and search the list for A, B and D.
10. Open B's detail page, then its History / audit trail.
11. Reopen Actions > Import barcodes, drop the same file, click Test.
12. Narrow the window to about 375px and repeat steps 2, 3, 5 and 6.
