# Hand test #1811 (BARCODE-IMPORT)

## URL
crew test copy

## Setup

1. Sign in as Teh Jayson (the E2E admin account). No migration.
2. Use the file you sent crew, `Sorento_Barcode_List.xlsx` (you have it; it is never in the repo). Sheet "Barcodes", 185 rows, columns No. | Product Code | Barcode (EAN-13) | Barcode Image | Note.
3. Crew sends you a second file, `handtest-errors.csv`, directly (never in the repo or a gist). 4 rows; codes A, B and C are three codes from your file without a Note: NOT-A-REAL-CODE | 9555123400066; code A | 9.55103E+12; code B | blank; code C | 12345. Never apply this one.
4. This test writes your 185 barcodes into SRT and 172 into MCH on the shared dev DB. Afterwards crew runs `crew/state/barcode/cleanup-dev-after-handtest.sql` (clears exactly those values on exactly your codes, and rolls itself back if more than 357 rows would change; held for you), so a re-test starts from New again.

## Steps

1. From `/`, open Products > Products > All Products from the sidebar.
2. In the top bar company switcher, make SRT the active company.
3. Click Actions, then Import barcodes.
4. Look at the Apply button before choosing any file.
5. Click Download template.
6. Drop `Sorento_Barcode_List.xlsx` on the drop zone and look at the Apply button again.
7. Click Test.
8. Read the "Importing into" line, the "Columns used" line and the count tiles.
9. Read the table (it lists only rows needing attention).
10. Turn on "Show all 185 rows".
11. Drop `handtest-errors.csv` on the drop zone (replacing the first file) and look at the Apply button.
12. Click Test and read the table.
13. Drop `Sorento_Barcode_List.xlsx` again and click Test.
14. Click Apply 185 barcodes.
15. Close the dialog, search the list for the first product code in your file and open it.
16. In the top bar, switch the active company to MCH.
17. Open Actions > Import barcodes, drop `Sorento_Barcode_List.xlsx`, click Test.
18. Click Apply 172 barcodes.
19. Reopen Actions > Import barcodes, drop the same file, click Test (still MCH).
20. Narrow the window to about 375px wide and repeat steps 3, 6 and 7.
21. Optional: switch back to SRT, open the one product whose existing barcode fails the EAN-13 check (you named it to crew; it is not in your file), Edit, clear the Barcode field, Save.
