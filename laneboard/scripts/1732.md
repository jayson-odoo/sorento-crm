# Hand test #1732 (CONTACT-ACTIONS-COPY)

## URL
crew test copy

## Setup

1. Sign in as Teh Jayson (the E2E admin account).
2. No migration and no data step. The copy never calls respond.io.
3. Crew names the source contact and two target contacts (real dev contacts). The source should have as many access settings set as possible; the targets should differ from it.
4. Write down each target's name, phone and linked customers.

## Steps

1. From the sidebar open Users & Access > People > Internal Users.
2. Tick the two targets.
3. Look at the bar above the grid, then open the Actions menu.
4. Click `Disable messaging (2)`. Read the dialog, click Cancel.
5. Open Actions and click `Delete (2)`. Read the dialog, click Cancel.
6. Open Actions and click `Copy access from contact (2)`.
7. In "Copy access from", search the source by name and pick it. Read the summary list.
8. Click `Preview changes`. Expand each target row.
9. Click `Apply to 2 contacts`, then `Done`.
10. Open the source's contact page, then each target's contact page, and compare every access setting.
11. Back on the list, tick one target, open Actions, `Copy access from contact (1)`, pick the source again, click `Preview changes`.

## Expected

- Step 3: the bar shows `2 selected`, one `Actions` button and `Clear`, and no other bulk buttons. The menu lists Export, Link customers (2), Enable messaging (2), Sync from Respond (2), Copy access from contact (2), Disable messaging (2), Delete (2); the last two are red.
- Step 4: the "Disable outbound messaging" dialog opens; Cancel changes nothing.
- Step 5: the "Delete contacts" dialog opens; Cancel deletes nothing.
- Step 7: the summary lists every access setting of the source: Access types, Tier, Chatbot switches (including Send files as links), Requires registered project, Regions, Field reveals, Agent access, Agent field overrides, Stock check mode, Locations, Companies, Market segments, Brands, Image access, Voice note access, Attachment types, Portal forms, Spec visibility. "Not copied" reads "Linked customers, CS routing, Memory".
- Step 8: each target lists every setting where it differs from the source.
- Step 9: "Copy finished", 2 updated.
- Step 10: every access setting on each target equals the source. Name, phone, linked customers, memory and language are unchanged from Setup.
- Step 11: the target shows "No change" (0 will change, Apply disabled).
