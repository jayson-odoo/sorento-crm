# Hand test: PR #2206 TAG-TEMPLATE-DELETE-CONFIRM (tag template delete asks first, and archives)

The row's "Delete template" icon on Tag Templates now opens a confirm that names the template and
how many products, combos and requests use it. Delete archives the template: it leaves the list
and the pickers, but its versions and links stay in the database so it can be restored.
Use only a throwaway template you create below. Never delete a real template.

## URL
crew test copy

## Setup
- Signed in as an admin, browser about 1280 px wide.
- The migration from the PR's `crew-migration:` comment applied to the test copy's database.

## Steps
1. From `/`, open the sidebar Dealer Kit > Room Designer > Tag Templates.
2. Click New Template, name it `ZZ delete test`, family Ala Carte (any price tag family), save.
3. Back on Tag Templates, on the `ZZ delete test` row click the Assign to products icon (chain link), filter to any one product code, and assign it. Close the dialog.
4. On the `ZZ delete test` row click the red trash icon (Delete template).
5. Read the dialog, then click Cancel.
6. Click the same row's trash icon again, then click Delete in the dialog.
7. Reload the page.
8. Open the product you assigned in step 3 (Master Data > Products > that product) and look at its tag templates.

## Expected
- Step 4: a dialog titled "Delete template?" opens. It reads `ZZ delete test is used by 1 product.` (after a moment; a template nobody uses reads `... is not used by any product, combo or request.`). Nothing is deleted yet, and no countdown toast appears.
- Step 5: the dialog closes; `ZZ delete test` is still in the list.
- Step 6: the dialog closes, a "Template deleted" toast shows, and the row leaves the list.
- Step 7: `ZZ delete test` is still gone from the list.
- Step 8: `ZZ delete test` is not offered for that product (the link is kept in the database, hidden).
- Selecting rows and using the toolbar Delete still runs the old 10 second countdown with Cancel (unchanged), and the templates it deletes are archived the same way.
