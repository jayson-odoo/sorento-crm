- D = a dealer contact (stock visibility "availability") of company A. S = a staff contact. Agent switch OFF.

1. As D, send "CWC604-P-RL x 2".
2. As D, send "CWC605RL x 1".
3. As D, send "cwc604-rl x 2", then reply "1".
4. As D, send "CWCY604 x 5, CWC604-P-RL x 2".
5. As D, send "CWC604-P-RL stock" (no quantity).
6. As S, send "CWC604-P-RL x 2".

  "Only 1 got stock."). No "How many units" question.
- Step 2. Prod says: "How many units for each?" 1. CWCX605-RL 2. CWCY605.
  This branch says: "CWCX605-RL x 1: <availability>" and "CWCY605 x 1: <availability>"; no -SOFT / -NEW / -WEPLS code.
- Step 3. The offer lists CWC604-P-RL and CWC604-S-RL; after "1" the reply is the same as step 1 (each part x 2).
- Step 4 (a part typed beside its set): one line for the pan "CWCX604-P-RL x 2: ..." and one for the cistern at the
  total, "CWCY604 x 7: ..." (5 typed + 2 from the set), the same whichever order the two codes are typed.
- Step 5 (no quantity): unchanged, "How many units for each?" with the two parts.
- Step 6 (staff): unchanged, the "*Set CWC604-P-RL*" block with each part's stock.
- A part that counts 2 in a set is asked at twice the typed quantity (a set with a 2-piece part at x 3 asks for 6).
- Note: a part typed with NO quantity beside a set WITH one ("CWCY604, CWC604-P-RL x 2") is answered at the set's
  quantity without asking.
