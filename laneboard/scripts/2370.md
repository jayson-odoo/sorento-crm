# PR 2370 hand test: chatbot stock code matching (close-code offers, sets, stored sizes)

## URL
crew test copy

## Setup
- Open the Chatbot Console (System Management > Chatbot Console). Every turn is a dry run; nothing is sent.
- D = a dealer contact (stock visibility "availability"). S = a staff contact (compact stock reply).
- Codes below are catalogue codes from the 12 Nov review; if one is missing on the copy, use a code of the same shape.
- Set: a registered product set with a dash in its code (review example CWC604-P-RL).
- Sized family: a water closet family where one member stores a trap outlet length and another stores none
  (review example SRTWC8152-SH-UF and its sized siblings).
- No migration and no SQL is needed.

## Steps
1. As D, send "Swtwc8354-SH-UF x 3".
2. Reply "yes".
3. As D, send "SRTWC8354-SH-UF x 2, Swtwc8152 x 1".
4. As S, send "SRTWC286-150".
5. As D, send "CWC604RL x 2".
6. Reply "1".
7. As S, send "SRTWC8152-SH-UF 400mm".
8. As D, send "8152-300-SH stock".
9. As D, send a typo of a code whose only close code is inactive in Products.
10. Open the trace of step 1 and find the code_candidates entry.

## Expected
- Step 1: "Couldn't find SWTWC8354-SH-UF. Did you mean SRTWC8354-SH-UF?" (no "Please refer to your salesman.").
- Step 2: the stock line of SRTWC8354-SH-UF for 3 units.
- Step 3: the stock line of SRTWC8354-SH-UF x 2, then "Couldn't find SWTWC8152. Did you mean ..." with its close code(s).
- Step 4: a did-you-mean whose first options hold "150" (SRTWC286-SH-150, SRTWC286-SH-NEW-150), then SRTWC286-SH.
- Step 5: "Couldn't find CWC604RL. Did you mean:" with 1. CWC604-P-RL (the set) then its member products.
- Step 6: the same reply as sending "CWC604-P-RL x 2".
- Step 7: "Couldn't find "SRTWC8152-SH-UF" (product) with size 400 mm. Did you mean:" with each family code and its
  stored size ("Trap outlet length: 300 mm") or "not recorded"; no stock answered.
- Step 8: "Did you mean SRTWC8152-SH-300?" with its stored 300 mm; not answered.
- Step 9: the inactive code is not offered; the reply is "Couldn't find X." and "Please refer to your salesman."
- Step 10: the typed code, the offered codes in order with tier and similarity, outcome "offered".
- Every step at 375 px and 1280 px: replies wrap, no clipped lines.
