crew test copy

## Setup
- The dev DB has the PR's `crew-migration:` SQL applied (crew test copy on a dev DB copy).
- Sign in as an admin (admin passes every permission check). Have a salesperson login ready for the last step.
- Dev data already left by crew: a CNY rate 1.6 effective 01/11/2026, an RMB row 1.6 effective 01/11/2026 (free text from before the currency pick-list; it matches no supplier cost, so it is never used), the transport rule CB-WB = Add 8, and a Bath Plus costing profile at 8%.
- The dev DB's `deferred_action_seconds` is 1, so the removal countdown toast lasts about 1 second.
- Figures below are the dev data's: CGB9032B primary supplier 400-C029 (on this DB the supplier's name equals its code), cost CNY 34.00, list price 100.00. 25BCSC (1/2" ULTRA CIRCULAR) has a supplier cost but no list price.
- History may already hold older rows from crew's earlier passes; read the newest entry.

## Steps
1. From `/`, open the sidebar: Products > Products > Costing. Look at the toolbar row above the grid.
2. Sorting (owner item 1): click the header of every column in turn, once for ascending and once for descending: Category, Code, Name, Supplier, Cost, Rate, SST, Transport, Landing (RM), Cost method, Mark-up, Final (RM), List price (AutoCount).
3. Supplier name (owner item 5): search "CGB9032B", read the Supplier cell, then hover it.
4. Click the CGB9032B row's expand control. Click each header of the supplier sub-grid.
5. No -100 % (owner item 6): search "25BCSC" and read the row (scroll right to see Mark-up, Final and List price).
6. Filters (owner item 3): clear the search. Open Filters. Pick Cost = "Has cost" only. Close the popover and read the chips. Then open Filters again and pick Cost = "No cost" only. Then clear the Cost filter from its chip.
7. "As of" (owner item 3): in the toolbar, open the As of date picker and pick 31/10/2026. Then set it back to today.
8. Settings grids (owner item 4): click Settings. On Exchange rates: open the Currency field and the Effective from field; click each column header; type "CNY" in the grid's search box; read the pager. On "SST and method": read it. On "Transport by category": type "CB-WB" in the grid's search box, read its rule, click each column header, read the pager. Close Settings.
9. Party select (owner item 2): in the toolbar's party select (it reads "Company standard"), type "bathplus" (or "304-R017") and look at the options. Pick RELATED - BATHPLUS SDN BHD (304-R017).
10. Read the header chips. Only if the header shows "Set up costing": click it, enter Party mark-up 8, leave Cost method as it is, Save.
11. Open the "Actions" menu (top right of the grid), choose "Add products", tick CGB9032B, add it.
12. Click the Margin header (asc and desc) in this party view.
13. Click Edit, type 10 into the CGB9032B Mark-up, Save.
14. Open the CGB9032B row menu, choose History.
15. Click Edit, clear the CGB9032B Mark-up, Save.
16. Open the "Actions" menu, choose "Export", open the downloaded xlsx.
17. CGB9032B row menu, "Remove from party". Do nothing while the toast counts down (about 1 s on this DB). Reload the page.
18. Clear the party select (its own clear control) back to "Company standard". Open the browser console.
19. Settings, Exchange rates: pick Currency CNY, Effective from 01/01/2027 (CNY 01/12/2026 already exists on this DB), "Units per MYR 1", Rate 1.63, Add rate. Then try Add rate again with the same currency and date.
20. Sign out. Sign in as the salesperson. Look at the sidebar, then open `/master-data-management/costing` directly.
