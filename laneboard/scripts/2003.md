# Hand test: PR #2003 CONVO-SEARCH-MESSAGES (the Conversations search box also finds message text)

Owner, 30 Oct: "i think from here need to be able to search by messages". The one search box on
SLA > Conversations now matches contact name, phone AND the text of any stored message (sent or
received). A row found by a message shows that message with the word highlighted, and clicking it
opens the thread on that message. No migration: the text index it uses (alembic 327) is already on
the dev database.

## URL
crew test copy

## Setup
1. The test copy runs on the latest dev restore. No migration.
2. Sign in as an admin (anyone with the Conversations view permission).
3. Pick an OLD message to search for, one that is not the contact's latest message:
   `SELECT c.name, h.message, h.sent_at FROM chat_histories h JOIN respond_contacts c ON c.respond_io_id = h.contact_id WHERE h.message_id IS NOT NULL AND length(h.message) > 30 AND h.sent_at < now() - interval '14 days' ORDER BY h.sent_at DESC LIMIT 5;`
   Take one row. Call its contact C, and pick one distinctive word from its message (5+ letters, not
   part of C's name). Call that word W.
4. Optional, for the mixed-language check: `SELECT message FROM chat_histories WHERE message ~ '[一-鿿]' LIMIT 3;` and take a two-character Chinese word from one result. Call it Z.

## Steps
1. From the sidebar, open SLA > Conversations.
2. Read the placeholder of the search box.
3. Click the All tab, then type W into the search box.
4. Find C's row in the list and read the line under the name.
5. Click C's row.
6. Look at the thread on the right.
7. Clear the search box and type part of C's name.
8. Type W again, then click the Mine tab, then the All tab.
9. If you picked Z in setup step 4: type Z into the search box.
10. Type "sign-in code is" and read any rows that come up.
11. Narrow the browser to 375px wide, type W, tap C's row, then tap "All conversations".

## Expected
- Step 2: "Search name, phone or message".
- Step 3: the list narrows within a second; rows found by a message are newest-match first.
- Step 4: C's row shows the matched message (not the latest message) with W highlighted in yellow; the time on the right is when that message was sent; the arrow shows whether it was sent or received.
- Step 5 / 6: the thread opens scrolled to the matched message (not the bottom), the bubble is ringed, and W is highlighted inside it. "Jump to latest" brings you back to the newest messages.
- Step 7: rows matched by name show the latest message as before (no highlight).
- Step 8: Mine shows only contacts where you hold an open enquiry and whose messages contain W (may be empty, with the "No conversation matches" message); All shows them all again.
- Step 9: contacts with Z in a message appear, Z highlighted.
- Step 10: any sign-in code row shows the code as ****** in the snippet; typing the six digits of a code never finds it.
- Step 11: the row and the thread fit at 375px with no sideways scroll; the thread opens on the matched message; "All conversations" goes back to the list with the search still applied.
