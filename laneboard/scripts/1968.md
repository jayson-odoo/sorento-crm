# Hand test: PR #1968 PROJECT-PO-ACTIONS (Orders tab: Upload a PO document on the right, Record a PO under Actions)

Owner, 29 Oct: on a project's Orders tab the Purchase orders toolbar had Search, Columns, Upload a PO document and
+ Record a PO all on the left. Upload stays the primary button but moves to the right end; Record a PO moves into an
"Actions" menu button beside it. UI only, no backend change, no migration.

## URL
crew test copy

## Setup
1. The test copy runs on the latest dev restore. No migration.
2. Sign in as an admin (anyone who can edit projects).

## Steps
1. From the sidebar, open Project Sales > Projects.
2. Open any approved project.
3. Open the Orders tab.
4. Read the Purchase orders card toolbar from left to right.
5. Click "Actions".
6. Click "Record a PO".
7. Close the dialog with Cancel.
8. Click "Upload a PO document", then close its dialog.
9. Narrow the browser to 375px wide and read the toolbar again, then repeat steps 5 and 6.
10. Sign in as a user who can view projects but not edit them, open the same project's Orders tab.

## Expected
- Step 4: Search POs, then Columns on the left; on the right end, "Actions" (outline button) then "Upload a PO document" (filled primary button, last). No separate "Record a PO" button.
- Step 5: a menu opens with one item, "Record a PO".
- Step 6: the "Record a purchase order" dialog opens, the same dialog the old button opened.
- Step 8: the PO upload dialog opens, unchanged.
- Step 9: nothing is clipped and there is no sideways scroll; Actions and Upload a PO document wrap onto their own row, right-aligned; the menu and dialog still open.
- Step 10: neither Actions nor Upload a PO document is shown; Search and Columns still are.
