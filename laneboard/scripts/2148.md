# Hand test: PR #2148 OI-UX-FILTER-SNAPSHOT (OI lines filter survives prev/next; every SO names its customer and project)

Two owner asks (3 Nov). (1) On an Order Inquiry page, the Lines search, State filter and sort
now ride in the address bar (`view_q`, `view_state`, `view_sort`) and carry over when you press
next/previous OI, and over a reload. (2) Wherever a sales order is named, its customer and project
are named too: grids get the SO list's own Customer + Project columns; compact places print one
line `CUSTOMER / project`, with a dash for a half the order does not have (`ACME SDN BHD / -`).

## URL
crew test copy

## Setup
- Signed in as an admin, one browser tab.
- The copy is a prod copy. Data named below was checked on it by crew (4 Nov): order inquiry
  OI-2609-0780 (15 lines, 7 match "SR"), Stock Debt products CB1519SS and ACC-CB2007, the one
  saved Stock Debt snapshot dated 28/10/2026, and SO397869 on the Fulfilment Planning board.
- Do not save a new Stock Debt snapshot.

## Steps
1. From `/`, open the sidebar Procurement > Supply Chain > Order Inquiries.
2. Pick the "All" tab, type "OI-2609-078" in the search box, and open OI-2609-0780.
3. On its Lines tab, type "SR" into "Search product...".
4. Open the State filter and tick "Request to reserve" and "On PO/SPO".
5. Click the "Product" column header once.
6. Press the next-inquiry chevron (top right) twice, then the previous chevron once.
7. Press the browser Reload.
8. Clear the search box and untick both State values.
9. Press the next-inquiry chevron once.
10. Type "SR" into "Search product..." again, then press "Back to order inquiries".
11. From `/`, open the sidebar Procurement > Supply Chain > Stock Debt, search CB1519SS and click its red month cell.
12. In the dialog, look at the Demand tab, then the Supply tab; on Supply find the Lent entry of B2154-NL in the Feb 27 column (search SO369758).
13. Close the dialog. Search ACC-CB2007 and click its red month cell.
14. Close the dialog. Open Snapshots, open the snapshot dated 28/10/2026, and click CB1519SS's red month cell.
15. In that snapshot drill, press "Request CS to reserve" on an OI group (if offered), look, then Cancel.
16. From `/`, open the sidebar Project Sales Admin > Sales Orders, tick two orders, open the toolbar Actions menu and choose "Reset planning (2)", look, then Cancel.
17. From `/`, open the sidebar Supply Chain > Project Demand > Fulfilment Planning, open the board holding SO397869, switch Rows to Sales order, then switch to List.
18. From `/`, open the sidebar Stock Transfers (under Inventory). Click the "Customer" column header, then the "Project" column header.

## Expected
- Step 3: 15 lines narrow to 7; the address bar gains `view_q=SR` (after you stop typing).
- Step 4: the address bar gains `view_state=reserve:requested,placed`; only matching lines show.
- Step 5: the address bar gains `view_sort=item_code:asc`.
- Step 6: every inquiry you land on opens on Lines with the same two State values ticked, the same search text and the same Product sort; the three `view_*` params stay in the address bar along with the list's own params.
- Step 7: after reload the same filter, search and sort are still applied.
- Step 8: `view_q` and `view_state` leave the address bar; every line shows again.
- Step 9: the next inquiry opens unfiltered (sort still Product, `view_sort` kept).
- Step 10: the list opens on the tab, search and page you left it with; no `view_` params in the address bar.
- Step 11: Demand has "Customer" and "Project" columns right after "Sales order" (a dash where the order has none, never an id).
- Step 12: Supply's "Assigned to" lists each receiving SO with `CUSTOMER / project` under it; the Lent entry under Covered by also names SO369758's `CUSTOMER / project`.
- Step 13: an order with no project reads `CUSTOMER / -` (or a dash in the Project column), never a note or an id.
- Step 14: the snapshot drill shows the same Customer and Project columns; each OI group heading reads the OI number only, with no `CUSTOMER / project` line under it.
- Step 15: the "Request CS to reserve" dialog names the SO number with `CUSTOMER / project` under the title.
- Step 16: the Reset planning dialog lists each ticked SO with its `CUSTOMER / project` under it.
- Step 17: under Rows = Sales order, SO397869 reads `NEU STUDIO PLT (PROJECT - CASH) / -`, the same as on the Sales Orders list (never `/ OWN COLLECT`, which is the order's note, not a project). The List view's sortable "Project" column right after "Customer" shows a dash for it. The board gear's "Split delivery SO..." / "View splits SO..." / "Undo SO..." items show the same `CUSTOMER / project` under the action.
- Step 18: the list has "Customer" and "Project" columns for the transfer's sales order (a dash when none); each header click shows a sort arrow and re-sorts the whole list.
