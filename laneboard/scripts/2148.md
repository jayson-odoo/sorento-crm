# Hand test: PR #2148 OI-UX-FILTER-SNAPSHOT (OI lines filter survives prev/next; every SO names its customer and project)

Two owner asks (3 Nov). (1) On an Order Inquiry page, the Lines search, State filter and sort
now ride in the address bar (`view_q`, `view_state`, `view_sort`) and carry over when you press
next/previous OI, and over a reload. (2) Wherever a sales order is named, its customer and project
are named too: grids get the SO list's own Customer + Project columns; compact places print one
line `CUSTOMER / project`, with a dash for a half the order does not have (`ACME SDN BHD / -`).

## URL
crew test copy

## Setup
- Signed in as an admin, one browser tab.
- The copy is a prod copy: it holds order inquiries with several lines in mixed states, and a
  saved Stock Debt snapshot (if none, step 11 saves one).
- Pick a Stock Debt product that has a red month with at least one order inquiry behind it
  (any product with a negative month on the board).

## Steps
1. From `/`, open the sidebar Project Sales > Order Inquiries, and open the first inquiry in the list.
2. On its Lines tab, open State and tick "Request to reserve" and "Placed". Type a product code fragment into "Search product...". Click the "Product" column header once.
3. Press the next-inquiry chevron (top right) twice, then the previous chevron once.
4. Press the browser Reload.
5. Clear the search box and untick both State values.
6. Press the next-inquiry chevron once.
7. Type a product code fragment into "Search product..." again.
8. Press "Back to order inquiries".
9. From `/`, open the sidebar Project Sales > Stock Debt. Click a red month cell of the chosen product.
10. In the dialog, look at the Demand tab, then the Supply tab.
11. Close the dialog. Open Snapshots, open the newest snapshot (or Save one with the current filters and open it), and click the same product's red month cell.
12. In that snapshot drill, press "Request CS to reserve" on an OI group (if offered).
13. From `/`, open SCM > Sales Orders, tick two orders and press "Reset planning (2)" (do not confirm; press Cancel).
14. From `/`, open Project Sales > Fulfilment Planning, open any order's board, switch Rows to Sales order, then switch to List.
15. From `/`, open the sidebar Stock Transfers (under Inventory). Click the "Customer" column header, then the "Project" column header.
16. From `/`, open Project Sales > AutoCount Differences.

## Expected
- Step 2: the address bar gains `view_state=reserve:requested,placed`, `view_q=<your text>` (after you stop typing) and `view_sort=item_code:asc`; only matching lines show.
- Step 3: every inquiry you land on opens on Lines with the same two State values ticked, the same search text, and the same Product sort; the three `view_*` params stay in the address bar along with the list's own `page`/`limit`.
- Step 4: after reload the same filter, search and sort are still applied.
- Step 5: `view_q` and `view_state` leave the address bar; every line shows again.
- Step 6: the next inquiry opens unfiltered (sort still Product, `view_sort` kept).
- Step 8: the list opens on the page and filters you left it with; no `view_` params in the address bar.
- Step 10: Demand has "Customer" and "Project" columns right after "Sales order" (a dash where the order has none, never an id). Supply's "Assigned to" lists each receiving SO with `CUSTOMER / project` under it. A "Lent to SO..." entry under Covered by also names that order's `CUSTOMER / project`.
- Step 11: the snapshot drill shows the same Customer and Project columns, and each OI group heading reads the OI number with `CUSTOMER / project` under it. An older snapshot shows them too.
- Step 12: the "Request CS to reserve" dialog names the SO number with `CUSTOMER / project` under the title.
- Step 13: the Reset planning dialog lists each ticked SO with its `CUSTOMER / project` under it.
- Step 14: under Rows = Sales order each row header shows the SO number with `CUSTOMER / project` under it; the List view has a sortable "Project" column right after "Customer". The board gear's "Split delivery SO..." / "View splits SO..." / "Undo SO..." items show `CUSTOMER / project` under the action.
- Step 15: the list has "Customer" and "Project" columns for the transfer's sales order (a dash when none); each header click shows a sort arrow and re-sorts the whole list (page 1 changes, not just the rows on screen).
- Step 16: each row shows the order's "Customer" next to its project (a dash when none, never an id).
