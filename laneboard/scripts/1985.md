# Hand test: PR #1985 SAMPLE-FROM-QUOTE (a new sample request starts from the project's quotation)

Owner meeting 29 Oct: a sample request pulls all items of the project's quotation; the user deletes the lines
not needed. Owner answers 30 Oct: latest issued revision (picker when the project has more than one quotation,
a never-issued quotation uses its working copy), qty 1 per row, one row per product, discontinued products
included, the source quotation recorded on the request, the staff form pre-fills too. Free-text quotation lines
are never added (owner Q3, 30 Oct): they are left out and counted in a note under the items. A request that comes
from a quotation can only carry that quotation's products (owner hand test, 30 Oct): Add row offers nothing else.

crew test copy

## Setup
1. Apply the lane's dev SQL first (crew-migration comment on the PR): two nullable columns on
   `projects.sample_requests` (`quotation_document_id`, `quotation_issue_id`).
2. Dev restore shapes used below (crew data, 29 Oct):
   - Project A: one quotation, never issued, one product line plus one product-set line of 3 parts.
   - Project B: one quotation, never issued, two product lines.
   - Project C: no quotation.
3. Sign in as an admin for steps 1 to 9; as a salesperson who sees only their own requests (Project A one of
   their projects) for steps 10 to 12; as a portal contact granted Sample Request for steps 13 to 14. Browser
   1280px wide unless a step says 375px.

## Steps
1. Sidebar: Project Sales > Projects, open Project A, click the "Sample Submission" stage action (or Project
   Sales > Sample Requests > Create and pick Project A as Registered project).
2. Read the Line items table.
3. Click the bin (Remove line) on the second row.
4. Click "Add row", tap the new row's item box without typing, read the list.
5. Type the code of a product that is NOT on Project A's quotation, read the list.
6. Type part of a product that IS on the quotation, pick it, set Qty 2.
7. In Registered project, pick Project B instead.
8. Cancel, start a new sample request again and pick Project B.
9. Without touching the rows, change Registered project to Project C.
10. As the salesperson: My Requests > Sample Request > New, pick Project A.
11. Read the Items card; tap Add item and the new row's box.
12. Save as draft and open it.
13. As the portal contact: portal > Sample Request > New, pick Project A in Registered project.
14. Narrow the browser to 375px and repeat step 13; tap Add item and the new row's box.

## Expected
- Step 2: 4 rows, each Qty 1: the single product, then the three set parts. No quotation picker (only one quotation). No note.
- Step 3: 3 rows remain; the removed one is gone.
- Step 4: the list shows only Project A's quotation products (the single product and the three set parts), not the
  whole catalogue.
- Step 5: "No matches": the off-quote product is not offered.
- Step 6: the picked product becomes a new row with Qty 2.
- Step 7: the rows stay exactly as you left them (you changed them), nothing is replaced.
- Step 8: 2 rows, Qty 1, from Project B's quotation.
- Step 9: the rows go back to one blank row (Project C has no quotation; untouched rows follow the project).
- Step 11: the same 4 rows as step 2; the new row's box lists only Project A's quotation products.
- Step 12: the saved request shows "Quotation: <number> (not issued)" above the items.
- Step 13: the same 4 rows as step 2.
- Step 14: the same rows; the box lists only the quotation's products; rows, Qty boxes and bin buttons fit, nothing
  clipped, no sideways scroll.
