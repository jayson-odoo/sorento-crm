# Hand test: PR #2013 CHATBOT-SET-STOCK (a set or catalogue code answers every part, for every ask)

Your salesperson asked "Pls check stock srtwc7405 x 6 sets" and the bot answered the seat cover only. Now a
catalogue code (SRTWC7405, SRTWC8826) or a set code answers every set it names, each under its own "Set <code>"
heading with its tank (X), bowl (Y) and seat cover (SC), in the same format as a product code. Round 2 (your
hand test of 30 Oct): this holds for every ask that takes products, ETA, photos, orders and delivery included,
and the bot never asks about sets or "how many sets". No prompt change: the resolver finds the sets.

crew test copy

## Setup
1. The copy runs the PR head (no migration in this PR) with a Gemini key in the AI assistant settings.
2. Sign in as the owner (admin).
3. A staff contact that sees stock numbers, and a contact on "Availability only" (crew names them).

## Steps
1. CRM sidebar: System > Messaging > Chatbot Console. Pick the staff contact.
2. Send: `Pls check stock srtwc7405 x 6 sets`
3. Send: `stock srtwc8826`
4. Send: `ada stok srtwc8608 3 set?`
5. Send: `stock srtwc7405 and srtwc8826`
6. Send: `stock SRTWC7405-SC`
7. Send: `srtwc8826 eta`
8. Send: `delivery for srtwc8608-rl`
9. Pick the "Availability only" contact and send: `srtwc8826 eta`
10. Same contact, send: `check stock srtwc8826`

Stock numbers vary with the copy's data; check that the parts appear. The numbers below are the crew copy's on
30 Oct.
