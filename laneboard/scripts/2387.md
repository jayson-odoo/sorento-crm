# PR 2387 hand test: order inquiry stock table shows a Mocha location's own stock

## URL
crew test copy

## Setup
- Sign in as a user who can open Order Inquiries (Procurement > Supply Chain > Order Inquiries)
  and who is granted BOTH companies, Sorento and Mocha, with **Sorento active** (company switcher
  in the header). This is the case the bug was found on, so test it this way first.
- OI = an order inquiry in Sorento with at least:
  - line M: Location `MOCHA-WH` (a Mocha location, outside every ownership group);
  - line G: Location at an ownership-group bin, e.g. `BRW-BB` (or any `<site>-BB` / `-IB` / `-IR` bin).
  The spare part request filed in Sorento during the PR 2381 test (a line at MOCHA-WH) fits; any
  sales-order inquiry with a line at MOCHA-WH works too. If none exists, create a spare part request
  in Sorento with one line at MOCHA-WH and one at BRW-BB.
- Before starting, note for line M's item: its On hand at MOCHA-WH from Inventory > Stock status
  (switch to Mocha to read it, then switch back to Sorento). Call it N.
- Note for line G's item: the On hand at each BB location and the BB group subtotal as the
  fulfilment board's stock table shows them today (unchanged by this PR).
- No migration and no SQL is needed.

## Steps
1. From the home page, open Procurement > Supply Chain > Order Inquiries in the sidebar.
2. Set the list filter to All and open OI.
3. On the Lines tab, click the chevron on line M (Location MOCHA-WH).
4. Read every cell of the MOCHA-WH row in the stock table under it.
5. Click the chevron on the MOCHA-WH row of that table.
6. Collapse line M. Click the chevron on line G.
7. Read the rows and the group subtotal of the stock table under line G.
8. Switch the active company to Mocha, reopen OI if it is still visible, and repeat step 3.
9. Switch back to Sorento. Make the window 375 px wide and repeat steps 3 and 6.

## Expected
- Step 4: one row, Location `MOCHA-WH`. On hand = N; SO qty, PO qty and SPO qty = the same
  figures Stock status shows for MOCHA-WH; Available = On hand - SO qty + SPO qty. No other Mocha
  location rows appear. Never "No stock position for this cell".
- Step 5: the documents list for MOCHA-WH opens: its open S/O lines, or "Nothing is claiming this
  stock". No error message.
- Step 7: exactly as before this change: every BB location (BRW-BB, MWH-BB, ...) with its own
  On hand, then a "BB group subtotal" row; the other-group rows below it as before.
- Step 8 (only if OI is visible with Mocha active): the MOCHA-WH row shows the same N; the table
  may also list other locations as "Other group" rows, as any same-company location read does.
- Step 9: the same figures as steps 4 and 7; the page itself does not scroll sideways (the stock
  table scrolls inside its own box, as it already did).
