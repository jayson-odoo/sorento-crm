# Hand test: customer asks as a salesperson's to-do (PR #1364, lane SALES-ASKS-TODO)

Built to the Lavish-approved mockup round 3 (`documentation/mockups/sales-asks-todo/index.html`).
Real rows: the to-do reads your dev DB's `stock_asks`; the conversation reads `chat_histories`.

## URL
crew test copy

## Setup
1. Run the lane migration on the shared dev DB (`alembic upgrade head` on the test copy, or the
   crew-migration SQL posted on the PR, which is everything `sat_0001_stock_ask_done` does: the
   three `stock_asks` columns with their FKs, the backfill, the five `sales.customer_asks.*` slugs,
   and the grants by explicit role list: `salesperson` gets view + edit; `director`,
   `project_sales_manager`, `project_sales_coordinator`, `customer_service`, `admin` and
   `superadmin` get all five including `view_all`).
2. Sign in to the CRM as yourself (superadmin, so you hold `view_all`).
3. Portal half: a contact linked to a sales agent (Sales Agents > Portal contact) with Contact page >
   Portal forms > "Customer asks" switched on; that agent handles at least one customer whose
   contacts asked the chatbot (your #1333 hand-test rows qualify; console asks count too).
4. Optional, team leader: Sales > Sales Teams, a team led by an agent linked to a CRM user you can
   sign in as, with one other member.
5. Salesperson half: a CRM user holding only the `salesperson` role whose WhatsApp contact (the
   user's Contact field) is a sales agent's Portal contact; that agent handles at least one
   customer with asks.

## Steps
1. CRM sidebar: Sales > Customer asks. Open the `Agent` select and pick an agent with asks.
2. Read the toolbar and the sections. Read one card.
3. Open `Sort` and pick `Customer`; then open it again and pick `Created`.
4. Click the card body (not the Done button) of the oldest ask.
5. In the sheet, click `Jump to message`.
6. Type "Called, wants 50 by Thursday" in Note and click `Save note`.
7. Click `Done` at the foot of the sheet.
8. Click `Reopen` on that card under Done today.
9. Click the list-view toggle (the left icon next to Sort).
10. Scroll the grid to its right edge; click `Done` on the first row, then `Reopen`.
11. Pick `All agents` in the Agent select while in list view.
12. Narrow the browser to phone width: scroll the cards; open a card; close it.
13. Portal: open the salesperson's portal, pick `Customer asks` in the tab selector.
14. Tap the first card; in the sheet tap `Jump to message`; type a note, tap `Save note`; tap `Done`.
15. Tap `Show done` at the foot.
16. Optional, as the team leader: Sales > Customer asks, open the Agent select, pick the other
    member, open one of their cards, click `Done`, then `Reopen`.
17. Sign out; sign in as the salesperson user (Setup 5). CRM sidebar: Sales > Customer asks.
    Click `Done` on one card, then `Reopen`.

## Expected
1. The select lists `All agents` first, then one line per agent with open asks ("SEAN I · 4 open · 2 need attention" style). Before picking, the page reads "Not linked to a sales agent" with the hint line (your user has no agent).
2. Toolbar: `Filter`, `Sort` (reading `Created`), the list / cards toggle; no New button, no counts line. Sections: `Needs attention` (red) then `Today` then `Done today`, no day sub-headings, no age labels. A card shows only: customer (bold) + contact, `Asked: CODE x Q`, `Answered: <the answer sentence, no "CODE x Q:" prefix>`, the datetime, and a blue `Done` top-right. No Sent / Not sent / Console / branch chip.
3. Cards inside each section re-order by customer, then back to oldest first; reload the page and re-pick the agent: `Sort` still reads the last choice (remembered per user).
4. A right-side sheet opens: customer, contact, asked at, agent code; the Asked / Answered block with `Jump to message`; `Conversation` with the WhatsApp messages around the ask (customer's messages left, the assistant's right, the answering message tagged `This ask`); `Show the whole day`; `Open in Conversations`; `Note` with `Save note`; `Done` at the foot.
5. The conversation scrolls to the tagged bubble and it flashes.
6. `Saved <time>` appears under the note; reopen the sheet later: the note is still there.
7. The sheet closes, the card fades out of its section and appears under `Done today`, greyed, reading "Done by <your name>, <time>" with `Reopen`.
8. The card returns to its section.
9. The DataGrid: columns Asked at, Customer, Contact, Asked, Answered, Done by and the action column LAST (`Done` / `Reopen`); the three sections are full-width rows in the same order; clicking a row (not the button) opens the same sheet.
10. Done moves the row under the Done today section row with your name in Done by; Reopen restores it.
11. An `Agent` column appears with each row's agent code; every agent's open rows are listed.
12. One column of cards, the Done button top-right, no sideways scroll; the sheet slides in and closes.
13. The tab body is the same to-do: toolbar, sections, cards; the kind badge shows the open count.
14. A bottom sheet with the same content (no `Open in Conversations`); the bubble flashes; `Saved <time>` appears; the sheet closes and the card lands under Done today reading "Done by <the contact's name>".
15. The done history grid opens under the to-do with a `Done by` column; the button reads `Hide done`.
16. The select lists only the team's current members (with counts, 0 allowed); the member's rows load; `Done` succeeds reading "Done by <leader's name>"; a member that left the team is not listed.
17. `Customer asks` is in the Sales menu for the salesperson; the page opens straight on their own to-do with NO Agent select and no `All agents`; `Done` and `Reopen` both succeed (the card reads "Done by <the salesperson's name>"). No permission error at any point.
