# Hand test: PR #2256 AGENT-BULK-W4-CONTACTS (pasted table edits contacts by phone)

A row = phone + any of: name, "sponsorship must name a registered project" (yes / no), Respond.io workspace (its
name or space id). The phone finds the contact (either `+601...` or `01...` form) and never changes. An unknown phone
is not found (nothing is created). A phone stored on two contacts is refused. A blank cell leaves its field as it is;
nothing is cleared. A name that differs only in spacing counts as the same name; capitals count (a case-only fix is a rename). Only users with Contacts
edit can do this. Nothing is sent to Respond.io.

## Setup
1. Sign in with your own login (Contacts edit, and Respond.io workspaces view for the workspace column).
2. Open Contacts from the top-bar apps menu (it is not in the sidebar; the sidebar's "Internal Users" is a different
   screen). Pick four dev contacts and note their phone, name and sponsorship switch (Edit Contact) so you can put
   them back afterwards: A, B (sponsorship switch off), C (any) and D (whose name you will retype with extra spaces
   between the words).
3. The dev DB has one Respond.io workspace and Edit Contact cannot clear a workspace, so this table changes no
   workspace; row 8 checks the workspace column with a name that does not exist.
4. Pick a phone nobody holds (e.g. 019-000 0000; check the contacts search finds nothing) = NOBODY.
5. The table (write A's phone in the `01x-xxx xxxx` form even if it is stored as `+601...`):

```

<A phone>      <A name> Sdn Bhd

<D phone>      <D  name  with  extra  spaces>

<A phone>      Second A Row

```
