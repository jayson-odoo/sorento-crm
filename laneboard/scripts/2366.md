# PR 2366 hand test: price tag request, tick several items from one search

## URL
crew test copy

## Setup
- No migration. Sign in as a salesperson who has Price Tag Request (admins create price tag requests from the staff pages, not this form).
- The catalogue has several products whose code contains `DIY` (for example `SRT6536-DIY`). Any shared prefix or suffix works; replace `DIY` below if the copy has none.

## Steps
1. From `/`, open Dealer Kit > Room Designer > Price Tag Requests in the sidebar and click Create.
2. Pick a customer, open the Price section (or the lines table), and on line 1 click "Search a set or product...".
3. Type `DIY`.
4. Tick the box on the left of three different results (do not click their text).
5. Look at the bottom of the list.
6. Click "Add 3".
7. Look at the lines table.
8. Click line 2's "Search a set or product..." and type `DIY` again.
9. Look at the three items you just added.
10. Click "Select all" at the top of the list, then press Esc.
11. Look at line 2.
12. Click line 2's picker again, type `DIY`, and click the TEXT of one result that is not yet added.
13. Click "+ Add line", open the new line's picker, type `D`.
14. Look at the top and the bottom of the list, then press Esc.
15. Click "+ Add line", open the new empty line's picker, type `DIY`, press the Down arrow twice, press Space, then press Ctrl+Enter (Cmd+Enter on a Mac).
16. Shrink the window to phone width (375 px) and repeat steps 2 to 6 on a new request.
17. Click Save Draft, then reopen the draft from the list.

## Expected
- Step 3: each result is one line showing only the product code (no name, no price); a set shows a grey "Set" hint.
- Step 4: the list stays open, `DIY` stays in the search box, and each ticked result shows a ticked box.
- Step 5: the bottom reads "3 ticked" with one blue "Add 3" button.
- Step 7: line 1 holds the first ticked item, and lines 2 and 3 hold the other two, in the order the list showed them. There is no empty line. Each line's Item shows the product's name (as when you pick one), Qty (tags) 1, empty remarks, and a product line its list price (a set line shows no list price, as today).
- Step 9: the items on lines 1 and 3 each show a grey ticked box and "Already added", and clicking its box does nothing.
- Step 10: "Select all N" ticks only the items not yet added (N counts those). After Esc the list closes.
- Step 11: line 2 is unchanged (Esc added nothing).
- Step 12: the list closes at once and line 2 now holds the clicked item (one click, as before).
- Step 14: the top reads "Select all N shown" and the bottom reads "More match. Type more of the code to see them." if more than 50 products (or 50 sets) contain `D`. A discontinued product shows a grey "Discontinued" and can still be ticked.
- Step 15: Space ticks the highlighted result without adding a space to the search. Ctrl+Enter puts the ticked item on that new line and closes the list.
- Step 16: the list fits the screen, "Add 3" stays visible at the bottom, and the page never scrolls sideways.
- Step 17: the reopened draft shows the same lines in the same order.
