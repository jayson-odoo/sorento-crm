## Reading tokens and calls (dev DB, read-only)

The owner's turns since the run started (set the user id and start time):

```sql
SELECT t.id, t.created_at, t.response->>'status' AS status, (t.response->>'rounds')::int AS rounds,
       left(t.envelope->>'text', 40) AS prompt,
       (SELECT count(*) FROM jsonb_array_elements(t.trace) e WHERE e->>'kind' = 'agent_round') AS calls,
       (SELECT sum((e->>'prompt_tokens')::int) FROM jsonb_array_elements(t.trace) e WHERE e->>'kind' = 'agent_round') AS prompt_tokens,
       (SELECT sum((e->>'completion_tokens')::int) FROM jsonb_array_elements(t.trace) e WHERE e->>'kind' = 'agent_round') AS completion_tokens,
       (SELECT string_agg(e->>'name' || ':' || coalesce(e->>'status', ''), ', ') FROM jsonb_array_elements(t.trace) e WHERE e->>'kind' = 'agent_tool') AS tools,
       (SELECT count(*) FROM chatbot.agent_actions a WHERE a.turn_id = t.id) AS actions
FROM chatbot.turns t
WHERE t.ingress = 'agent' AND t.envelope->>'user_id' = '<owner user id>' AND t.created_at >= '<run start>'
ORDER BY t.created_at;
```

`agent_round` entries are written per model call (`loop.py` `chat`, `trace.add("agent_round", ...)`): `calls` is
the model calls of the turn, the token sums are that turn's spend. The same numbers are in
`ai_assistant_usage_logs` (`chatbot_turn_id = t.id`). `actions` must be 0 for P1-P4 and 1 for P5 (status
`cancelled` after step 5).
