# Hand test #1421 (SO-TRANSFERABLE)

## URL
crew test copy

## Setup

1. Apply the migration: `ALTER TABLE public.sales_orders ADD COLUMN IF NOT EXISTS is_transferable BOOLEAN;` Sign in as an admin.
2. Until the ss lane (ss#106) pushes the flag, mark the owner's examples by hand on the test copy DB (company SRT):
   `UPDATE public.sales_orders SET is_transferable = false WHERE so_number IN ('SO421824','SO422024','SO422058');`
   `UPDATE public.sales_orders SET is_transferable = true WHERE so_number IN ('SO422049','SO422051');`
   Skip any number the copy does not hold.
3. Before running the UPDATE, note the item code of one line on SO422024, and that item's Stock Debt balance for the month the line is due in (sidebar Procurement > Supply Chain > Stock Debt, search the item code).

## Steps

1. From the sidebar open Project Sales Admin > Sales Orders.
2. Find the Transferable column on the list (scroll the table right if needed).
3. Open Filters, set Transferable = No, close the popover.
4. Click SO422024.
5. On the General tab, read the Transferable field in the Order card.
6. Gear (Sales order options) > Edit; read the Transferable field again; click Cancel.
7. Back to sales orders, clear the filter chip, then set Filters > Transferable = Not stated.
8. From the sidebar open Procurement > Supply Chain > Stock Debt, search the item code noted in setup 3, and open the month cell SO422024's line is due in.
9. Narrow the browser to phone width (375px) and repeat steps 2 and 5.

## Expected

1. Step 2: Transferable reads `No` (amber) for SO421824 / SO422024 / SO422058, `Yes` (green) for SO422049 / SO422051, `Not stated` (grey) for every other order.
2. Step 3: the chip reads `Transferable: No` and the list holds only the F orders.
3. Step 5: Transferable = `No`, with the muted words `From AutoCount` beside it (an AutoCount order).
4. Step 6: in Edit the field is the same read-only `No`; there is no input for it.
5. Step 7: only orders with no flag are listed (most of the book).
6. Step 8: SO422024's line is NOT in the cell drill's Demand table, and the month balance is less negative than the value noted in setup 3 by exactly SO422024's outstanding qty for that item.
7. Step 9: no horizontal page scroll; the table scrolls inside its card; the detail field wraps under its label.
