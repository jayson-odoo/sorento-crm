# Hand test: PR #2236 PRICETAG-DISCONTINUED-PICK (discontinued combo options stay selectable)

On the price tag request form, a discontinued option in a combo's choice group ("Not sure, any of N") can now be
picked. It still reads "Discontinued" so the requester knows. Approve no longer stops on a discontinued option picked
in a choice group. A discontinued FIXED part still stops Approve (unchanged, asked separately).

crew test copy

## Setup
1. Sign in as a staff user who can create price tag requests in Dealer Kit (the user from the 7 Nov screenshot).
2. Confirm on Master Data > Products that SRTWT5831-BL is marked Discontinued and that SRTKS7061-BL has the combo whose
   tap group lists SRTKT1633SS-BL, SRTKT1634SS-BL, SRTWT5830-BL, SRTWT5831-BL and SRTKT71SS-BL.

## Steps
1. From the sidebar, open Dealer Kit > Room Designer > Price Tag Requests and click the Add button.
2. Fill the header the way you did on 7 Nov (dealer, price type).
3. On line 1, pick item SRTKS7061-BL.
4. Pick the package that carries the tap group, and pick Template KS_1TAP_SP.
5. Open the "Not sure, any of 5" select under the line.
6. Look at the SRTWT5831-BL option.
7. Click SRTWT5831-BL.
8. Click Save Draft.
9. Reload the page.
10. Click Approve.

## Expected
- Step 6: SRTWT5831-BL RM 285 is listed with "Discontinued" under it, in normal (not greyed) text, and can be hovered
  like the other four.
- Step 7: the select now shows SRTWT5831-BL RM 285; no error on the line.
- Step 8: the draft saves (success toast, no error).
- Step 9: line 1 still shows SRTWT5831-BL in the tap select.
- Step 10: line 1 does NOT show "SRTWT5831-BL is discontinued." If nothing else is missing, Approve goes ahead as for
  any other pick. Any other message on the line (for example "No combo selling price.") is unrelated to this PR; note
  it if it appears.
