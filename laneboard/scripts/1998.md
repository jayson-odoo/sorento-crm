# Hand test: PR #1998 DO-EDIT-NO-AUTODATE (the DO edit form no longer stamps today on an undated DO)

Owner ruling 30 Oct (#1975): a DO with no readable document date is imported undated and stays out of
sales reports until a person types the real date. The edit form used to fill an empty date with
today, so opening and saving an undated DO quietly put a made-up date on it. FE only, no backend
change, no migration.

## URL
crew test copy

## Setup
1. The test copy runs on the latest dev restore. No migration.
2. Sign in as an admin (anyone who can edit delivery orders).
3. Pick an undated DO: `SELECT order_number FROM orders WHERE order_date IS NULL LIMIT 1;`. If none exists, take any non-AutoCount test DO and run `UPDATE orders SET order_date = NULL WHERE order_number = '<that number>';`. Call it DO-U.
4. Pick a second DO that has a date (any non-AutoCount DO with `order_date IS NOT NULL`). Call it DO-D and note its date.

## Steps
1. From the sidebar, open Delivery Orders > Delivery Orders.
2. Search for DO-U and open it.
3. Click Edit.
4. Read the "Delivery Order Date" field.
5. Narrow the browser to 375px wide, read the field again, then widen it back.
6. Change Debtor Name (add " X" at the end), then click "Update Delivery Order".
7. Open DO-U again and read its DO date.
8. Click Edit, type 15/10/2026 into "Delivery Order Date", then click "Update Delivery Order".
9. Open DO-U again and read its DO date.
10. Open DO-D, click Edit, clear "Delivery Order Date", then click "Update Delivery Order".
11. From the Delivery Orders list, click Add and read "Delivery Order Date".

## Expected
- Step 4: "Delivery Order Date" is empty (not today's date) and its label has no asterisk. "Estimated Delivery Date" is empty too if DO-U had none (it used to show today + 2).
- Step 5: still empty, nothing is clipped and there is no sideways scroll.
- Step 6: the save succeeds and Debtor Name shows the " X".
- Step 7: DO-U is still undated: no date shown, and today's date does not appear. `SELECT order_date FROM orders WHERE order_number = '<DO-U>';` returns NULL.
- Step 9: DO-U shows 15 Oct 2026.
- Step 10: the cleared field stays empty (it does not jump to today), the form shows "Order date is required." under it, nothing saves, and DO-D keeps its date.
- Step 11: the new-DO form still shows today's date, label "Delivery Order Date *".
