# Hand test: PR #1982 AGENTIC-P1 (read-only agent in the Chatbot Console)

A separate "Agent" mode in the Chatbot Console: you ask in plain words, the agent looks things up with
the CRM's own read tools (stock, incoming, orders, purchasing, the sales report, name and code lookup),
checks every figure it writes against what the tools returned, and says what it could not check. It
only reads. It answers as the contact's linked user and never shows more than today's bot would show
that contact. Today's bot (the "Bot" tab, WhatsApp) is unchanged.

## URL
crew test copy

## Setup
Crew prepares the copy. The owner runs no commands.

1. The copy runs the PR head with the agent migration applied and a Gemini key in the AI assistant
   settings.
2. Sign in to the CRM as the owner.
3. Pick one internal staff contact that has AI replies allowed and a linked active user (crew names
   it). Below it is "Contact S". Its Agent mode starts off.
4. Have one product code you know (for example one with stock and an incoming shipment) and a sales
   month you know the figures for.

## Steps
1. CRM sidebar: Users & Access > Settings. Open the `Chatbot Media` tab and find the `Agent budgets` card.
2. Type `99` in `Tool rounds`.
3. Set `Tool rounds` back to `8` and click `Save Settings`; refresh the page.
4. CRM sidebar: System > Messaging > Chatbot Console. Click the `Agent` tab and pick Contact S.
5. Send any message, for example `stock of <your code>`.
6. CRM sidebar: System > Messaging > Respond.io Contacts > Internal Users. Open Contact S and its `Chatbot` tab.
7. Switch on `Agent mode`; refresh the page.
8. Back in the Chatbot Console, `Agent` tab, Contact S. Send: `How much stock of <your code> do we have, and when is the next shipment coming?`
9. Wait for the reply and read the line under it.
10. Send the follow-up: `and how many did we sell of it last month?`
11. When the agent asks which sales basis, answer `invoiced`.
12. Send: `Sorento baby WC: what is in stock and when does more come in?`
13. Click `New conversation`.
14. Send: `and the month before?`
15. Click the `Bot` tab, send any message, then click the `Agent` tab again.
16. Open System > Messaging > Chat History, find the latest Contact S turns and open one agent turn.
17. Switch `Agent mode` off for Contact S (step 6 path) and send any message in the Agent tab.

## Expected
1. Four numbers: Tool rounds 8, Seconds per turn 45, Input tokens per turn 150000, Compact history above 40000.
2. The inline error `Enter a whole number between 1 and 30.` shows and `Save Settings` is disabled.
3. Saved; after the refresh Tool rounds still reads 8.
4. The Agent tab shows a contact picker and an empty conversation with a short hint, no button in it.
5. `Agent mode is off for this contact (Contact Details > Chatbot).` No reply is generated.
6. The Chatbot tab shows an `Agent mode` switch, off.
7. The switch is still on after the refresh.
8. A `Working...` bubble, then one reply giving the stock on hand and the next shipment's quantity and date. Every figure matches the Stock and Incoming screens for that product.
9. A muted line: `N rounds` and chips such as `Find names and codes: ok`, `Stock balance: ok`, `Incoming by product: ok`. No `(not verified)` next to a true figure.
10. The agent keeps the same product (it does not ask which product again).
11. The figure is labelled as invoiced and matches the Sales report for that product and month. It never presents one basis as "the" sales number without saying which.
12. The baby WC models with their stock and the next incoming quantity and date (the copy's data has one model with an incoming shipment). No "no upcoming shipments" when the Incoming screen shows one.
13. The conversation clears to the empty state.
14. The agent asks what you mean or which product: it does not remember the earlier product after a new conversation.
15. The Bot tab works exactly as before this PR.
16. The turn shows the agent's rounds and tool calls (names, status, time) in its trace.
17. `Agent mode is off for this contact (Contact Details > Chatbot).` again, no reply.
18. Nowhere on these screens is a UUID shown.
