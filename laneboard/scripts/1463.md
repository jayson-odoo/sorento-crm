# Hand test #1463 (CONTACT-BULK-ACCESS)

Nothing here sends a WhatsApp message or an email: copying access only changes CRM settings on the
test copy. No migration is needed.

## URL

crew test copy

## Setup

1. Pick R, your already-configured reference dealer contact (Owner/Director profile: access types
   Dealer and End user, cost visible, escalation off, packing list off).
2. Pick three dealer contacts T1, T2, T3 that are NOT configured yet (for example freshly synced
   ones with no access types). Note each one's linked customer code (or "none").
3. Optional, for step 9: pick a fourth contact T4 that already has exactly R's access.

## Steps

1. Sidebar > Users & Access > People > Internal Users.
2. Open the filter "Access differs from: any", search R's name, pick R.
3. Read the list, then click "Clear filters".
4. Tick T1, T2, T3 (and T4 if you have one) in the list.
5. In the bulk bar click "Copy access from contact (3)" (or (4)).
6. In "Copy access from", search R's name and pick R. Read the summary box.
7. Click "Preview changes". Read the counts and open each contact's row.
8. Click "Apply to N contacts" (N = the "will change" count).
9. Read the result: counts and each contact's row.
10. Click "Check who still differs".
11. Click "Clear filters". Set "Escalation: Escalation allowed" and "Cost: Cost visible" together.
12. Reload the page (browser refresh).
13. Open T1's contact page and read the Chatbot settings card, the Access tab (Field reveals,
    Access Agents) and the Customers section.

## Expected

1. Step 3: the list shows every contact whose access is not the same as R's; R itself is not in it;
   T1, T2, T3 are in it.
2. Step 6: the summary lists Access types "Dealer, End user", Tier, the five chatbot switches with
   "Packing list off" and "Escalation off", Field reveals "Last purchase cost", the agents R holds,
   and "Not copied: Linked customers, companies, CS routing, media limits, memory".
3. Step 7: T1, T2, T3 each say "Will change" with green "+ Dealer" / "+ End user", "+ Last purchase
   cost", Escalation struck "on" then "off". T4 (if used) says "No change". Nothing mentions customers.
4. Step 9: "N updated", every row green "Updated" (T4 "No change"); no spinner left anywhere.
5. Step 10: the list is filtered to "Access differs from: R" and T1, T2, T3 are no longer in it.
6. Steps 11-12: after the reload both filters are still set ("Escalation: Escalation allowed",
   "Cost: Cost visible") and the list is the same as before the reload; T1-T3 are not in it
   (their escalation is now off).
7. Step 13: T1 shows access types Dealer and End user, Tier Dealer, Escalation off, Packing list
   off, field reveal "Last purchase cost" ticked, the same agents as R, and the SAME linked
   customer as noted in setup step 2 (not R's customer).
