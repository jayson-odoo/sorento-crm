# Hand test: PR #2197 PROJECT-OUTCOME-SINGLE (one Won/Lost outcome per project)

A project has one outcome: Open, Won or Lost. Areas (scopes) no longer have their own. The gear
on the project page gets Mark won and Re-open; Mark lost asks for a reason and sets the project
Lost; Make quotation is offered on an Open or Won project (not Lost). No migration.

## URL
crew test copy

## Setup
- Signed in as a project sales user who can edit projects, window about 1280 px wide.
- Project A: approved, stage Registered, outcome Open, with one SENT proposal that has two areas
  and no quotation yet. (On the dev copy the Quoted / Tendering stages are not reachable without a
  requirements document, so the script uses Registered and Identified.)
- Project B: approved, stage Identified, outcome Open, no quotation.
- At least one loss reason exists in the project quotation loss-reason list (for example "Price").
- Note Project A's and B's numbers on Project Sales > Reports > Forecast (Pipeline) before step 1.

## Steps
1. From `/`, open the sidebar Project Sales > Projects and click Project A.
2. Open the gear menu.
3. Click Mark won.
4. Open Project Sales > Reports > Forecast.
5. Go back to Project A and open the gear menu.
6. Click Re-open.
7. Open the Proposals list on Project A and click the sent proposal.
8. Look at the area tabs above the lines, then open the actions (gear) menu.
9. Close the menu. Go to Project Sales > Projects and click Project B.
10. Open the gear menu and click Mark lost.
11. Without picking a reason, look at the Save button. Then pick "Price" and click Save.
12. Open the proposal list or the actions of any proposal on Project B (if it has one), else skip.
13. Open Project Sales > Reports > Forecast, then the Loss reasons part.
14. Go back to Project B, open the gear menu and click Re-open.
15. Narrow the window to about 375 px and repeat step 10 on Project B, then click Cancel.

## Expected
- Step 2: the menu lists Mark won and Mark lost (plus the usual items); no Re-open.
- Step 3: a toast; a green "Won" tag next to the stage pill; the stage pill still reads Registered.
- Step 4: Project A adds nothing to Pipeline any more (its earlier pipeline figure is gone).
- Step 5: the gear shows Re-open, and no Mark won.
- Step 6: the Won tag is gone; Mark won is back in the gear.
- Step 8: no Open/Won/Lost pill on the areas, no "Record outcome" anywhere on the page; the
  actions menu offers "Make quotation" (the project is Open).
- Step 10: a "Mark lost" dialog opens with a Reason picker; the stage has NOT moved yet.
- Step 11: Save is disabled until a reason is picked; after Save the stage pill reads Lost.
- Step 12: "Make quotation" is not offered on a Lost project.
- Step 13: Project B no longer counts in Pipeline; Loss reasons shows Price with 1 more than before.
- Step 14: the stage returns to Identified (the stage before Lost, not the initial Registered); the
  project is Open again; Mark won is back in the gear.
- Step 15: the dialog fits the screen with no sideways scroll; Reason, Cancel and Save are all
  visible and usable; Cancel closes it with no stage change.
