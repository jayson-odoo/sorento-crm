# Hand test: PR #2274 PRICETAG-UPGRADE-VARIANTS (upgrade items on combo tags, one tag per WC family)

Two things to try. (a) A combo tag shows its upgrade in an "UPGRADE" box read from the combo's own upgrade
part (product page > Combos), with a "TOPUP RM 150" you can drag anywhere. (b) One WC tag shows a trap icon
for every variant of the model, and you untick variants per request line.

"All variants" reads the product Family (product page > Variants tab, "Family"; owner ruling 9 Nov ~16:05).
On the dev copy family SRTWC8354 is SRTWC8354-SH, -SH-150, -SH-200, -SH-P, -SH-UF, -SH-UF-150, -SH-UF-200 and
-SH-UF-P, so nothing needs linking.

## Setup
1. Migration (crew has applied it): `ALTER TABLE price_tag_request_lines ADD COLUMN IF NOT EXISTS
   excluded_variant_ids JSONB NOT NULL DEFAULT '[]'::jsonb;`
2. Sign in with your own login. Master Data > Product Specifications > Trap outlet length > Choices and words:
   on 150, 200 and 250 click the Icons cell and pick (or upload) the 6", 8" and 10" S-trap icons. Leave 180 and
   300 empty. On "Trap": P trap gets the P-trap 180mm icon. On "Seat cover material": UF gets the UF seat cover icon.
3. Master Data > Products > SRTKS2432 > Combos > Add combo, name "UPGRADE TEST": add part SRTKT1862SS (Fixed
   part), add part SRTKT71SS and tick Upgrade, Top-up 150. List price (RM) 1150, Sell price (RM) 949.
4. Dealer Kit > Tag Templates > New tag template, name "UPGRADE TEST", 148 x 105 mm: add a Photo, a Code text
   (Field Code), a Price badge with Variant "Promotion (LP struck + SP)" (the default "List price only" prints
   RM 1,150 whatever is picked), then Accessories (toolbar) and set its List to Upgrades. Publish this template.
   It reads no combo position, so it fits any combo (do not use a "Combo ... 1 fixed part" template: it carries
   a choice-group layer and does not fit this combo).
5. Back on SRTKS2432 > Combos > UPGRADE TEST: Price tag templates, add "UPGRADE TEST".
6. Dealer Kit > Tag Templates > New tag template, name "WC FAMILY TEST", 148 x 105 mm: Photo, Code, Price badge,
   and a Feature icons layer with Product "All variants". Publish. On SRTWC8354-SH > Overview > Price tag
   templates, add "WC FAMILY TEST".

## Steps
1. Dealer Kit > Tag Templates > UPGRADE TEST, preview product SRTKS2432, combo UPGRADE TEST.
2. Select the Accessories box.
3. Double-click the box, drag the "TOPUP RM 150" element to the bottom right of the card, press Done, then Save.
4. Reload the page.
5. Add a text layer: Slot Binding "Upgrade top-up", Product "Upgrade 1". Place it above the price badge.
6. On that layer change Slot Binding to "SP with upgrade", then back to "Upgrade top-up".
7. Add a text layer: Slot Binding "Code", Product "Fixed part 1" (SRTKT1862SS). Publish this template.
8. Sign out. Sign in as a salesperson (crew's salesperson-a), not an admin (admins are told "Staff create
   requests from the staff pages.").
9. Price Tag Request > new request. Add a line SRTWC8354-SH with template WC FAMILY TEST, and look at the preview.
10. Open "Variants on this tag" and untick SRTWC8354-SH-P, then untick SRTWC8354-SH-UF-P.
11. Add a line SRTKS2432, combo UPGRADE TEST, template UPGRADE TEST, Price SP. Then pick the upgrade SRTKT71SS.
12. Save the request and reload the page.
13. Submit the request. Sign back in as yourself (staff), open the request from Dealer Kit > Price Tag Requests
    and open its Design view.
