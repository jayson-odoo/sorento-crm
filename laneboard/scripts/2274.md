# Hand test: PR #2274 PRICETAG-UPGRADE-VARIANTS (upgrade items on combo tags, one tag per WC family)

Two things to try. (a) A combo tag shows its upgrade in an "UPGRADE" box read from the combo's own upgrade
part (product page > Combos), with a "TOPUP RM 150" you can drag anywhere. (b) One WC tag shows a trap icon
for every variant of the model, and you untick variants per request line.

"All variants" reads the product's variant links (product page > Variants tab, "Variant of"). On the dev copy
almost no product has them (2 of 15,591), so Setup links the SRTWC8354-SH codes first. Whether it should read
the product Family instead is a separate question on the PR (crew-ask); this script tests the links.

## Setup
1. Migration (crew has applied it): `ALTER TABLE price_tag_request_lines ADD COLUMN IF NOT EXISTS
   excluded_variant_ids JSONB NOT NULL DEFAULT '[]'::jsonb;`
2. Link the WC variants (crew can run this instead of doing it by hand; it only sets the link and marks it manual
   so the auto-derivation keeps it):
   ```sql
   UPDATE products c SET variant_of_id = p.id, variant_link_manual = true
     FROM products p
    WHERE p.product_code = 'SRTWC8354-SH'
      AND c.product_code IN ('SRTWC8354-SH-150','SRTWC8354-SH-200','SRTWC8354-SH-P','SRTWC8354-SH-UF')
      AND c.company_id = p.company_id;
   UPDATE products c SET variant_of_id = p.id, variant_link_manual = true
     FROM products p
    WHERE p.product_code = 'SRTWC8354-SH-UF'
      AND c.product_code IN ('SRTWC8354-SH-UF-150','SRTWC8354-SH-UF-200','SRTWC8354-SH-UF-P')
      AND c.company_id = p.company_id;
   ```
   By hand instead: open each code above, Variants tab, "Set parent", pick SRTWC8354-SH (the -UF-xxx codes:
   SRTWC8354-SH-UF).
3. Sign in with your own login. Master Data > Product Specifications > Trap outlet length > Choices and words:
   on 150, 200 and 250 click the Icons cell and pick (or upload) the 6", 8" and 10" S-trap icons. Leave 180 and
   300 empty. On "Trap": P trap gets the P-trap 180mm icon. On "Seat cover material": UF gets the UF seat cover icon.
4. Master Data > Products > SRTKS2432 > Combos > Add combo, name "UPGRADE TEST": add part SRTKT1862SS (Fixed
   part), add part SRTKT71SS and tick Upgrade, Top-up 150. List price (RM) 1150, Sell price (RM) 949.
5. Dealer Kit > Tag Templates > New tag template, name "UPGRADE TEST", 148 x 105 mm: add a Photo, a Code text
   (Field Code), a Price badge, then Accessories (toolbar) and set its List to Upgrades. Publish this template.
   This template reads only the main product, so it fits any combo (do not use a "Combo ... 1 fixed part"
   template: it carries a choice-group layer and does not fit this combo).
6. Back on SRTKS2432 > Combos > UPGRADE TEST: Price tag templates, add "UPGRADE TEST".
7. Dealer Kit > Tag Templates > New tag template, name "WC FAMILY TEST", 148 x 105 mm: Photo, Code, Price badge,
   and a Feature icons layer with Product "All variants". Publish. On SRTWC8354-SH > Overview > Price tag
   templates, add "WC FAMILY TEST".

## Steps
1. Dealer Kit > Tag Templates > UPGRADE TEST, preview product SRTKS2432, combo UPGRADE TEST.
2. Select the Accessories box.
3. Double-click the box, drag the "TOPUP RM 150" element to the bottom right of the card, press Done, then Save.
4. Reload the page.
5. Add a text layer: Slot Binding "Upgrade top-up", Product "Upgrade 1". Place it above the price badge.
6. On that layer change Slot Binding to "SP with upgrade", then back to "Upgrade top-up".
7. Open WC FAMILY TEST, preview SRTWC8354-SH.
8. Sign out. Sign in as a salesperson (crew's salesperson-a), not an admin (admins are told "Staff create
   requests from the staff pages.").
9. My Requests > Price tag > new request. Add a line SRTWC8354-SH with template WC FAMILY TEST.
10. Open "Variants on this tag" and untick SRTWC8354-SH-P, then untick SRTWC8354-SH-UF-P.
11. Add a line SRTKS2432, combo UPGRADE TEST, template UPGRADE TEST, Price SP. Then pick the upgrade SRTKT71SS.

  the SRTKT71SS picture, "TOPUP RM 150", "SRTKT71SS", its description, "LP: RM 440" and SRTKT71SS's own feature
  icons (only if its spec values carry icons).
- Step 4: the top-up is still at the bottom right of the card.
- Step 5: the layer prints "TOPUP RM 150" and the inspector says the template now needs 1 upgrade.
- Step 6: "SP with upgrade RM 1,099", then "TOPUP RM 150" again (never "SP with upgrade RM 150").
- Step 7: icons 6" S-trap 150mm, 8" S-trap 200mm, 10" S-trap 250mm, P-trap 180mm, UF seat cover, once each;
  the canvas and the request preview show the same icons.
- Step 9: "8 of 8 ticked", SRTWC8354-SH ticked and locked. If the members' list prices differ, the line reads
  "Variants price differently: RM x to RM y" (lowest and highest list price of the ticked members).
- Step 10: "7 of 8 ticked", the P-trap icon stays (SRTWC8354-SH-UF-P is still a P-trap); then "6 of 8 ticked" and the
  P-trap 180mm icon leaves the preview (no ticked member is a P-trap any more).
- Step 11: before the pick the preview shows SP RM 949 and the UPGRADE box; after picking SRTKT71SS the price is
  SP RM 1,099 and the UPGRADE box is gone.
- Old tags and templates print exactly as before.
