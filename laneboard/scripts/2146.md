# Hand test: PR #2146 OI-EXPORT-SHARED (one OI exporter: S/O then delivery date, header row first)

Every Order Inquiry Excel and PDF now comes from one exporter with two layouts (owner answer
(b), 3 Nov 22:50): the list page's own export (Lines Excel/PDF, and an OI's own Export Excel)
keeps its full layout; the handover attachment, the per-project download and the reserve email
use the eight columns SO DATE, S/O NO, ITEM CODE, QTY, DELIVERY DATE, PROJECT/CUSTOMER, LOCATION,
REMARK. Both are header row first (no ORDER INQUIRY title row) and sorted by S/O, then delivery
date earliest to latest within each S/O. The handover email's line table and the reserve email's
table follow the same order, so email, preview and attachment tally.

crew test copy

## Setup
- Signed in as Teh Jayson (admin), one browser tab.
- No migration. The copy is a prod copy: pick any S/O on the Order Inquiries Lines list that
  has two or more lines with different delivery dates (call it SO1), plus at least one other
  S/O (SO2). Steps 1 to 6 only read; step 7 sends one handover email from the copy (it goes
  to the copy's outbox, never to purchasing).

## Steps
1. From `/`, open Procurement > Supply Chain > Order Inquiries from the sidebar, then press "Lines".
2. Search SO1's number, then clear the search so the list shows SO1 and other S/Os.
3. Press the toolbar's "Export Excel" and open the file from My Downloads.
4. Press the toolbar's "Print / Download PDF" and open the file from My Downloads.
5. Press "Documents", open an OI that holds SO1, press the gear at the top right, choose Export Excel, and open the file.
6. Open a project that has order inquiry lines, open its Order Inquiry tab, press "Export Excel", and open the file.
7. On SO1's fulfilment board, Confirm a change to one line, open the handover email under System > Messaging > Outgoing Mails > Email Outbox and open its attached OI Excel.

## Expected
- Steps 3 to 7: row 1 of the sheet is the column header. There is no ORDER INQUIRY title row; the sheet tab is named ORDER INQUIRY.
- Steps 3 and 5 (full layout): the header is SO DATE, S/O NO, ITEM CODE, QTY, REQUESTED RESERVE, RESERVED, TOTAL QTY, DELIVERY DATE, PROJECT/CUSTOMER, SUPPLIER, PO NO, LOCATION, ACKNOWLEDGED, TAKEN, REMAINING, SUGGESTED, CHANGE QUANTITY, CHANGE DATE, REMARK. TOTAL QTY shows only on the last of two or more rows next to each other with the same SUPPLIER and ITEM CODE, and is their total.
- Steps 6 and 7 (eight columns): the header is SO DATE, S/O NO, ITEM CODE, QTY, DELIVERY DATE, PROJECT/CUSTOMER, LOCATION, REMARK, nothing else; step 7 adds NEW ITEM CODE / QTY CHANGE TO / DELIVERY DATE CHANGE TO only when a line in that email changed.
- Steps 3 to 7: S/O NO runs in order (all of SO1's lines together, then the next S/O); within each S/O, DELIVERY DATE runs earliest to latest; a line with no date sits last within its S/O.
- Step 4: the PDF is one table with the same header row and the same rows in the same order as step 3's Excel; no title above the table.
- Step 7: the attachment's rows are the email's line table rows, in the same order (S/O, then delivery date).
- Not changed: which rows each export holds, the filters, the file names.
