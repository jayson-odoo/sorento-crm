# Hand test #1431 (STOCK-TOTAL-OS-SCOPE)

## URL
crew test copy

## Setup

1. Pick a test contact that has its Respond.io `space_id` and both field reveals, `inventory.sellable` and `purchase_orders.placed`. Give it a `compact` stock-visibility policy. BRW-IB must be visible to it (on dev, MWC7624-RL-S10 has open SO1 on BRW-IB, SO414050, and no stock row there). BRW-NTC must be outside the policy. Note whether `hide_zero_locations` is on.
2. Note the product's open SO per warehouse:
   `select w.warehouse_code, sum(l.qty_ordered - l.qty_delivered) from sales_order_lines l left join warehouses w on w.id = l.warehouse_id where l.product_id in (select id from products where product_code = 'MWC7624-RL-S10') and l.line_status = 'open' and l.qty_ordered > l.qty_delivered group by 1;`
3. Pick product B. It needs zero stock, no incoming, and an open PO line or an unshipped SPO allocation on BRW-NTC.

## Steps

1. Open the chatbot console on the test copy.
2. As the test contact, ask "stock for MWC7624-RL-S10".
3. Read the stock block in the reply.
4. Add up the O/S on every warehouse line.
5. Ask "stock for MWC7624-RL-S10 at BRW-BB".
6. Ask "stock for <product B>".
7. Read the on-order note under the zero-stock sentence.
8. Remove the contact's `inventory.sellable` reveal.
9. Ask "stock for MWC7624-RL-S10" again.

## Expected

1. Step 3: the reply reads `Total: 372 (O/S: 531)`. Lines are in code order, and `BRW-BB: ... (O/S: 530)` and `BRW-IB: 0 (O/S: 1)` are among them. BRW-IB is printed even though it has no stock. There is no `Unassigned O/S` line. No hidden warehouse's open SO appears anywhere, and neither does any open SO with no warehouse.
2. Step 4: the line O/S values sum to exactly the Total's O/S, which is 531.
3. Step 5: Total O/S equals BRW-BB's O/S (530) only, and BRW-IB is not listed.
4. Step 7: the on-order rows still show Product Code, Ordered, Outstanding and PO date. There is NO `Location:` line, and `BRW-NTC` appears nowhere in the reply.
5. Step 9: a plain `Total: 372` with the location lines and no O/S anywhere. BRW-IB's `0` line may still be listed, because a line is printed for any visible warehouse with open SO.
