## Setup
- No migration: this lane changes no table.
- Sign in as an admin (the Town is admin-only).
- Crew (not the owner) builds today's Town snapshot once on the test copy after 07:00 Malaysia time (the copy runs with the scheduler off; the tick refuses outside 07:00 to 22:05):
  `cd sorento_crm_backend && venv/bin/python -c "from app.services.town.snapshot import run_town_snapshot_tick; print(run_town_snapshot_tick())"`
- Dev data note: the copy's invoices end before today, so today's Town reads RM 0 with nothing lit. So the owner sees real figures, crew then serves each company's latest full day as today (Redis only; the database is only read). Run it from `sorento_crm_backend` with the copy's env:
  ```
  venv/bin/python - <<'PY'
  from datetime import datetime, time, timedelta, timezone
  import sqlalchemy as sa
  from app.main import app  # noqa: F401
  from app.database import SessionLocal
  from app.models.base import set_company_scope
  from app.models.company import Company
  from app.models.finance import BillingDocument
  from app.services.queue_service import redis_conn
  from app.services.town import snapshot as town
  MYT = timezone(timedelta(hours=8))
  today = datetime.now(MYT).date()
  with SessionLocal() as db:
      set_company_scope(db, None)
      for (cid,) in db.query(Company.id).filter(Company.is_active.is_(True)).all():
          cid = str(cid)
          day = db.execute(sa.select(sa.func.max(BillingDocument.doc_date)).where(
              BillingDocument.company_id == cid, BillingDocument.doc_date < today)).scalar()
          if day is None:
              print(cid, 'no invoices before today, skipped'); continue
          full = town.build_snapshot(db, cid, day, now=datetime.combine(day, time(15), MYT))
          full['day'] = today.isoformat()
          town.store(redis_conn, cid, today, full)
          print(cid, 'serves', day.isoformat(), 'as', today.isoformat())
      db.rollback()
  PY
  ```
  It prints one line per company, e.g. "<company id> serves 2026-11-11 as 2026-11-12". The next scheduled tick (when the scheduler runs) replaces it with the real today. The dev trading-house links have no linked customer, so no tower stands on the copy.
- Optional, for a project site with dates: open any open project and set its Launch date and Expected delivery (from) in the sales profile, and its State; for a trading house: link a party in role Trading house that is tied to a customer which has a Project-type invoice today. Then rebuild the snapshot (command above).

## Steps
1. From `/`, click Town in the sidebar.
2. Look at the default view without touching anything.
3. Look at the sales card on the right ("How much did we sell today?").
4. Hover a lit (amber roof) shop on the Selangor island, then hover a slate-blue glass tower and a project site (a plot, frame with a crane, or building with a small flag).
5. Click a project site.
6. Close it, then click a glass tower.
7. Close it. In the row of state names under the map, click Johor.
8. Click the map icon button (Whole map) at the bottom right of the map.
9. Click Reset view (the round arrow).
10. Click the sign that reads "+N more projects" or "+N dormant" near the Selangor island (if your data has more than 30 open projects or any dormant one).
11. Click Wallboard at the top right.
12. Click Exit wallboard.
13. Shrink the browser to phone width (375 px) and scroll the Town page.
