# Hand test: PR #2106 QUOTE-SIGN-COLUMNS (customer sign page shows the quotation's columns, photo included)

Owner report, 2 Nov: the customer's countersign link showed no product photo column, while the
quotation did. The sign page now reads its columns from the same definition as the PDF, so it shows
the same columns, in the same order, with the same headings, including PRODUCT IMAGE and the
drawing under TECHNICAL SPEC.

## URL
crew test copy

## Setup
Any issued project quotation whose lines carry a product photo, with a sign link: the
`Copy link` button in the WhatsApp dialog that opens after `Send to Customer R{n}` > WhatsApp. Ideally one with two sections where only one section has a photo.
Open the sign link in a private window (not signed in).

## Steps
1. On the quotation in the CRM, click `Download PDF` and open it.
2. Open the sign link in a private browser window.
3. Open each section row on the sign page.
4. Compare each section's table headings with the same section in the PDF.
5. Look at a line that has a photo in the PDF.
6. Compare that line's QTY with the PDF.
7. Resize the window to phone width (375 px) or open the link on a phone.
8. Scroll one section's table sideways to its last column.

## Expected
1. The PDF opens; a section with a photo has the headings ITEM, PRODUCT IMAGE, TECHNICAL SPEC, DESCRIPTION, BRAND, PRODUCT CODE, QTY, UNIT RATE (RM), COMPLETE SET, GRAND TOTAL.
2. The sign page opens with no login prompt.
3. Each section opens to its table.
4. Every section shows exactly the PDF's headings for that section, in the same order; a section with no photo on any line has no PRODUCT IMAGE column, in both.
5. The photo shows under PRODUCT IMAGE and the drawing (if any) under TECHNICAL SPEC, the same pictures as the PDF.
6. QTY reads the same as the PDF, unit included (for example `4 NO`).
7. The page itself does not scroll sideways.
8. The table scrolls inside its card and reaches GRAND TOTAL; no column is missing.
