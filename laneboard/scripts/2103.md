# Hand test: PR #2103 PS-SPEC-SHEET (project spec sheet from templates)

A quotation now has a Spec sheet tab: a cover page plus one page per quoted item, drawn by two new
tag template families (Spec sheet cover / Spec sheet page) and exported as one PDF. A price prints only where the template places one (owner Q-B).
Dev data is thin (crew: 13 / 7 quotation lines on the dev DBs), so the test builds a small case.

## URL
crew test copy

## Setup
1. Migration `pss_0001_spec_sheet` applied (one JSONB column, see the crew-migration comment).
2. Worker running (the PDF renders on the `catalogue_render` queue).
3. A project with a quotation that has been issued at least once (R1), whose lines include one
   product set line (a WC set: pan + angle valve + hose) and two plain product lines (a basin and a
   bottle trap). Sign in as a user who can edit project quotations and Dealer Kit tag templates.

## Steps
1. Open Dealer Kit > Tag Templates and click New Template.
2. Name it `Catalogue cover`, Family `Spec sheet cover`, Width 338.7, Height 190.5, create it.
3. Add a text layer, Insert field, pick `Project title` from the Spec sheet group, Publish.
4. Create another template `Item with accessories`, Family `Spec sheet page`, 338.7 x 190.5.
5. Add an image layer bound to `Product Image`, an image layer bound to `Drawing`, a text layer with `{{product.brand}} {{product.code}} {{line.marker}}`, a text layer with `AREA : {{line.area}}` and `REF : {{doc.ref}}`.
6. Add a text layer `{{product.code}}`, set its Product to `Accessory 1` and Show only when `Accessory 1 exists`. Add another for `Accessory 2` the same way. Publish.
7. Open Project Sales, the project, the Quotation tab, the issued quotation, then the `Spec sheet` tab.
8. Pick `Catalogue cover` as Cover template and `Item with accessories` as Page template.
9. On the WC row, click Area, type `unit & podium facilities` in its search box and pick `Use "UNIT & PODIUM FACILITIES"`; type Marker `*` and click outside.
10. On the basin row, open Accessories and pick the bottle trap.
11. Switch Print off on any remaining row you do not want, then drag the basin row above the WC row.
12. Page through the Preview with the arrows.
13. Click Export PDF, then open My Downloads and open `spec-sheet-<quotation no>.pdf`.
14. Open Dealer Kit > Price Tag Requests, open any request's design, and open its template picker.

## Expected
1. The New Template dialog opens.
2. The template is created; its family shows as `Spec sheet cover` in the list.
3. The Insert field dialog shows a `Spec sheet` group; on the canvas the layer shows `{{doc.project_title}}`; Publish succeeds.
4. The page template is created with family `Spec sheet page`.
5. The Slot Binding list offers `Drawing` right after `Product Image`.
6. The Product picker offers `Main item`, `Accessory 1`, `Accessory 2`, `Accessory 3`; the `Show only when` section is there.
7. The Spec sheet tab is the last tab, after Signatures, and lists one row per item (the WC row shows `With <valve code>, <hose code>`).
8. The pickers keep the choices after a reload; Export PDF turns on.
9. The WC row shows Area `UNIT & PODIUM FACILITIES` and Marker `*` after a reload.
10. The bottle trap row disappears; the basin row keeps its page.
11. The page numbers count only printed rows (cover = page 1); the new order sticks after a reload.
12. Page 1 shows the project title; each item page shows brand, code, marker, photo, drawing, area and ref; the WC page shows two accessory codes, the basin page shows the bottle trap as accessory 1 and no second accessory text.
13. A toast says `Preparing the spec sheet. It will appear in My Downloads.`; the PDF has the same pages as the preview at 338.7 x 190.5 mm (16:9 landscape); no price shows, because these templates place no price.
14. Neither spec sheet template is offered as a price tag template.
