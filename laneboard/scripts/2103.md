# Hand test: PR #2103 PS-SPEC-SHEET (project spec sheet from templates)

A quotation now has a Spec sheet tab: a cover page plus one page per quoted item, drawn by two new
tag template families (Spec sheet cover / Spec sheet page) and exported as one PDF. A price prints only where the template places one (owner Q-B).
Dev data is thin (crew: 13 / 7 quotation lines on the dev DBs), so the test builds a small case.

## URL
crew test copy

## Setup
1. Migration `pss_0001_spec_sheet` applied (one JSONB column, see the crew-migration comment).
2. Worker running (the PDF renders on the `catalogue_render` queue).
3. Use PRJQ-2026-0027 on project PRJ-000002 (crew created it and issued R1). Its lines: the WC set
   SRTWC6405 (pan SRTWCX6405 + tank SRTWCY6405 + seat cover SRTWC6405-SC) under the Section heading
   `UNIT`, basin SRTWB1413-GY, bottle trap SRTKSBT001 and floor trap SRTFT205. Its spec sheet
   settings start empty. Sign in as a user who can edit project quotations and Dealer Kit tag
   templates.

## Steps
1. Open Dealer Kit > Tag Templates and click New Template.
2. Name it `Catalogue cover`, Family `Spec sheet cover`, Width 338.7, Height 190.5, create it.
3. Add a text layer, Insert field, pick `Project title` from the Spec sheet group, Publish.
4. Create another template `Item with accessories`, Family `Spec sheet page`, 338.7 x 190.5.
5. Add an image layer bound to `Product Image`, an image layer bound to `Drawing`, a text layer `{{product.brand}} {{product.code}} {{line.marker}}`, a text layer `AREA : {{line.area}}`, a text layer `COMMENT : {{line.comment}}` and a text layer `REF : {{doc.ref}}`.
6. Add a text layer `{{product.code}}`, set its Product to `Accessory 1` and Show only when `Accessory 1 exists`. Add another for `Accessory 2` the same way. Publish.
7. Open Project Sales, the project, the Quotation tab, the issued quotation, then the `Spec sheet` tab.
8. Pick `Catalogue cover` as Cover template and `Item with accessories` as Page template.
9. In the page strip, click the WC thumbnail.
10. On the open page, click AREA, type `unit & podium facilities`, press Enter.
11. Click COMMENT on the page, type `Soft close seat`, press Enter.
12. Click the basin thumbnail, open Add accessory and pick the bottle trap.
13. Click the floor trap (or any other) thumbnail and click Leave out.
14. Drag the basin thumbnail in front of the WC thumbnail. Reload the page.
15. Click Export PDF, then open My Downloads and open `spec-sheet-PRJQ-2026-0027-R1.pdf`.
16. Open Dealer Kit > Price Tag Requests, open any request's design, and open its template picker.

## Expected
1. The New Template dialog opens.
2. The template is created; its family shows as `Spec sheet cover` in the list.
3. The Insert field dialog shows a `Spec sheet` group; on the canvas the layer shows `{{doc.project_title}}`; Publish succeeds.
4. The page template is created with family `Spec sheet page`.
5. The Slot Binding list offers `Drawing` right after `Product Image`.
6. The Product picker offers `Main item`, `Accessory 1`, `Accessory 2`, `Accessory 3`; the `Show only when` section is there.
7. The Spec sheet tab is the last tab, after Signatures. There is no table; a strip shows `1 Cover` and one thumbnail per item.
8. The pickers keep the choices after a reload; Export PDF turns on.
9. `Page 2: SRTWCX6405` opens large, as it prints, with `AREA : UNIT` (the Section heading) and two accessory codes (SRTWCY6405, SRTWC6405-SC).
10. The page now prints `AREA : UNIT & PODIUM FACILITIES`.
11. The page prints `COMMENT : Soft close seat`.
12. The bottle trap thumbnail leaves the strip; the basin page shows the trap as accessory 1 and no second accessory.
13. That page shows `Left out of the spec sheet` with Put back; its thumbnail shows `Left out` and `-`; the other numbers close up.
14. After the reload the basin is page 2 and the WC page 3; AREA, COMMENT and Left out are as set.
15. A toast says `Preparing the spec sheet. It will appear in My Downloads.`; the PDF has the same pages as the strip (cover, then the printed pages in strip order) at 338.7 x 190.5 mm (16:9 landscape); no price shows, because these templates place no price.
16. Neither spec sheet template is offered as a price tag template.
