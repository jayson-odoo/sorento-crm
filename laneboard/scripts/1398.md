# Hand test #1398 (STOCK-DEBT-LENDABLE)

## URL
crew test copy

## Setup

1. Sign in as a user who can open Supply Chain > Project Demand > Stock Debt.
2. Shared dev DB, product SRTSS8710, book Project. Before the change: SO381065 (due 29/03/2027) reads Pinned 88 "On hand BRW-BB"; SO396071 (due 01/09/2026) reads Short 32; Sep 26 cell -76, Oct -29, Dec -207.
3. Note SRTSS8710's lead time (Product > Suppliers, standard lead time; 90 days when none is stated). SO381065's due date must be on or after today + lead + 14 days for the lend to apply; on 30 Sep 2026 with a 90-day lead that is 12 Jan 2027, so 29/03/2027 qualifies.

## Steps

1. From the sidebar open Supply Chain > Project Demand > Stock Debt, set Book to Project, search `SRTSS8710`.
2. Read the Sep 26, Oct 26, Dec 26 and Mar 27 cells of the row.
3. Click the Sep 26 cell. Read SO396071's row on the Demand tab (Status, Assigned, Covered by).
4. Close it. Click the Mar 27 cell. Read SO381065's row (Status, Assigned, Covered by).
5. Set Due to (date range end) to 31/12/2026. Read the Sep 26 cell and SO396071's row again. Clear the date.
6. Read-only check that the view wrote nothing, run against the shared dev DB:

```sql
SELECT count(*) FROM projects.so_supply_decisions d
JOIN projects.sales_orders p ON p.id = d.project_sales_order_id
JOIN sales_orders so ON so.id = p.so_id
WHERE so.so_number IN ('SO381065', 'SO396071') AND d.confirmed_at > now() - interval '1 hour';
```

## Expected

1. One row, SRTSS8710.
2. Sep 26 improves by the lent quantity: -76 becomes -44 (32 lent to SO396071). Oct 26 improves by up to 29, Dec 26 by whatever of the 88 is left, and Mar 27 reads the lent total as a negative amber cell (for example -88 when all 88 went out). Exact figures depend on which nearer BRW-BB lines are short on the day.
3. SO396071: Status `covered`, Assigned 32, Covered by `On hand BRW-BB (from SO381065)`.
4. SO381065: Status `order back N` (violet pill) where N is the lent total; Assigned = 88 - N; Covered by lists `Lent to SO396071 (32)` and the other receivers with their quantities. If N is 88 the Assigned column reads 0.
5. Sep 26 reads the same -44 and SO396071 the same `covered` 32 with the date range set (the lender's row is hidden by the range, so Covered by reads `On hand BRW-BB` without the name). Nothing else moves.
6. The count is 0: opening the cells and reading the lend changed no decision and raised no order inquiry row. The dialog has no Rebalance button.
