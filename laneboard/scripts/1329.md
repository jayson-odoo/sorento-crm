# Hand test: PR #1329, chatbot ETA policy (lane ETA-POLICY)

Every chatbot turn below runs in the Chatbot Console, which is a dry run (`is_test`): nothing is
sent over WhatsApp or email. Do not use Respond Outbox, Email Outbox or any "send" button.

## URL

crew test copy

## Setup

1. The test copy's DB needs the new column (crew-migration on the PR):
   `ALTER TABLE respond_contacts ADD COLUMN IF NOT EXISTS chatbot_eta_offset_applied BOOLEAN NOT NULL DEFAULT true;`
2. Pick product P with at least one still-incoming shipment line. Suggested: SRTWC286-SH-NEW (the
   product from the 28 Sep hand test). Note its exact shipment ETA E from Incoming Stock.
3. Sidebar > Products > P > Edit: set "ETA offset (days)" to 7, save. Call E+7 the
   padded ETA.
4. Pick contact D (dealer): a Respond contact whose access type is availability only (the stock ask
   answers "available / not available", no numbers), linked to a customer that has a sales agent.
   Note the sales agent's name S.
5. Pick contact N (non-dealer): a Respond contact with the full incoming view (not availability only).
6. On both D and N: the contact's page (Users & Access, Contacts) > Access tab > Chatbot card: "ETA buffer days" is
   ON (default) and "Packing list allowed" is ON.
7. Users & Access > Access > AI Agents > the agent that answers N: in the Incoming Stock Enquiries
   field list, "Container number" and "Quantity" are both allowed (default).

## Steps

1. Sidebar > Chatbot Console. Contact = N. Send "incoming P".
2. Reset the conversation. Contact = N. Send "check stock P".
3. Open N's contact page > Access > Chatbot card, switch "ETA buffer days" OFF.
4. Chatbot Console, reset, contact N, send "incoming P".
5. Chatbot Console, reset, contact N, send "check stock P".
6. Switch N's "ETA buffer days" back ON.
7. AI Agents > N's agent > Incoming Stock Enquiries: deny "Container number" and "Quantity", save.
8. Chatbot Console, reset, contact N, send "incoming P".
9. AI Agents > N's agent > "Fields for N": set Container number and Quantity to allowed for N only, save.
10. Chatbot Console, reset, contact N, send "incoming P".
11. Remove the per-contact exception from step 9 and allow both fields on the agent again.
12. N's contact page > Chatbot card: switch "Packing list allowed" OFF. Console, reset, contact N,
    send "incoming P". Then switch "Packing list allowed" back ON.
13. Chatbot Console, reset, contact D, send "incoming P".
14. Chatbot Console, reset, contact D, send "incoming ZZZNOTAPRODUCT999".
15. Chatbot Console, reset, contact D, send "check stock P".
16. Chatbot Console, reset, contact D, send "incoming" plus a partial code that matches several
    products including P (for SRTWC286-SH-NEW: "incoming SRTWC286"), so a product list comes back.
17. Clean up: set P's "ETA offset (days)" back to its original value.

## Expected

1. N incoming P: ETA shown is E+7 (not E). Container number and quantity are shown. The packing list
   is attached.
2. N stock P: any ETA in the reply is E+7, the same date as step 1.
3. Switch saves with no error; the card shows "ETA buffer days" OFF after a reload.
4. N incoming P: ETA shown is exactly E.
5. N stock P: any ETA in the reply is exactly E.
6. Switch reads ON after a reload.
7. Save succeeds; both fields show as denied on the agent.
8. N incoming P: ETA still shown (E+7); no container number and no quantity anywhere in the reply
   (not shown as blank or "null", simply absent).
9. The "Fields for N" dialog lists "Container number" and "Quantity"; save succeeds.
10. N incoming P: container number and quantity are back.
11. Both fields allowed on the agent, no per-contact exception left.
12. N incoming P with packing list OFF: no packing list attachment on the reply; everything else as
    in step 1. After switching back ON the card reads ON.
13. D incoming P: one message, no intro line, no numbering. The code P once, then "ETA: " with its
    distinct ETAs sorted, each padded (E+7). No container number, no quantity, no allocation, no
    packing list. Last line: "Please refer to your salesperson, S." (or "Please refer to your
    salesperson." if D's customer has no sales agent).
14. D incoming miss: referred to the salesperson. It does NOT read "No incoming, no stock and nothing
    on order" and does NOT offer the purchasing team.
15. D stock P: the availability answer ("How many units of P?" or one availability sentence per
    product). It never lists incoming lines with container or quantity.
16. D partial code: in the product list, P (and any other listed product with a still-incoming
    line) is NOT marked "no incoming"; picking P replies exactly as in step 13.
17. P's offset is back to its original value.
