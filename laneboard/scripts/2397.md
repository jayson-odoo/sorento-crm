# PR 2397 hand test: certificate miss for a described set reads "Couldn't find ..." again (#2370 regression)

Since #2370, asking which products of a kind (for example "bidet") have a certificate, when none of them do, got
"Here's what you want: product: <code> (+2 more) / But no cert matched these ...". Before #2370, and again on this
branch, the bot says it plainly: "Couldn't find ..." with "certificate" in the sentence, and it names the products it
looked at. Two more fixes ride along: a product hidden from the chat is never offered as "Did you mean", and a bare
number inside exactly one code reads "Couldn't find 9031. Did you mean <that code>?".

The chatbot has no screen, so this is the console check (documentation/agents/chatbot-verification.md), run against
the test copy's backend. Every turn is a dry run: nothing reaches WhatsApp.

## URL
crew test copy (backend of the copy; the console script posts to it)

## Setup
1. The test copy runs this branch's backend on the dev copy of prod data, migrated to head (no migration in this PR).
2. Pick a test contact whose Agent switch is OFF (chatbot-verification.md "Console turns are routed").
3. Pick a product kind on dev where EVERY matching product has NO certificate linked (the shape is three or more
   products whose names share one class word, such as "bidet"). Crew: if "bidet" has a certified product on dev, use
   another class word that has none and write it in place of "bidet" below.
4. Pick a product hidden from the chat (not chat-searchable) whose code contains a number that no visible product's
   code contains, for step 3.
5. From `sorento_crm_backend/`, each step is one command:
   `venv/bin/python scripts/chatbot_console_check.py --say "<text>" --contact <test contact> --base-url <copy backend>`

## Steps
1. Send `which sorento bidet has cert`.
2. Send `9031 got stock?` (or, if dev has no SRTKT9031-GM, a number that appears inside exactly ONE visible product code).
3. Send `<the number from Setup 4> stock?`.
4. Send `wich bidet got certificat` (typo variant of step 1).
5. Send `bidet mana ada sijil?` (Malay variant of step 1).

## Expected
- Step 1: the reply starts with "Couldn't find", contains the word "certificate", and names the bidet products it
  looked at, by code. It ends with a "Did you mean" or an offer to escalate to the marketing product team. It does NOT
  start with "Here's what you want:" and does NOT read "But no cert matched these".
- Step 2: "Couldn't find 9031. Did you mean SRTKT9031-GM?" (or the same sentence with your number and its one code).
- Step 3: the hidden product's code never appears in the reply or its options. The reply is a plain miss ("Couldn't find ...").
- Steps 4 and 5: the same shape as step 1 (a "Couldn't find ..." certificate miss naming the products), not
  "Here's what you want:".
- No step shows an internal id, UUID or hidden code.
