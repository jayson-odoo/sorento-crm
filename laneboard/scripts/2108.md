# Hand test: PR #2108 PS-QUOTE-MATRIX (quotation grid: unit types / levels x areas / rooms; customer feedback notes)

Owner rulings 2 Nov, mock v3 approved: any quotation section can be a grid (column headers with
columns under them, a quantity per box, the line's quantity is the sum); every existing column
stays; columns are set up in the table itself; a section without a grid is unchanged; the
customer leaves feedback notes (optional hint), nothing is accepted or applied.

crew test copy

## Setup
Crew applies the crew-migration SQL for #2097's `ppq_0001_proposal_quotation` first, then this
PR's `pqm_0001_quote_matrix` (both posted on the PRs). Sign in as a project sales user with edit
rights. Pick a project you own (or register "PQM hand test") and add a proposal with two
sections: "UNIT" and "GUARD HOUSE". In UNIT add one line SRTFT205 at unit price 45.00, qty 1; in
GUARD HOUSE add any product (e.g. SRTKSBT001), qty 2, unit price 520.00. Save, do not send yet.

Editing: the Lines tab has no Edit button. Open the proposal's actions menu and click
**Edit proposal**; after every Save, open **Edit proposal** again before the next change. A new
header or column starts named "Header 1" / "Column 1" with the name selected: type over it.

## Steps
1. Open the proposal, Lines tab, section UNIT.
2. Actions > Edit proposal, then click `+ Column header` under the table, type `TYPE A`, press Enter.
3. Click `+ Column` after TYPE A twice and name the two columns `1 BH` and `BALCONY`.
4. Click `+ Column header` again, type `TYPE B`, then `+ Column` twice for `2 BH` and `BALCONY`.
5. On the SRTFT205 line type TYPE A / 1 BH = 120, TYPE A / BALCONY = 120, TYPE B / 2 BH = 500, TYPE B / BALCONY = 250, then click Save.
6. Read the row and the footer.
7. Actions > Edit proposal, then rename `TYPE B` to `TYPE B - 2 BH` by clicking its name.
8. Click Remove (x) on TYPE A / BALCONY, then click Undo before the countdown ends.
9. Switch to section GUARD HOUSE.
10. Back on UNIT, copy `10<TAB>20` from a text editor (two numbers separated by a tab), click the TYPE A / 1 BH box of the line and paste.
11. Type 120 and 120 back into TYPE A / 1 BH and TYPE A / BALCONY, then Save.
12. Actions > Edit proposal, add a line CKS903 at 310.00 with only TYPE B / 2 BH = 250 (leave TYPE A blank), Save.
13. Actions > Sign proposal. Then Send to Customer > Email: it issues the proposal at once, with no confirm (no email leaves the test copy). Then Actions > Copy counter-sign link and keep the link for step 15. Then Actions > Download PDF and open the file from My downloads when it is ready.
14. Actions > Download Excel and open the file from My downloads when it is ready.
15. Paste the link copied in step 13 into a private window (not signed in to the CRM). If it is lost, Actions > Copy counter-sign link copies it again.
16. Open the UNIT section; on the SRTFT205 line (shown by its description) tap the TYPE B / 2 BH box, write "need 520", suggested quantity 520, click Send feedback.
17. Tap the feedback button beside the CKS903 line (shown by its description), write "can do 290?", choose suggested price 290.00, Send feedback.
18. Sign the proposal on the same page.
19. Back in the CRM, open the proposal's Customer feedback tab.
20. Tick Handled on the SRTFT205 note.
21. Click Show in Lines on the CKS903 note.
