# Hand test: PR #2108 PS-QUOTE-MATRIX (quotation grid: unit types / levels x areas / rooms; customer feedback notes)

Owner rulings 2 Nov, mock v3 approved: any quotation section can be a grid (column headers with
columns under them, a quantity per box, the line's quantity is the sum); every existing column
stays; columns are set up in the table itself; a section without a grid is unchanged; the
customer leaves feedback notes (optional hint), nothing is accepted or applied.

## URL
crew test copy

## Setup
Crew applies the crew-migration SQL for `pqm_0001_quote_matrix` (posted on the PR) to the test
copy first; this branch also carries #2097's `ppq_0001_proposal_quotation`, which must be applied
before it. Sign in as a project sales user with edit rights. Pick a project you own (or register
"PQM hand test") and add a proposal with two sections: "UNIT" and "GUARD HOUSE". In UNIT add one
line FT100-SS (or any catalogue product) at unit price 45.00; in GUARD HOUSE add any product,
qty 2, unit price 520.00. Save, do not send yet.

## Steps
1. Open the proposal, Lines tab, section UNIT.
2. Click the narrow "Add a column header" column at the far right and type `TYPE A`, press Enter.
3. Click "+" after TYPE A twice and name the two columns `1 BH` and `BALCONY`.
4. Click "Add a column header" again, type `TYPE B`, add columns `2 BH` and `BALCONY`.
5. On the FT100-SS line type TYPE A / 1 BH = 120, TYPE A / BALCONY = 120, TYPE B / 2 BH = 500, TYPE B / BALCONY = 250.
6. Read the row and the footer.
7. Rename `TYPE B` to `TYPE B - 2 BH` by clicking its name.
8. Click Remove (x) on TYPE A / BALCONY, then click Undo before the countdown ends.
9. Switch to section GUARD HOUSE.
10. Back on UNIT, copy `10\t20` from a text editor (two numbers separated by a tab), click the TYPE A / 1 BH box of the line and paste.
11. Undo that by typing 120 and 120 back into TYPE A / 1 BH and TYPE A / BALCONY.
12. Add a line KS903 (or any product) at 310.00 with only TYPE B / 2 BH = 250 (leave TYPE A blank).
13. Send the proposal (sign and issue as usual), then open the PDF.
14. Export Excel.
15. Open the customer link in a private window (not signed in to the CRM).
16. Open the UNIT section, tap the TYPE B / 2 BH box of FT100-SS, write "need 520", suggested quantity 520, click Send feedback.
17. Tap the feedback button beside KS903, write "can do 290?", choose suggested price 290.00, Send feedback.
18. Sign the proposal on the same page.
19. Back in the CRM, open the proposal's Customer feedback tab.
20. Tick Handled on the first note.
21. Click Show in Lines on the second note.
