box on spec sheet pages, the new variables, a table element in both designers, PowerPoint export,
the price tag add-element toolbar on the spec sheet page, and the Reset to template fix.

crew test copy (branch `claude/spec-sheet-designer-parity-b2-2sv9bf`, PR #2349)

## Setup
1. Run the crew-migration on the test copy's DB:
   `ALTER TABLE products ADD COLUMN IF NOT EXISTS spec_sheet_description TEXT;`
2. Sign in as a user who can edit products, tag templates and project sales (and has
   `dealer_kit.library.manage` for step 27).
3. Use the project "ZZT outcome 2197 B" (PPF2611006) > Proposals > PRJQ-2026-0027-A > Spec sheet > SS1.
   Note the product code of its first page (call it P1) and the spec sheet page template it uses.
   SS1 needs at least 3 product pages.

## Steps
1. Open Products > P1 > Specifications. In "Spec sheet description" type two lines: `WALL HUNG BASIN` then `- L520 x W400 x H125MM`. Save, then reload.
2. Open Dealer Kit > Tag templates > the spec sheet page template SS1 uses. Select a text layer, click Insert field, search "Spec sheet description", click it, Done.
3. In the same template, click Add Accessories. Look at the box's sample cards.
4. Click Add Table. Right-click a cell: Insert row below; right-click again: Merge right; right-click again: Merge down. Press Cmd+Z (Ctrl+Z) three times.
5. Double-click the top-left cell, type `REF : `, type `{`, search "Ref", pick it, click away from the table.
6. With that cell still picked, in the Inspector Cell section set Border colour to a green and width 0.3 mm (All sides).
7. Click the bottom-right cell and set only its Top border to red.
8. Right-click an empty spot, Insert field search "doc.", and look at the list. Then open a PRICE TAG template, Insert field, and search "Subject".
9. Publish the spec sheet template. Open SS1 and use the sheet's Templates menu to take the latest template versions.
10. On page 1 open "Add accessory" and pick two other products.
11. On page 1 double-click the spec sheet description text. Change the second line to `- L520 x W400 x H130MM`, press Cmd+Enter (Ctrl+Enter). Reload.
12. Double-click the same text again and click "Reset to product text".
13. Click a text layer on page 1, Inspector > Insert field, search "Page", insert "Page number", Done.
14. Click Export > PowerPoint. Open the Downloads tray in the top bar and wait for it to finish; open the file.
15. Click Export > PDF and open it from the Downloads tray.
16. On SS1, look at the toolbar row at the top of the page area. Click an empty spot on page 2, then click Add Text.
17. With the text selected, look at the same toolbar row; click ALL CAPS.
18. Click Add Image, pick a picture from the library. Then click Add Image again and Cancel the picker.
19. Click Add Shape; select the shape, open More > Duplicate, then press the Delete key. Press Cmd+Z (Ctrl+Z). Reload.
20. In the Inspector set Apply to = Every page, select a page, click Add Text. Reload.
21. Move a box on page 3 and wait 2 seconds. Click "Reset to template" on page 3 and let the countdown finish. Move a different box on page 3, wait 2 seconds, reload.
22. Look at the Pages side bar on the left; click the thumbnail of page 3.
23. Right-click the page 3 thumbnail (or its "..." menu) and choose Remove page. Reload. Then at the bottom of the side bar open "Removed pages (1)" and click Put back.
24. On page 2 click Add Table. With the table selected click Header row in the toolbar row, then + Row four times.
25. Click a cell in the last row; in the Inspector set Row height to 30. Then drag the bottom edge of the row above it down a little. Press Cmd+Z (Ctrl+Z).
26. Select the table and press the Delete key; press Cmd+Z (Ctrl+Z). Double-click a cell, type a word and press Backspace.
27. Select a text layer, open the font list in the toolbar row and click Manage fonts.
28. Reload SS1.
29. Open Dealer Kit > Room Designer > Tag Templates > the page template SS1 uses.
30. Resize the browser to phone width (375 px) and repeat steps 16, 22, 23 and a right-click (long-press) on a cell of a table that is not selected.

## Expected
- Step 1: the two lines are kept after reload; the product's History shows the change.
- Step 2: the text shows the product's spec sheet description (the two lines) on the template preview where a product is bound, the token otherwise.
- Step 3: each sample card shows a picture area, a bold first line with brand and code, then the description lines.
- Step 4: the table gets a new row; the cell joins its right neighbour; then it joins the one below. Each Undo steps back one change.
- Step 5: the cell editor opens on that cell; the field shows as a "Ref" chip after "REF : "; after clicking away the cell reads "REF : " plus the ref (or the chip name where no document is bound). There is no Content box, Cell row or Cell column box in the Inspector.
- Step 6: the cell's border is green. Where it touches another cell the line is drawn once, not doubled.
- Step 7: the line between the bottom-right cell and the cell above it turns red (setting either cell's side of a shared line changes that line).
- Step 8: the spec sheet template lists Subject title, Attn, Recipient, Project code, Page number, Page count and the Accessories group (Accessory 1 to 3: code, name, brand, description, spec sheet description, dimensions). The price tag template lists none of these spec-sheet-only fields.
- Step 9: SS1's pages print the new template: the table with the ref filled in, the description lines.
- Step 10: the two picked products appear as cards in page 1's Accessories box (photo, bold "BRAND CODE", their description); their own pages leave the sheet.
- Step 11: page 1 shows H130MM after reload; the product master (Products > P1) still says H125MM; other spec sheets of the product still say H125MM.
- Step 12: page 1 goes back to H125MM.
- Step 13: the text shows its page number.
- Step 14: a PowerPoint row appears in the Downloads tray and turns ready; the file opens with one slide per printed page at the page's size; texts are editable text boxes (font, size, bold kept), the photos are pictures, the table is a real PowerPoint table (merged cells, red/green borders, bold header row), the Accessories cards are there.
- Step 15: the PDF still exports and matches what the pages show.
- Step 16: ONE toolbar row: Text, Shape, Image, Badge, Table, Accessories, Undo, Redo, More, zoom out / % / zoom in, Fit width, Full screen and the save state ("Saved"). No separate page bar, no "1 of N" counter, no previous / next buttons, no Product, Set, Alternatives, Price badge or Barcode. The new text appears on page 2 (the page you clicked), selected.
- Step 17: the font, size, bold, italic, align and ALL CAPS controls show in that same row, and "Saved" stays visible at the right; the text turns to capitals on the page.
- Step 18: the picture lands on page 2; cancelling the second picker leaves no empty frame.
