# Hand test: PR #2349, spec sheet designer parity slice B (lane SPEC-SHEET-DESIGNER-PARITY)

Slice B: spec sheet description (product field + per-sheet override), the price tag Accessories
box on spec sheet pages, the new variables, a table element in both designers, PowerPoint export,
the price tag add-element toolbar on the spec sheet page, and the Reset to template fix.

## URL
crew test copy (branch `claude/spec-sheet-designer-parity-b2-2sv9bf`, PR #2349)

Open it over https or on localhost (pasting from the OS clipboard needs a secure origin). The
PowerPoint and PDF exports need the RQ worker running on the test copy (`catalogue_render` queue).

## Setup
1. Run the crew-migration on the test copy's DB:
   `ALTER TABLE products ADD COLUMN IF NOT EXISTS spec_sheet_description TEXT;`
2. Sign in as a user who can edit products, tag templates and project sales.
3. Use the project "ZZT outcome 2197 B" (PPF2611006) > Proposals > PRJQ-2026-0027-A > Spec sheet > SS1.
   Note the product code of its first page (call it P1) and the spec sheet page template it uses.

## Steps
1. Open Products > P1 > Specifications. In "Spec sheet description" type two lines: `WALL HUNG BASIN` then `- L520 x W400 x H125MM`. Save, then reload.
2. Open Dealer Kit > Tag templates > the spec sheet page template SS1 uses. Select a text layer, click Insert field, search "Spec sheet description", click it, Done.
3. In the same template, click Add Accessories. Look at the box's sample cards.
4. Click Add Table. Right-click a cell: Insert row below; right-click again: Merge cells; right-click again: Merge down.
5. Left-click the top-left cell. In the Inspector set its Content to `REF` + a new line + Insert field "Ref"; set Border colour to a green and width 0.3 mm (All sides).
6. Click the bottom-right cell and set only its Top border to red.
7. Right-click an empty spot, Insert field search "doc.", and look at the list. Then open a PRICE TAG template, Insert field, and search "Subject".
8. Publish the spec sheet template. Open SS1 and use the sheet's Templates menu to take the latest template versions.
9. On page 1 open "Add accessory" and pick the other two products.
10. On page 1 double-click the spec sheet description text. Change the second line to `- L520 x W400 x H130MM`, press Cmd+Enter (Ctrl+Enter). Reload.
11. Double-click the same text again and click "Reset to product text".
12. Click a text layer on page 1, Inspector > Insert field, search "Page", insert "Page number", Done.
13. Click Export > PowerPoint. Open the Downloads tray in the top bar and wait for it to finish; open the file.
14. Click Export > PDF and open it from the Downloads tray.
15. On SS1, look at the toolbar row under the page bar. Click an empty spot on page 2, then click Add Text.
16. Click Add Image, pick a picture from the library. Then click Add Image again and Cancel the picker.
17. Click Add Table, then Add Shape; select the shape, click Duplicate, then Delete. Reload.
18. In the Inspector set Apply to = Every page, select a page, click Add Text. Reload.
19. Move a box on page 3 and wait 2 seconds. Click "Reset to template" on page 3 and let the countdown finish. Move a different box on page 3, wait 2 seconds, reload.
20. Open Dealer Kit > Room Designer > Tag Templates > the page template SS1 uses.

## Expected
- Step 1: the two lines are kept after reload; the product's History shows the change.
- Step 2: the text shows the product's spec sheet description (the two lines) on the template preview where a product is bound, the token otherwise.
- Step 3: each sample card shows a picture area, a bold first line with brand and code, then the description lines.
- Step 4: the table gets a new row; the cell joins its right neighbour; then it joins the one below. Undo (Cmd+Z) steps back each change.
- Step 5: the cell shows REF and the ref field; its border is green. Where it touches another cell the line is drawn once, not doubled.
- Step 6: the line between the bottom-right cell and the cell above it turns red (setting either cell's side of a shared line changes that line).
- Step 7: the spec sheet template lists Subject title, Attn, Recipient, Project code, Page number, Page count and the Accessories group (Accessory 1 to 3: code, name, brand, description, spec sheet description, dimensions). The price tag template lists none of these spec-sheet-only fields.
- Step 8: SS1's pages print the new template: the table with the ref filled in, the description lines.
- Step 9: the two picked products appear as cards in page 1's Accessories box (photo, bold "BRAND CODE", their description); their own pages leave the sheet.
- Step 10: page 1 shows H130MM after reload; the product master (Products > P1) still says H125MM; other spec sheets of the product still say H125MM.
- Step 11: page 1 goes back to H125MM.
- Step 12: the text shows its page number.
- Step 13: a PowerPoint row appears in the Downloads tray and turns ready; the file opens with one slide per printed page at the page's size; texts are editable text boxes (font, size, bold kept), the photos are pictures, the table is a real PowerPoint table (merged cells, red/green borders), the Accessories cards are there.
- Step 14: the PDF still exports and matches what the pages show.
- Step 15: the toolbar is the price tag designer's: Text, Shape, Image, Badge, Table, Accessories, Undo, Redo, Delete, Duplicate, Group, Ungroup; no Product, Set, Alternatives, Price badge or Barcode; one Undo on the page. The new text appears on page 2 (the page you clicked), selected.
- Step 16: the picture lands on page 2; cancelling the second picker leaves no empty frame.
- Step 17: a table and a shape appear on page 2; Duplicate adds a second shape, Delete removes the selected one; after reload they are all still there and the page saves (no "Not saved"), also on a page whose template has an Accessories box.
- Step 18: the text appears once on every product page (the cover is untouched); after reload still once per page.
- Step 19: after the reset page 3 shows the template layout; after the last reload only the second move is there, the first move is gone.
- Step 20: the template has none of the elements added on the spec sheet pages (they belong to the sheet's pages only).
