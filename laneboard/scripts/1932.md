# Hand test: PR #1932 CONTACT-DELETE-FK (contact delete with linked records)

## URL

crew test copy

## Setup

1. Sign in as an admin with Contacts edit.
2. Pick contact A: a contact that has at least one Price Tag Request (Dealer Kit > Price Tag Requests, note the contact
   on any request). Note how many requests it has.
3. Pick contact B: a throwaway contact with no price tag requests and no ticket comments (or create one: Contacts > Add,
   any unused phone number, name "Delete test B").
4. Pick contact C: a second throwaway contact like B (name "Delete test C").

## Steps

1. Contacts, tick contact A only, Delete contacts, click "Delete 1 contact".
2. Contacts, open contact A's row action Delete (single delete dialog), confirm.
3. Contacts, tick contact A and contact B, Delete contacts, click "Delete 2 contacts".
4. Contacts, tick contact C only, Delete contacts, click "Delete 1 contact".

## Expected

1. A red toast "Deleted 0 contacts. 1 contact was not deleted because it has linked records." with the line
   "<A's name>: This contact has <N> price tag request(s); it cannot be deleted." No SQL, no constraint name, no id.
   Contact A is still in the list.
2. A red toast "This contact has <N> price tag request(s); it cannot be deleted." Contact A is still in the list.
3. A red toast "Deleted 1 contact. 1 contact was not deleted because it has linked records." naming A. B is gone
   from the list, A stays.
4. A green toast "Deleted 1 contact." C is gone from the list.
