It inserts ONE unlabelled version of `chatbot_semantic_parser` built from the owner's production text of 1 Oct 2026. Note the version number from the deploy log line `prod snapshot vN: ...`.

## Steps

1. Open the prompt through the sidebar: System Management > AI Assistant > Prompts, then `chatbot_semantic_parser`. Open the newest version.
2. Press Ctrl+F and type `current`. Note the counter, then press Enter twice.
3. With find still open, switch to v53 in the version list. Then switch back to the newest version.
4. Click at the very start of the text and type `current `.
5. Click right after `domain_hint = ONE of:` in the editor. In the "Wired to this agent" panel, click `+ Insert` on Brands.
6. Click right after `== ACCESS LEVELS ==`. Use the toolbar's "Insert variable" and pick Access levels.
7. Repeat step 5 at 375px width.
8. Discard the draft without saving.
9. Item 3: open version N (from the deploy log) and use Preview. Compare it with the owner's production text (`documentation/prompts/chatbot_semantic_parser.prod-20261001.txt` on branch `crew/prod-semantic-parser-20261001`), where only `{{current_date}}` differs.
