# Hand test #1405 (PROMPT-DYNAMIC), round 2

## URL
crew test copy

## Setup

1. Deploy the PR #1405 head to the crew copy. The crew copy's dev DB is migrated by SQL, so apply the lane's crew-migration file: `psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f documentation/plans/chatbot/crew-migration-prompt-dynamic.sql`. It is additive and idempotent, and it never sets or moves a label. It prints `NOTICE: prod snapshot vN: published unlabelled`, then one line per list (`replaced` or `kept literal`). Note N.
2. Sign in as a superadmin.

## Steps

1. Open the prompt through the sidebar: System Management > AI Assistant > Prompts, then `chatbot_semantic_parser`. Open the newest version.
2. Press Ctrl+F and type `current`. Note the counter, then press Enter twice.
3. With find still open, switch to v53 in the version list. Then switch back to the newest version.
4. Click at the very start of the text and type `current `.
5. Click right after `domain_hint = ONE of:` in the editor. In the "Wired to this agent" panel, click `+ Insert` on Brands.
6. Click right after `== ACCESS LEVELS ==`. Use the toolbar's "Insert variable" and pick Access levels.
7. Repeat step 5 at 375px width.
8. Discard the draft without saving.
9. Item 3: open version N (from the SQL notices) and use Preview. Compare it with the owner's production text (`documentation/prompts/chatbot_semantic_parser.prod-20261001.txt` on branch `crew/prod-semantic-parser-20261001`), where only `{{current_date}}` differs.

## Expected

1. Step 2: the counter reads `1/N`, then `3/N`. Every yellow highlight covers exactly the word "current", and the active one is orange.
2. Step 3: after each switch, the counter re-counts for that version. Every highlight still covers exactly "current", never shifted text.
3. Step 4: the counter goes up by one, and all highlights stay exact.
4. Step 5: the Brands chip appears exactly where the caret was, not at the bottom of the prompt.
5. Step 6: the Access levels chip lands right after `== ACCESS LEVELS ==`.
6. Step 7: the same as step 5, with no sideways scroll on the page.
7. Step 9:
   - Version N has no label, and `production` has not moved.
   - In Edit, the swapped lists show as chips (at least Teams).
   - Preview equals the owner's text byte for byte, apart from today's date in place of `{{current_date}}`.
   - Every `kept literal` notice is a list whose registry differs from the owner's text. Those lists keep his words.
