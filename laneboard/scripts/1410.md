# Hand test #1410 (DO-OWNERSHIP-GUARD)

## URL
crew test copy

## Setup

1. No migration. Sign in as an admin.
2. On the shared dev DB, pick one AutoCount-owned DO and one ordinary DO:
   `SELECT order_number FROM orders WHERE doc_key IS NOT NULL AND deleted_at IS NULL ORDER BY order_date DESC LIMIT 1;` (call it AC-DO)
   `SELECT order_number FROM orders WHERE doc_key IS NULL AND deleted_at IS NULL ORDER BY order_date DESC LIMIT 1;` (call it PLAIN-DO)
   If the first query returns no row, stop and reply on PR #1410: the dev DB has no AutoCount DO yet.
3. Note AC-DO's Debtor Name, Agent and Delivery Order Date as they read now.

## Steps

1. From the sidebar open Delivery Orders > Delivery Orders, search AC-DO, open it.
2. Scroll to the Delivery Order Lines card and read its toolbar.
3. Click Edit. On Basic Information, read Delivery Order Number, Delivery Order Date, Debtor Code, Debtor Name, Agent and Cancelled.
4. Change Delivery Order Type to `RMA` and Remarks CS to `PS25-2053`. Click Update Delivery Order.
5. Click Edit again and open the Delivery & Tracking tab. Read Debtor Code, Debtor Name, Agent and Cancelled there. Change Driver Name to `HANDTEST`. Click Update Delivery Order.
6. Narrow the browser to phone width (375px) and repeat step 3 (read only, do not save).
7. Go back to the list, open PLAIN-DO, read the Lines card toolbar, click Edit and read Debtor Name and Cancelled.

## Expected

1. Step 2: the lines card shows `From AutoCount` in its toolbar, no "Add line", no "Delete selected", no checkboxes and no per-line delete button.
2. Step 3: those six fields are greyed out (cannot be typed in or ticked), and each shows `From AutoCount` under or beside it. Delivery Order Type, Remarks CS, Delivery Order Status, Estimated and Actual Delivery Date are editable.
3. Step 4: the save succeeds with no error toast; the detail page shows Type `RMA` and Remarks CS `PS25-2053`; Debtor Name, Agent and Delivery Order Date still read exactly as noted in setup 3.
4. Step 5: on the tracking tab, Debtor Code, Debtor Name, Agent and Cancelled are greyed out with `From AutoCount`; the save succeeds and the Delivery & tracking tab shows Driver Name `HANDTEST`.
5. Step 6: the same fields are greyed out with `From AutoCount`, nothing is cut off and the page does not scroll sideways.
6. Step 7: PLAIN-DO shows "Add line" and "Delete selected (0)", Debtor Name and Cancelled are editable, and no `From AutoCount` appears anywhere.
