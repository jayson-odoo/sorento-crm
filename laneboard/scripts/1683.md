# Hand test: PR #1683 STOCK-DEBT-SAVED-VIEWS (saved views and a Location filter on Stock Debt)

Round 3, after the owner's hand test ("use the true location, don't do grouping like that"): the
Location filter now lists the REAL warehouses (`BRW-IB`, `DC1-IB`, `MWH-BB`, the site pools such
as `BRW` and `HQ`, ...), not the groups (`IB`, `BB`, ...). `Only` keeps exactly the warehouses
picked; `All except` keeps every other one. The balance is recomputed from those warehouses'
own stock, incoming and orders, not the same rows filtered. Saved views keep the picked
warehouses, the mode and a rolling delivery range. The three BRW columns are a fixed BRW
retail-pool reference and say so.

The dev copy has no `-ED` warehouse, so this test uses the five **IB** warehouses as ED's
stand-in. In production ED works the same way once its warehouses are switched on (Setup 3).

## Setup
Crew prepares the copy. The owner runs no commands.

1. Sign in with your own admin account (SRT + MCH, active company SRT).
2. Product used for the numbers: **B2155-NL-BLUE** (figures read by the lane on the shared dev
   DB, 15 Oct, through this branch's code: Book = All, no date range, Projected balance off).
   Keep Book on `All` until step 15.
3. Production step after deploy (owner, not part of this test): to bring ED in, sidebar
   **Inventory > Warehouses**, open each active warehouse whose code ends in `-ED` (e.g.
   `PRJ-ED`, `BRW-ED`), click **Edit**, switch **Fulfilment planning** ON, save. Those
   warehouses then appear in the Location list by their own codes, with no code change.

## Steps
1. CRM sidebar: Procurement > Supply Chain > Stock Debt. Search `B2155-NL-BLUE`.
2. Note its Oct, Nov, Dec, TBA and Total.
3. Click `Filters`. Open the `Location` select (under `Supplier`) and scroll the list.
4. In the Location search box type `-IB`, then click `Select 5 matching`. Leave the mode on `Only`.
5. Close the Filters panel and read B2155-NL-BLUE's figures.
6. Click `Save view`, name it `IB only`, click `Save`.
7. Open `Filters`, switch the Location mode to `All except` (the five IB warehouses stay picked).
8. Close the panel and read B2155-NL-BLUE's figures.
9. Click `Save view`, name it `Project view`, click `Save`.
10. Open the views menu (it reads the current view's name or `No segment`), choose `No segment`.
11. Open the views menu, pick `IB only`.
12. Open the views menu, pick `Project view`.
13. Click B2155-NL-BLUE's Nov cell, look at the locations listed, close it.
14. Open the views menu, choose `No segment`. Open `Filters`, pick only `BRW-IB` in Location
    (mode `Only`), close the panel and read B2155-NL-BLUE's figures. Click its Oct cell, look
    at the supply lines, close it.
15. Open `Filters`, clear Location, set `Book` to `Project`, open the Location select; then set
    `Book` to `Retail` and open it again. Set `Book` back to `All`.
16. Open the views menu, pick `Project view`. Open `Filters`, set `Sales order delivery date` to
    today to today + 30 days (type e.g. `15/10/2026 - 14/11/2026`). Click `Save view`, name it
    `Project next 30 days`.
17. Open the views menu, choose `No segment`, then pick `Project next 30 days`.
18. Look at the column headers between Product and the first month, then pick `IB only` and look
    again.
19. Open the views menu, pick `Project next 30 days`, open the menu again, click `Delete view`;
    click `Cancel` in the toast. Then click `Delete view` again and let it run out.
20. Optional, on a later day: re-create `Project next 30 days` if deleted, pick it again.
