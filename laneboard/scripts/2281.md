# Hand test: PR #2281 COMBO-RENAME (rename a product combo after creating it)

On product detail > Combos, a pencil next to each combo's title renames it in place. Enter or Save saves, Escape or
Cancel leaves it alone. A name another combo on the same product already has (any letter case) is refused under
the input; so is an empty name. Names cap at 100 characters, in the inputs and in the API. Price tags read the
combo's name live, so they show the new name with no other step.

## URL
crew test copy

## Setup
1. Sign in with a login that holds `master_data.products.edit` (for example an admin).
2. Use product SRTKS8547 and its combo "2 in 1". If it has no second combo, add one with Add combo, named
   `ZZ TEST COMBO` (step 10 removes it).

## Steps
1. From the home page, open the sidebar: Products > Products > All Products, and open SRTKS8547.
2. In the Combos card, click the pencil next to "2 in 1".
3. Change the text to `2 IN 1 SET`, then press Escape.
4. Click the pencil again, change the text to `2 IN 1 SET`, press Enter.
5. Reload the page.
6. Click the pencil on "2 IN 1 SET", type the OTHER combo's name in different letter case (for example
   `zz test combo`), click Save.
7. Clear the input to spaces only and click Save.
8. Paste a 120-character name into the input.
9. Click Cancel. Then click Add combo in the card header and paste the same 120-character name into Name.
10. Close the modal. Click the pencil on "2 IN 1 SET", type the original name `2 in 1`, press Enter. Delete `ZZ TEST COMBO` if you added it.
11. Sign in as a user without `master_data.products.edit` and open the same product.

## Expected
- Step 2: the title becomes an input holding "2 in 1", with Save and Cancel beside it.
- Step 3: the input closes, the title still reads "2 in 1", no toast.
- Step 4: toast "Combo saved"; the title reads "2 IN 1 SET".
- Step 5: still "2 IN 1 SET".
- Step 6: under the input, in red: "Another combo on this product already has this name"; the input stays open; no
  toast.
- Step 7: under the input, in red: "A combo needs a name"; nothing is saved.
- Step 8: the input keeps the first 100 characters only.
- Step 9: the Name box also keeps the first 100 characters only.
- Step 10: the title reads "2 in 1" again.
- Step 11: the titles show with no pencil (and no Delete).
