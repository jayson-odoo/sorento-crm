2. A fake sender, so nothing reaches n8n or WhatsApp. In a spare terminal:
   `python3 -c "import http.server as h,time;exec('class H(h.BaseHTTPRequestHandler):\n def do_POST(s):\n  b=s.rfile.read(int(s.headers[\"Content-Length\"]));print(time.strftime(\"%T\"),b[:300],flush=True);s.send_response(200);s.end_headers();s.wfile.write(b\"ok\")');h.HTTPServer(('127.0.0.1',8899),H).serve_forever()"`
   and on the shared dev DB set the default respond workspace's sender to it (Settings, Respond.io workspace:
   sender URL `http://127.0.0.1:8899/sender`, any sender key). Note the old values to put back.
3. Test contact: `INSERT INTO respond_contacts (id, respond_io_id, phone_number, session_vars, chatbot_allowed)
   VALUES (gen_random_uuid()::text, 'zzt-photo-first-1', '+60000000001', '{"variables":{}}', true);` and allow its
   photos: `INSERT INTO contact_media_limit (id, contact_id, modality, is_allowed) SELECT gen_random_uuid(), id,
   'image', true FROM respond_contacts WHERE respond_io_id = 'zzt-photo-first-1';`
4. System Settings, chatbot: direct ingress mode `contacts`, contacts list `zzt-photo-first-1` only.
5. The webhook secret: `RESPOND_WEBHOOK_SECRET` from the test copy's backend `.env` (call it `$SECRET`). Endpoint:
   `POST http://localhost:8000/api/v1/public/respond/webhook`, header `x-respond-signature: <hex HMAC-SHA256 of the raw
   body with $SECRET>`, `content-type: application/json`.
6. Respond.io's contact lookup is real on a test copy: if it cannot find `zzt-photo-first-1` the row waits. If so,
   use the owner's own test contact id instead of `zzt-photo-first-1` in steps 3 to 4 and in every body (no other contact).
7. Save this as `post.py` (bodies are the respond.io `message.received` shape; the message id is the send time in
   microseconds, so the photo is sent 201 ms after the text):

```python
import hashlib, hmac, json, os, sys, time, httpx
URL, SECRET, C = "http://localhost:8000/api/v1/public/respond/webhook", os.environ["SECRET"], sys.argv[1]
t0 = int(time.time() * 1_000_000)
def body(mid, inner):
    return {"event_type": "message.received", "event_id": f"evt-{mid}",
            "contact": {"id": C, "firstName": "Zzt", "lastName": "Test", "phone": "+60000000001"},
            "message": {"messageId": mid, "contactId": C, "channelId": 12, "traffic": "incoming",
                        "timestamp": mid // 1000, "message": inner, "sender": {"source": "contact"}},
            "channel": {"id": 12, "name": "ZZT WA", "source": "whatsapp_cloud"}}
def post(b):
    raw = json.dumps(b).encode()
    sig = hmac.new(SECRET.encode(), raw, hashlib.sha256).hexdigest()
    print(httpx.post(URL, content=raw, headers={"x-respond-signature": sig, "content-type": "application/json"}).status_code)
post(body(t0, {"type": "text", "text": "check stock"}))
time.sleep(0.2)
post(body(t0 + 201_000, {"type": "attachment", "attachment": {"type": "image", "mimeType": "image/jpeg",
     "url": "https://media.example.invalid/zzt/photo.jpg", "size": 2048}}))
```
