## Setup

1. Apply the crew-migration SQL posted on PR #1849 (new registrations table, State / Mukim on projects, the two lookup sets, the `projects.registrations.approve` permission, project numbering switched to PPF).
2. Sign in as the E2E admin account (admin roles hold `projects.registrations.approve`).
3. Pick one portal contact that is linked to an active sales agent (Sales > Sales Agents shows the linked contact). Call it the salesperson contact.
4. Open that contact (User Management > Internal Users, sidebar), and under Portal forms set "Project Registration" to "Always show".
5. Note one existing project's code and title in Project Sales > Pipeline (any open project with a developer). Call it P.

## Steps

1. On the salesperson contact's row, open the actions menu and choose "Impersonate in portal".
2. In the portal, open the form selector and choose "Project Registration", then press New.
3. Read the Sales agent field without typing anything.
4. Press AI Extract, paste this text into the dialog and run it: `CADANGAN MEMBINA KILANG 2 TINGKAT DI ATAS LOT 9001, MUKIM TEBRAU, DAERAH JOHOR BAHRU, JOHOR. UNTUK TETUAN ALPHA PACKAGING SDN BHD`. Confirm and prefill.
5. Clear the State field and press Submit.
6. Pick State "Johor", open Customer name and pick any customer from the dropdown, type Distributor name `Distributor D`, then press Submit.
7. Stop impersonating. In the CRM, from `/`, open Project Sales > Registrations from the sidebar.
8. Read the row for the Alpha Packaging registration.
9. Back in the portal (impersonate again), register a second project with exactly P's title, State `Selangor` and Developer = P's developer name. Submit.
10. In the CRM Registrations list, read the second row's Possible duplicate cell and click the link in it.
11. Go back, open the second registration, pick P's developer in Developer, and press Approve.
12. Change the title in the form by adding ` PHASE 2` at the end and press Approve again.
13. Open the Alpha Packaging registration. Leave Developer empty and press Approve.
14. Pick a developer (create "Alpha Packaging Sdn Bhd" under Project Sales > Parties first if it is not there), set Project type, press Approve.
15. Open Project Sales > Pipeline and open the newly registered Alpha Packaging project.
16. Impersonate the salesperson contact again and open the Project Registration list.
17. Register a third one (any title, State, Developer), submit, then in the CRM open it and press Reject with reason `Already registered`. Back in the portal, open it.
18. Shrink the window to phone width (375px) and repeat steps 2, 8 and 11.

## Expected

- Step 3: the salesperson's NAME (the agent's person name), not a code like `SA-007`; the field cannot be edited.
- Step 4 (AI output can vary slightly by model): the dialog proposes Project title (the pasted text), Developer `Alpha Packaging Sdn Bhd`, State `Johor`, Mukim `Tebrau`, Type of building `Factory / industrial`; after Confirm the fields are filled and still editable.
- Step 5: refused, State is named as required; nothing is submitted.
- Step 6: status `Pending`; the form is now read-only; PPF No. is empty.
- Step 8: Date today, the long title truncated (full text on hover), Developer `Alpha Packaging Sdn Bhd`, State `Johor`, Sales agent = the NAME, Status `Pending`.
- Step 10: Possible duplicate shows P's code and title as a link; the link opens P's project page.
- Step 11: refused with a message naming P's code (exactly the same title under the same developer cannot be registered twice); the registration stays Pending; no PPF is used up.
- Step 12: approved. Possible duplicates never block: the admin decides.
- Step 13: refused on the form: Developer is required. Nothing is created.
- Step 14: approved; the page returns to the list; the row no longer shows under Pending.
- Step 15: the project code is `PPF` + 2-digit year + 2-digit month + 3 digits (for example `PPF2610003`); State `Johor` and Mukim `Tebrau` show in the overview's "The development" card; the owner is the salesperson linked to the contact (or the person picked in step 14).
- Step 16: the approved one shows status `Approved` and its PPF number; the second one too.
- Step 17: status `Rejected` with the reason `Already registered`; the form is editable again and can be resubmitted.
- Step 18: nothing is clipped; the form, list and review screen are usable.
