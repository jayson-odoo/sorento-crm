# Hand test #1435 (SO-NUMBER-ASK)

## URL
crew test copy

## Setup

1. Sign in as an admin who can open System Management > Chatbot Console and a contact's Access tab.
2. Pick the HANLIM dealer contact the PR #1433 tester used (linked to the HANLIM TRADING SDN BHD accounts, A/C I to IV among them). On its Access > Field reveals card, make sure `Sales order outstanding` (`sales_orders.outstanding`) is ON. Do the same for crew's multi-group contact "CONTACT B" (respond_io_id 437264483).
3. `sales_orders.debtor_name` is empty on dev, so find these through the customer. FOREIGN_SO is an open SO of a customer the HANLIM contact is NOT linked to:
   `SELECT so.so_number, c.customer_name FROM sales_orders so JOIN customers c ON c.id = so.customer_id WHERE so.status = 'open' AND c.customer_name NOT ILIKE 'HANLIM%' ORDER BY so.order_date DESC LIMIT 1;`
   Cancelled HANLIM SO (crew found it): SO418652, 27 Aug 2026, [A/C I].

## Steps

1. From the sidebar open System Management > Chatbot Console and pick the HANLIM contact.
2. Send `status of SO422056`. Read the reply.
3. Send `status of SO421624`. Read the reply.
4. Send `status of SO422057`. Read the reply.
5. Send `status of SO422095`. Read the reply.
6. Send `status of SO418652`. Read the reply.
7. Send `status of FOREIGN_SO` (the number from setup 3). Read the reply.
8. Send `status of SO421624 SO999999 SO422057`. Read the reply.
9. Send `status of SO999999`. Read the reply.
10. Send `okay how about all my sales order?`. Read the reply. Repeat steps 2 and 10 twice more (three runs in all).
11. Send `september`. Read the reply.
12. Send `my sales orders from 20 Aug to 3 Sep`. Read the reply.
13. Send `my sales orders from 1 Aug to 30 Sep`. Read the reply.
14. Send `my outstanding SOs`. Read the reply.
15. Pick crew's contact "CONTACT B" (437264483) in the console. Send `all my sales orders`, then `september`. Read the second reply.
16. Still on "CONTACT B": send `my outstanding sales orders in september`. The reply is the SO outstanding summary ending `Reply 1 for the sales order list.` with a `Sales order list` button. Then reply `1`. Read the reply.
17. Send `my outstanding sales orders in september` again, then tap the `Sales order list` button. Read the reply.
18. Send `my outstanding sales orders in september` again, then send `give me the sales order list`. Read the reply.
19. Send `my outstanding sales orders in september` again, then send `find all my sales order`. Read the reply.
20. Send `my outstanding SOs` (no month). The reply is the outstanding summary with `Reply 1 for the sales order list.`. Reply `1`, then send `september`. Read both replies.
21. On the HANLIM contact's Access > Field reveals card, switch `Sales order outstanding` OFF. Back in the console (HANLIM contact), send `status of SO421624`, then `all my sales orders`. Read both replies. Switch the key back ON afterwards.
