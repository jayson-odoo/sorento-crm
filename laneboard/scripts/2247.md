# Hand test: PR #2247 AGENT-BULK-W2-TAGS (pasted table adds / removes contact tags)

A row = a contact's phone + tags to add and / or remove. A tag is matched by its exact name (case and spaces aside);
a name that is not a tag but sits inside tag names makes the row WAIT with those tags (max 10), nothing is picked
until you reply. Adding a tag also applies its settings (as the bulk-tag dialog's default); removing leaves settings.
Not known yet: follow-up turns may re-include rows you cancelled (fixed on main by AGENT-DECIDED-CARDS, not here).

## Setup
1. Sign in with your own login (Contacts edit).
2. Pick four real contacts and note their phones: Person A (holds Office Staff + Project Salesperson), Person B
   (holds Sorento Mocha Dealer Tag), Person C and Person D (no tag). Write them into the table below.
3. The table (the fifth phone is held by nobody):

```
Phone            Name       Add tag                    Remove tag
<Person C>       Person C   Office Staff

<Person D>       Person D   Salesperson

017-555 6666     Person E   Gold
```

## Steps
1. From the sidebar, open the AI assistant panel and start a new thread.
2. Type `tag these contacts`, paste the table, send.
3. Read the reply's tables (do not confirm).
4. Reply `row 3: Retail Salesperson`.
5. Read the reply's tables and the Confirm card, then click Confirm.
6. Open Contacts from the sidebar; open Person C, Person A and Person D; look at Tags and Tag settings.
7. New thread: `tag <Person C phone> with Mocha Dealer`; read the card, then Cancel.
8. New thread: `buang tag Project Salesperson untuk <Person A phone>`; read the reply.
9. New thread: `buang tag Office Staff untuk <Person C phone>`; Confirm; open Person C.
