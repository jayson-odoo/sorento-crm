# Hand test: PR #2152 OI-ROUTE-BY-RAISER (order inquiry emails routed by who raised the OI)

Automation rows for the order inquiry emails can now be set by who raised the order inquiry
(condition "Raised by"). Agnes' project orders go to her own row; Eling's project row skips them.
Send to purchasing follows the same rows. Mail does not leave a test copy, so the check is the
preview's To line, each row's run history and the queued email rows.

## URL
crew test copy

## Setup
- Signed in as an admin, one browser tab.
- The copy is a prod copy: it holds open project order inquiries raised by Agnes and at least one
  open project order inquiry raised by someone else (call it OTHER).
- Pick a user to stand in for Agnes' team (call them TEAM), anyone who is not Eling.

## Steps
1. From `/`, open the sidebar System Management > Automation.
2. Open the handover row whose To holds Eling and whose condition reads "Sales order class is Project". Click Edit.
3. Click Add condition, pick Raised by, pick "is none of", pick Agnes in the list. Save.
4. Back on Automation, click Add automation. Trigger: Order inquiry handover to purchasing; the same email template as Eling's row; name "ZZT Agnes project orders"; To: TEAM; tick One email, everyone on the thread.
5. Add condition Sales order class, is, Project. Add condition Raised by, is any of, Agnes. Enabled on. Save.
6. From `/`, open the sidebar Project Sales > Order Inquiries. Filter Raised by to Agnes and open one of her open project order inquiries.
7. Click Send to purchasing. Read the preview, then Cancel.
8. Go back, clear the Raised by filter, open OTHER, click Send to purchasing. Read the preview, then Cancel.
9. Open Agnes' order inquiry again, click Send to purchasing, then Send.
10. Open System Management > Automation > "ZZT Agnes project orders" and read its run history; then open Eling's row and read its run history.
11. Run on the copy's DB: `SELECT title, data->'recipient_emails' AS recipients, data->>'to_count' AS to_count, created_at FROM notifications WHERE type = 'automation_email' ORDER BY created_at DESC LIMIT 2;`

## Expected
- Step 3: Eling's row detail reads "Sales order class is Project AND Raised by is none of Agnes" (a name, never an id).
- Step 5: the new row's detail reads "Sales order class is Project AND Raised by is any of Agnes".
- Step 7: exactly one email in the preview; its To is TEAM; Eling is not on To or Cc.
- Step 8: exactly one email; its To is Eling (as before); TEAM is not on it.
- Step 9: the dialog closes with a success message and no skipped order inquiry.
- Step 10: "ZZT Agnes project orders" has one new run (Mode manual, Attempted 1 or more); Eling's row has no new run from step 9.
- Step 11: the newest row's title ends "(Resent)"; recipients is TEAM's address only (to_count 1); Eling's address is not in it.
