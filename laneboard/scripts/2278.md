# Hand test: PR #2278 PRICETAG-HEADER-DRAG (drag the accessories box header in the Tag Template designer)

With an accessories box selected, a dashed outline sits over its header ("FREE"). Dragging that outline moves the
HEADER anywhere inside the box; dragging anywhere else on the box still moves the box. A moved header is plain
text (no border break), draws over the cards, and never moves the cards, frame or footer. The print sheet / PDF
places it exactly where the designer shows it. Reset header position puts it back on today's spot.

## URL
crew test copy

## Setup
1. Sign in with your own login (Tag templates manage).
2. Pick a scratch tag template you can change, or create one: Dealer Kit > Room Designer > Tag Templates >
   New Template, name `Header drag hand test`, price type LP, Create template.

## Steps
1. From the sidebar open Dealer Kit > Room Designer > Tag Templates and open the scratch template.
2. Click the Add Accessories button in the toolbar, then Default box.
3. In the Inspector set Header text to `FREE`.
4. Press on the dashed outline around FREE and drag it down onto the second card, near the bottom border; release.
5. Look at the Inspector X / Y (mm) of the box and the Header section.
6. Click Save, then reload the page.
7. Click the box once to select it.
8. Drag the box itself (press on a card, not on FREE) to the right by about 2 cm; release.
9. Set the box Rotation to 90 and press Enter; drag the dashed outline around FREE towards the box's own bottom
   edge (now on the left); release.
10. Press Ctrl+Z (Cmd+Z on a Mac) once.
11. Click Reset header position in the Inspector.
12. Open any linked box (one made from a saved Accessory Template, Inspector shows `Linked: <name>`), drag its
    header, Save, then open another tag template that uses the same saved accessory template.
13. Print or download a tag sheet for a request line using the scratch template (Price Tag Requests > a request >
    Download); compare the header spot on the PDF with the designer.

## Expected
- Step 4: while dragging, FREE moves with the pointer and is shown once (no copy left at the top); pink snap guides
  appear at the box centre and edges. After release FREE sits where dropped, drawn on top of the card.
- Step 5: the box X / Y did not change. Header on the border and Behind the header are gone; a Reset header
  position button shows under Header text.
- Step 6: after reload FREE is still where you dropped it; the top border has no gap.
- Step 8: the box moves with FREE inside it at the same spot; no dashed outline is left behind during or after the
  drag.
- Step 9: the outline turns with the box; FREE moves along the box's own direction; the box X / Y / Rotation 90
  stay as set.
- Step 10: FREE goes back to where it was before step 9's drag.
- Step 11: FREE returns centred on the top border, the border breaks behind it, and Header on the border (ticked)
  is back.
- Step 12: the second tag template's box shows the header at the same moved spot (owner Q5 a: the position is part
  of the saved accessory template). Detach on a box keeps a one-off.
- Step 13: FREE prints at the same spot as in the designer, over the card, plain text (no white patch).
- Any template not touched in this test looks exactly as before.
