# Hand test: PR #2278 PRICETAG-HEADER-DRAG (the accessories box header as a normal design element)

Round 1: drag the header ("FREE") anywhere inside its box. Round 2 (owner 9 Nov ~17:00): click the header to
select it; it then resizes with the usual handles and is styled in the Inspector like a text element (font, size,
weight, colour, alignment, line height, padding) plus Background (colour or Transparent = none) and Corner Radius.
The cards never move with it. The print sheet / PDF draws the header exactly as the designer shows it. Reset header
puts position, size and style back to the default look. A template nobody touched looks exactly as before.

crew test copy

## Setup
1. Sign in with your own login (Tag templates manage).
2. Pick a scratch tag template you can change, or create one: Dealer Kit > Room Designer > Tag Templates >
   New Template, name `Header drag hand test`, price type LP, Create template.

## Steps
1. From the sidebar open Dealer Kit > Room Designer > Tag Templates and open the scratch template.
2. Click the Add Accessories button in the toolbar, then Default box.
3. Click FREE (the box header) once.
4. Drag the header's bottom-right handle right and down by about 1 cm; release.
5. In the Inspector set Header text to `ACCESSORIES INCLUDED FREE`.
6. In the Inspector open Background and type `#1f4d36`; set Colour to `#ffffff`; set Corner Radius to `2`.
7. Drag the header (press inside it) down onto the second card; release.
8. Press Delete once, then Escape once.
9. Click Save, then reload the page; click the box once.
10. With the box selected click Save as accessories template, name `FREE green pill`, Save; then click the header.
11. In another tag template, add the saved accessories template `FREE green pill` from the Add Accessories menu.
12. Back in the scratch template click the header, then click Reset header in the Inspector.
13. Print or download a tag sheet for a request line using a template with a styled header (Price Tag Requests >
    a request > Download); compare the header with the designer.

## Expected
- Step 3: the box's handles go; the header gets its own handles (no rotate stalk). The Inspector shows Header:
  Header text, X / Y / W / H, Font Family, Font Size, B / I / U / S, Font Weight, Colour, Align, Line Height,
  Letter Spacing, Padding (mm), Background, Corner Radius, Reset header.
- Step 4: the header band grows in width and height independently; FREE stays centred in it; the cards do not move.
- Step 5: the text wraps onto two lines inside the band, centred, at the same font size.
- Step 6: the band turns dark green with white text and rounded corners, on top of the card.
- Step 7: while dragged the header keeps its green fill, wrap and colour and is shown once; it lands where
  dropped; the box X / Y do not change.
- Step 8: Delete does nothing (the box stays); Escape goes back to the box (box handles and box Inspector).
- Step 9: the header is still resized, green, rounded and where it was dropped.
- Step 10: the Inspector shows `Linked: FREE green pill`; with the header selected a strip under the toolbar says
  `Linked to FREE green pill: changes here update 1 tag template` with Detach.
- Step 11: the new box's header has the same size, spot, green fill, white text and corners.
- Step 12: the header returns centred on the top border in the default green text on white, square, single line;
  the text `ACCESSORIES INCLUDED FREE` stays. Header on the border is back in the box section.
- Step 13: the PDF header has the same spot, size, fill, corners, colour and line breaks as the designer.
- Any template not touched in this test looks exactly as before.
