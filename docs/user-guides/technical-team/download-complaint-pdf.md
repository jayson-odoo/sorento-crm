# 7.6-Technical Team — Download a complaint as PDF

How to save a complaint as a PDF file. The PDF is generated in the background and collected from the **Downloads** panel — it does not download the instant you click.

## Where

Open [**Complaint Management → Complaints**](/complaint-management/complaints) → click the complaint you want → the top action bar has the **Download PDF** button.

## Steps

1. Click **[Download PDF](#guide_target=complaint-management.complaints.download-pdf)**. The button shows **Preparing…** and a message confirms *"Preparing PDF… it will appear in My Downloads."* The file is now being built in the background — you don't have to wait on this button.
2. Next to it is a **printer icon** with a small number badge — click it to open the **Downloads** panel for this complaint.
3. In the panel the file appears with a status: **Queued** → **Processing** → **Ready**. It refreshes itself every few seconds.
4. When the status is **Ready**, click the file row. The PDF opens in a new tab / downloads to your computer.

## Notes

* The PDF is the same whether you open it immediately or come back later — it stays in the Downloads panel, so you can close the complaint and collect it afterwards.
* If the status shows **Failed**, click **Download PDF** again to re-queue it.
* The number badge on the printer icon is how many generated files are waiting for this complaint.
