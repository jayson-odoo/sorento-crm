# UAC — TCK-2026-000031 — User↔RespondContact link + phone + per-channel prefs

Spec: [../TCK-2026-000031.md](../TCK-2026-000031.md). Foundation — validate before 29/30. See [protocol](./README.md).

## Functional

- [ ] **AC-31-F1 [F] — Admin set phone + link + toggles, resolve works.**
  Admin sets `contact_number`, picks a RespondContact, flips `notify_whatsapp` on → persists; `resolve_user_respond_io_id(user)` returns that contact's `respond_io_id`.
  **Validate:** `pytest tests/test_user_respond_link.py::test_admin_link_and_resolve` + `curl PUT /api/v1/user_management/{id}`.

- [ ] **AC-31-F2 [F] — Auto-link by phone + resolution order.**
  With `respond_contact_id` unset but `contact_number` uniquely matching a RespondContact, `resolve_user_respond_io_id` returns the id and caches it on the user. Order: explicit link → phone match → None.
  **Validate:** `pytest tests/test_user_respond_link.py::test_auto_link_phone_match_and_cache`

- [ ] **AC-31-F3 [F] — E.164 normalization.**
  `012-3456789` and `60123456789` normalize equal; saving the local form stores E.164 and matches a contact stored either way.
  **Validate:** `pytest tests/test_phone_normalize.py::test_e164_my` + save-form smoke.

- [ ] **AC-31-F4 [F] — Unique phone constraint.**
  Saving a second user with a phone normalizing to an existing user's number → 4xx, not silent overwrite.
  **Validate:** `pytest tests/test_user_respond_link.py::test_duplicate_phone_rejected`

- [ ] **AC-31-F5 [F] — Backfill idempotent.**
  `scripts/backfill_user_respond_contact.py` links unique matches; second run changes nothing.
  **Validate:** run twice in a test DB; assert second run reports 0 changes.

- [ ] **AC-31-F6 [F] — Picker shows no UUID.**
  The RespondContact picker renders name + phone only; no UUID visible in the UI.
  **Validate:** Playwright MCP snapshot of the picker — assert label text has name/phone, no UUID pattern.

## Data

- [ ] **AC-31-D1 [D] — Schema.**
  `users` has `respond_contact_id` (nullable FK → respond_contacts), `notify_whatsapp`, `notify_whatsapp_summary` (bool, default false); `daily_sla_summary_subscribed` retained; unique constraint on `contact_number`.
  **Validate:** `psql -c "\\d users"` + constraint listing.

## RBAC

- [ ] **AC-31-R1 [R] — Self vs admin scope.**
  A non-admin can edit only their own channel prefs (self-service endpoints); admin can edit any user's via user-management.
  **Validate:** `pytest tests/test_user_prefs_rbac.py` (self editing another user → 403).

## UX

- [ ] **AC-31-UX1 [UX] — Both surfaces expose matrix, round-trip.**
  Admin user-profile form AND self-service account settings expose phone + (admin: picker) + the channel toggles; values round-trip on reload.
  **Validate:** Playwright MCP — User Management → user → set fields → save → reload assert; Account settings → toggle → reload assert. Vitest for the shared toggle/picker components. No console errors.

## Scalability

- [ ] **AC-31-S1 [S] — Indexed resolution (XS4).**
  `respond_contact_id` FK + `contact_number` unique index exist; `resolve_user_respond_io_id` is a single indexed lookup, not a scan.
  **Validate:** `EXPLAIN` on the resolve query shows index usage; constraints present in `\\d users`.
