# CONTEXT-MAP

This repo's ubiquitous language lives in the glossary below. Read it when working in
the area it covers.

| Glossary                   | Covers                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------ |
| `documentation/CONTEXT.md` | Project Sales (module `projects`), Company vs Tenant, Core vs Module                                    |

meanings is a defect - fix it rather than picking a winner.

design, After-sales, Supply and purchasing) was planned but never committed, so only
`documentation/CONTEXT.md` exists today. Add a row here when another glossary lands.
