Quotation: Certification tab (mock v1)

Owner ask of 8 Nov. One new tab on a quotation listing the distinct certificates of the quoted products, with the quoted product's row boxed on each certificate, editable, and sent to the customer as a PDF. Static mock, masked data. Every screen below names the existing component it is built from (map at the bottom).

1. The tab: Certification (standard list view)

Quotation document detail, new last tab. Rows = distinct certificates of the quoted products (via the existing certificate_products links), plus any added by hand. One row per certificate even when it covers several quoted products; the "Quoted products" cell lists them all. Row click opens the certificate (screen 2).
