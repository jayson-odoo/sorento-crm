22 rules. The first rule that finds something wins. 5Columns
  1. 1
    Rules have their own tab, as a data gridOwner ruling, 27 Sep 2026: "rule should be in own tab and don't need advanced, should be basic and non technical". One row per rule, in the order they run. Drag the handle, or use Move up / Move down in the row menu, while the grid is sorted by Order.AC-S1.11, AC-S1.14, AC-S1.9; plan D14
  2. 2
    Finds, in plain words, edited in placeWhat the rule looks for: words ("MATT BLACK"), a number ("the number before OZ"), a size, or a code ending ("ends with -GM"). Click the cell to change the words (shown open on rule 4). No pattern exists anywhere to show.AC-S1.14, AC-S1.6; plan D5
  3. 3
    Answer is a pickThe choice the rule gives, picked from this specification's own choices when edited in place. Number and size rules read "the number it finds".AC-S1.14, AC-S1.5
  4. 4
    Add a rule, or the pencil in the row menuOpens the rule form (mockup 4) for the parts a cell cannot hold: Looks in, the kind of rule and Only when.AC-S1.7
  5. 5
    Nothing else on the tabNo Advanced, no pattern, no "Changed here", no "Put back the built-in rules", no re-read (owner rulings, 27 Sep 2026). Removing a rule is a 5 s countdown with Cancel (rule 13 shown), and saving updates the products it changes by itself.AC-S1.10, AC-S1.16; plan D8, D10
