Gmail clips a body above about 102 KB: about 165 lines on the request email and about 145 on the reserved email. "View entire message" still opens every row. Real volume on the dev copy: 71 request lines in 30 days from one requester, and the per-CS split makes each email smaller again. Reason lines add to these figures. A test pins the 110-line size.

On a phone (375 px) the email measures about 640 px wide (request) to 710 px (reserved), so the reader scrolls sideways, heading included. A wrapper that scrolls only the table did not help in the app's table-based layout, so none is added.

A one-OI email uses the same table, and its button goes straight to that OI's page. Several open requests on one OI now land in one email, because without #n separate emails would look like duplicates.
