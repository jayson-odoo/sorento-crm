### 1.2 Rulings applied

- Ladder v3 (section 1b): beyond the window Buy the whole line; inside it own group first (own location included, available only), then the site pools, then other locations' available; group borrow is a manual pick. Dealer hot-selling products keep the BRW pool for retail (3.3a gate stays).
- An OI ORDER row is raised only for a Buy, one row per SO line, full quantity, `stock_location` = the SO line's warehouse (BRW-IB).
- ORDER BACK (part 2 4b): verb `ORDER_BACK`, set by the Order Inquiry Form upload when the delivery-date cell reads ORDER BACK, or by Amend on the board. Only an ORDER BACK row may link to an SPO. Its walk: the cited document first, then SPO allocations, then PO lines.
- Link tiers (Q5): same location (BRW-IB) > same group other site (DC1-IB, MWH-IB, WH3-IB, RSW-IB) > site pool (BRW, then MWH / DC1 / WH3 / RSW) > sibling locations at the site (BRW-BB and other BRW-*). Never filtered, only ranked; a link outside tier 1 reads "location differs".
- Cascade date (Q7): PO issue date first, then line expected date, then document number. Partial links allowed; row state raised / partly linked / linked.
- The form is the oracle: a cascade that lands elsewhere than the cited document is a finding, recorded in Actual, not a failure. A cited document absent from the system is recorded, never skipped (AC-J2).
- SO import refuses an order without a demand class (part 2 QP1); SO381895 is classified project, so the re-upload for part 3 passes.
