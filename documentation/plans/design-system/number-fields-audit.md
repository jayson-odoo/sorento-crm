subagents. Plan: `PLAN-number-fields.md`. Paths relative to `sorento_crm_frontend`.

Classes:
- SNAP: controlled numeric state with coercion on change; the user cannot clear the field.
- SILENT: field can be emptied, but on save empty/invalid becomes 0 / 1 / null / min or is dropped, no message.
- SILENT-OPT (area A) / OTHER-optional (area B): optional field, empty means "no value" (null) by design.
- STR-OK: string draft, parsed and checked on save with a visible message.
- STR-GATED: string draft, Save disabled with no message (never-stuck gap).
- RHF-OK: react-hook-form with a schema message on submit.
- FILTER: list filter / search / non-persisted control.
