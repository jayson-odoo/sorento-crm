Questions for you

Which options do we ship?Recommendation: A + B + D now (shift+click, checkbox drag, keyboard) in the shared component, so all ~140 selectable grids get them at once. C is a separate question below.
Should drag also UNtick?Recommendation: yes, the first box decides. Pressing on an unticked box ticks the run; pressing on a ticked box unticks it. Dragging back up restores what was there before.
On a phone or tablet, what does a finger do on the checkbox column?Recommendation: tap only, no drag. A finger swipe on a list must keep scrolling it. Shift+click and keyboard do not exist on touch, so phones keep tap-per-row plus the existing "select all on this page".

Each option on its own

What stays exactly as it is

Text selection and copy

Drag only starts when the press lands on the checkbox column. Pressing on any other cell is a normal text selection.

Row click and inline edit

A click on the row still opens the record. Buttons, links, inputs and menus inside a cell keep their own clicks. A drag never opens a row.

Header box and bulk bar

The header checkbox, the "N selected" count, the Actions menu and Clear behave as today. They just fill faster.
