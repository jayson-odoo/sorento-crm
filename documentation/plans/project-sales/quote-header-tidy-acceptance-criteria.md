# UAC: QUOTE-HEADER-TIDY

1. A proposal or quotation with several areas shows exactly one "Issued by" and one "Opened" in the Header's
   right-hand block, no per-area labels. The values are those of the most recently opened issued area version
   (any current version when none is issued).
2. The record card under "PRJQ-xxxx Draft v1" reads the project's short name; with no short name, the title.
3. The Header section shows a "Project" row with the document's full project title, clamped to two lines with
   an expand control when long.
4. In view mode, the Header card and the Lines card each fold and unfold from their heading; folded, each shows
   a one-line summary (Header: To, title, date, total; Lines: N scopes, total).
5. Same behaviour on a phone (375px) and desktop (1280px), no sideways scroll.
