# UAC: Project Sales polish (13 Oct)

| AC | Point | Criterion |
|---|---|---|
| AC-PSP01 | 1 | The sidebar, page title, crumbs and back links say "Projects" or "Back to projects". The URL stays /project-sales/pipeline. |
| AC-PSP02 | 3 | Register project is disabled until a lead is picked. Edit stays optional. |

| AC-PSP09 | 9 | The lead tab is "Assignment", with no acceptance chip repeated inside its card. |
| AC-PSP10 | 11 | The Projects grid's Brands column is one line of pills with a "+N" overflow. |

| AC-PSP12 | 13 | "Filing reference" reads "Reference" on the Overview and the form. |
| AC-PSP13 | 14 | The Overview cards sit in one even grid (two columns at md and up, one on a phone). Critical runs full width below. |
| AC-PSP14 | 15 | Nothing is printed under the project title. |
| AC-PSP15 | 16 | The stage label is "Spec In". Making it opens New quotation. Back to registered is available from Spec In. |
| AC-PSP16 | 17 | The Tasks empty state has no second add button. |
| AC-PSP17 | 18 | A new quotation's Name, Phone and Attn default from the project's customer, and fall back to the developer. |
| AC-PSP18 | 19 | The Overview shows a Customer card: name, phone and main contact. |
| AC-PSP19 | 20 | A pen beside the scope name opens Edit scope (name and series). No series text in the scope header. |
| AC-PSP20 | 21 | Remove scope is a red destructive button with a trash icon. |
| AC-PSP21 | 2 | Answered in the PR card: Outcome is derived from the quotations (won, lost or open), not from the stage. |
