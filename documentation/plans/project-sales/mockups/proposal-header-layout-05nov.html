4. Behaviour card v3: 5 questions, each with a recommendation (still open)

Q1. Pager: should proposals get one, over what list?

They already have one: prev/next over this project's proposals and quotations, shown once the project has two or more (QuotationDocumentClient.tsx:350). People reach the page from the project's Proposals tab, so the project's own list is the right one, not a global list.

Recommend: keep it as is, in the OI position (left of the gear).

Q2. Should "Edit opens the next version" survive somewhere?

Edit sits in the gear and, on a version the customer holds, already opens a prompt naming the scopes and the version it will create (ReviseToEditDialog.tsx). A tooltip does not work on a phone.

v3: the lines block carries a twin of it too ("The customer holds v1. Edit quotation opens v2 and leaves what was sent untouched.", QuotationVersionEditor.tsx:747-751); the same answer covers both.

Recommend: drop the text everywhere, both places; the Edit prompt already says it at the moment it matters.

Q3. Quotation: same page as proposal, or separate?

Same page. One route serves both; only the noun changes (documentNoun, app/(protected)/project-sales/_shared/services/quotationDocumentService.ts:213; tabs QuotationDocumentTabs.tsx:32). So both change in this PR. (The older per-scope page project-sales/[projectId]/quotations/[quotationId] has no link to it in the app and is not touched.)

Recommend: one change, both get it.

Q4. The two other hint lines under the buttons ("With a manager for approval", "You can read this quotation but not change it.")

You struck only the "customer holds" hint. These two still matter (the first explains why there is no Send button while approval is pending).

Recommend: move them onto the subtitle line ("test · Not viewed yet · With a manager for approval"), so nothing hangs under the buttons.

Q5. Record outcome (new in v2): where does it go now the area header row is gone in view?

(a) In the gear, "Record outcome: <open area>", acting on the open area tab (frame 2b). (b) In the area tab's own menu (right-click, or the ⋯ on a phone), the way the edit form already offers Rename / Remove scope (QuotationScopeTabs.tsx). (b) is hidden on a desktop until you right-click.

Recommend: (a), the gear, because that is where every other secondary action on this page lives and it is visible on desktop and phone alike.

Default, not a question: Order Inquiry also switches to the shared header card (no visible change) so the two cannot drift; the ~12 other pages that copy it wait for later.
