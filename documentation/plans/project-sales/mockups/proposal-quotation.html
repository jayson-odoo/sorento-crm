Proposal and quotation (PS-PROPOSAL-QUOTATION)

Five screens: the Proposals tab, issuing a proposal revision whose price moved, "Make quotation" on a won project, the quotation with a further discount waiting for approval, and a PO above the quoted quantity. Callouts map each element to the existing component it changes. Every new word is in the screen; no help text.
