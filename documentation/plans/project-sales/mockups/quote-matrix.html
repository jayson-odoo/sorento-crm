Quotation grid scopes, mock v3

Owner notes on v2 (2 Nov 23:11), drawn here: (1) columns are configurable: answered on the page next to the header; (2) every existing quotation column stays around the grid (product code, brand, UOM, rate, complete set, rate only, photo, drawing); (3) "Bathroom" is the existing section heading: answered on the page; (4) columns are set up in the table itself, no separate screen; (5) no Accept / Reject: the customer leaves feedback notes per item or per cell, and the salesperson reads them and acts freely, at most ticking one as handled.

Unchanged from v2: one engine for every quotation (a scope without columns is today's quotation), the real quantity punched into each cell, totals per column / per column header / per row, same product on several rows, no Excel import. Rates and counts are made up; every total is computed from the cells shown. Rules: documentation/plans/project-sales/CARD-ps-quote-matrix-02nov.md.
