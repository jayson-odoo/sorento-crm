# PLAN: Project registration from the portal (PROJECT-REG-PORTAL)

Status: research, card v2 filed for owner answers (25 Oct). Track: full (one additive migration, new permission).

Salespeople register a project from the portal, the same way they submit a sample request
(SR-CORE #1718) and a new product code application (NPA, #1769). The CRM checks it before it
becomes a row in Project Sales > Projects.
