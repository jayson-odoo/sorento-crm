Sample Request form, mock v3 (create / edit)

After the owner's hand test (16 Oct): the section-by-section form is dropped. Staff and portal forms now follow the Purchase Request / Sponsorship Form screens: one document card with the header fields on top, then the product lines in a table (one row per product, a product search box in each row), then the footer fields, in the paper Consignment Requisition Form's order. Customer is the same searchable customer box PR / SF use. Data: paper Form C (10 Oct), company and product names only.

Unchanged from v2: the list, the detail page (it already uses this document card, so create, edit and view now look the same), the portal landing and the printed requisition.
