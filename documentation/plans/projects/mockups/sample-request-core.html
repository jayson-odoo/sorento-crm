Sample Request (SR-CORE) mock v2

Rebuilt after the owner's notes on v1 (16 Oct 08:54). Every element is an EXISTING component, and the notes beside each frame name it with its repo path. The portal form copies the Price Tag Request form (plain page, collapsible sections, same pickers). The staff pages copy Purchase Request / Sponsorship Form / Stock Inquiry. They show the current status as a pill only (no submitted → processing flow), and a status move is one plain button per allowed move. Data is built on the real Form C (10 Oct), with people shown as roles.

What changed from v1: no branded portal header (note 2, 3); the project picker is the portal's existing AsyncCombobox (note 1); the staff request page has no status strip and uses the PR/SF/SI page layout (note 4); the list is the DataGrid + DataGridListToolbar those lists use, with "Create" in the toolbar (note 5). New / edit opens a full page, like New Purchase Request, instead of a modal.
