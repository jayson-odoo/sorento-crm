4. How one message is matched (same for every list)

numbered steps, plain markup; links to View B for a real turn
  1. Split the customer's own line (not the quoted reply) into words; also every run of up to 3 words.
  2. Look up each word or run in the vocabularies above: exact first; near spelling only for 4+ letters, trigram score ≥ 0.55 (product codes: ≥ 0.5, or 0.30 when no code holds the word exactly).
  3. Write lines under "Candidates for words of this message" (max 12 candidate lines, 12 file lines), then the held products' lines under "On record for the held products".
  4. Parser reads the static rules + these lines and picks a listed item or none.
  5. Grounding checks every pick against the same tables and drops what is not on them (warehouses included), then the tool runs.

A word nothing matches gets no line; the ask paths handle it. No word is special-cased in code: every match comes from the tables above.
