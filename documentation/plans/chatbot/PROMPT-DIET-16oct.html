9. Method and caveats

  • Sections split at == X == headings, banner titles and the policy block marker; tokens with tiktoken o200k_base over the raw template.
  • Readers: every parser key traced through PARSE_OUTPUT_JSON_SCHEMA (chatbot/head/parser.py:85-683, 58 required keys) to its consumers. app/schemas/ai_semantic_parser.py is an older schema used only by ai_assistant_service.py, not this parser.
  • TRAIN mapping is by each section's trigger (markers in the recorded context, words in the message); counts for broad sections (18, 21, 22) run high and a "0" can hide an item the trigger missed. Item text is never copied here; only ids.
  • "After" tokens are estimates of the rewritten section, to be replaced by the real count of each stage's version.
  • Untouched: CHAT-ADVISOR-SPIKE work (#1720, #1730, #1731, #1737, F5 typed_as).
