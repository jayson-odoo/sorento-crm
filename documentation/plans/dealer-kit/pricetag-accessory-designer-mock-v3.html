One card layout, any accessories: mock v3

07/11/2026. Answer to: "how do we make sure it applies to every accessory or specific accessories, some got the dot, some don't, some product / combo has 2 accessories, some have 3".
You design this ONCE, in the Tag Template designer Comes from the data (the product's / combo's own list), different on every tag

1. What you design once: a card made of slots, not of a colander

You never design "the colander card"

You design ONE card with slots. Each slot says which field of an accessory it shows:
  • Picture slot shows that accessory's picture
  • Name slot shows its name
  • Spec lines slot shows its spec lines
  • Colour dots slot shows its colours
On a tag, the box makes one card per accessory in that tag's list and fills the slots from each accessory. Whatever the product or combo lists, 1, 2, 3 or more, chopping board or colander, they all use this one card.
In the designer with no product previewed, sample text shows in the slots (as today). Pick a preview product to see real cards.

Rule: a slot whose field is empty for that accessory does not print. A slot sitting directly under it in the same column moves up into its space (V7). Every card in one box keeps the same height so the stack or row lines up (Q1).

4. Questions

Q1. One accessory has less to show (chopping board: no spec, no dots). Card height? (a) every card in a box the same height, recommended: rows and stacks line up like your printed Dealer Kit box / (b) each card only as tall as its own content (vertical boxes only).
Q2. One accessory needs to LOOK different (not just different text)? (a) not now, recommended: no real tag needs it yet; different wording or picture for one product is already the list-entry pencil (P1), and an empty field already hides its slot. Built when the first real tag needs it. / (b) build now: an "own card layout" for one accessory in the library.
