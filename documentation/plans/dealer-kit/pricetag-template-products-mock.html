Behaviour, as built (recommendations taken)

  • Only dealer_kit.tag_templates.manage sees the Products button. Salespeople and the request form are unchanged: they pick from what is linked.
  • Link never changes a default a product or combo already has. A product with no links gets this template as its Default LP / SP (for the price types it fits) because it is its only one. A product with one link keeps that one as default when this second one is added.
  • The product page "Price tag templates" card and the combo's template field read and write the same rows, so a link made here shows there at once, and the other way round.
  • Archived templates have no designer, so nothing here touches them.
