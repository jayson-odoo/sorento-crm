Each tap tile is ordinary picture, code, description and price layers whose subject is "Picked option 1", "2", and so on. The template decides how many tiles (its tap count); the salesperson decides which taps fill them.

A tile not yet filled shows dashed on the preview and Approve stays off until every tile is filled. A tile never falls back to the sink.

Price under each tap: the package price with that tap (the option's SP) when the combo stores one (Q-B). Headline SP: the combo's SP, or the SP the salesperson typed when the combo has none.
