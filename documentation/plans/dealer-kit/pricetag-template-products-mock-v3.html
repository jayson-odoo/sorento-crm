Behaviour

  • Only dealer_kit.tag_templates.manage sees the Products button. Salespeople and the request form are unchanged.
  • Link never changes a default a product already has. A product with no template gets this one as its Default LP / SP (for the price types it fits); one with a single template keeps that one as default. Unlinking a product's default leaves its remaining lone template as default. Today's rules in product_tag_template_service (bulk_assign, _lone_link_is_default).
  • The product page "Price tag templates" card reads and writes the same rows, so a change made here shows there at once, and the other way round.
  • One Save adds or removes at most 500 products, the picker's existing cap; the footer says so when the change is larger.
