7. Fit: cards shrink together, then whole cards only, never cut (F1-F2)

8. Questions (also in the card)

  1. Saved template changed: (a) copy on apply + "update this box" note, recommended / (b) live link with Detach / (c) (a) plus "also update the N templates" tick.
  2. Shrink minimum: (a) 70%, recommended / (b) 50% / (c) no shrink, warn only.
  3. Which colour picture prints: (a) chosen on the list entry, default first; dots show all, recommended / (b) match product colour (needs product colour first).
  4. Footer dots: (a) all colours in the box, de-duplicated, recommended / (b) picked by hand.
  5. Where saved templates are managed: (a) only the designer's Accessories menu, recommended / (b) also a list page like Tag Sizes.
