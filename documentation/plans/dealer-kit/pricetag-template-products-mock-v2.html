Behaviour

  • Only dealer_kit.tag_templates.manage sees the Products button. Salespeople and the request form are unchanged.
  • Link never changes a default a product already has. A product with no template gets this one as its Default LP / SP (for the price types it fits); a product with one keeps that one as default. This is today's rule in product_tag_template_service.bulk_assign.
  • The product page "Price tag templates" card reads and writes the same rows, so a link made here shows there at once, and the other way round.
  • One Link or Remove takes at most 500 products, the picker's existing cap; the footer says so when the pick is larger.
