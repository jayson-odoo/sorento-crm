New Product Application, mock v2

Lane NEW-PRODUCT-APP, 17 Oct. v2 = v1 + crew answers (17 Oct): Q2 approval, lock and Revise copy the owner-approved quotation approval (#1698): approvers are holders of the approve permission in the company; Submitted and Approved are locked; Revise asks "What changed, and why?" and goes back to Draft (no snapshot, no revision number; the audit trail keeps the reason and old values); a Rejected application is edited and sent with the same Submit. Q3 inquiry link optional, Q4 many lines each linked on its own, Q5 description, item group and base UOM required. Q1 (staff only now) is with the owner; this mock is staff side. New in v2: frame 3b (Rejected, and the Revise dialog); the Revisions box is gone. Every callout names the existing component and repo path it is built from. FE = sorento_crm_frontend/. Data is illustrative: no real customers, people or codes (public repo); the real dev examples come from the crew-data-request.

Layout follows the Purchase Request / Sponsorship Form / Stock Inquiry / Sample Request document card: header fields in a 2-column grid, then the product line table, then the footer buttons. View and edit are the same card.
