# Archive

Plans land here once their `Status:` line reads terminal: IMPLEMENTED, DONE, SHIPPED,
MERGED, BUILT, DEPLOYED, COMPLETE, CLOSED, SUPERSEDED, or ABANDONED. Structure mirrors
`documentation/plans/<domain>/`, so a plan's original path is `_archive/<domain>/PLAN-<slug>.md`
(no domain folder for plans that lived directly under `documentation/plans/`).

Git history holds each file's original path (`git log --follow`) and every prior revision.

Do not edit a file here further - update the live plan under `documentation/plans/<domain>/`
instead if the work resumes, and move it back out of `_archive/` when it does.
