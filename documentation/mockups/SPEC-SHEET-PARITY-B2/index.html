F. Cover stuck on "Fetching image"

Cause (code read on 0ef9310c): the image draw shows "Fetching image" whenever it has a URL but no loaded picture (KonvaTagLayer.tsx:658-665), and useHtmlImage.ts:48-50 treats a FAILED load the same as "not loaded yet" (sets null, no error state). So a picture that cannot be downloaded reads "Fetching image" forever. The URL is a signed thumbnail / medium rendition from storage (project_spec_sheet_service.py:905 _asset_urls -> asset_service.py:261 screen_urls_for); on the test copy that storage request fails (same cause as the font 502s crew saw). Proposed: a failed load shows "Image not available" (grey box), and a load in progress stays "Fetching image".
