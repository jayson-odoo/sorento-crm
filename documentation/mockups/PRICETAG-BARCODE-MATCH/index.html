Every image below is the real output of barcodeSvg() (lib/dealer-kit/barcode.ts), the same string the Room Designer canvas, the request preview and the PDF draw. Product SRT6638-DIY, EAN-13 9551028475956 (the staff barcode the owner shared).

What each part reuses

  • Barcode layer box, position, rotation, "Show product code" toggle: unchanged (lib/dealer-kit/tag-template-types.ts, Inspector panel).
  • Value and code binding: unchanged (resolveBarcodeValue, resolveSlotText in lib/dealer-kit/product-block.ts).
  • Symbology rule: unchanged (barcodeSymbologyFor: checksum-valid 13 digits = EAN-13, else Code128).
  • Canvas draws it as a Konva image over the layer box (KonvaTagLayer.tsx BarcodeContent, image loading via useHtmlImage).
  • Preview (components/dealer-kit/ScaledSheet.tsx) and PDF print page draw it as one <img> over the layer box (TagSheetRenderer.tsx BarcodeLayer).
  • Gone: the black header strip with white bold code, the single centred digit line, the stretched (canvas) vs letterboxed (print) bars.
