How it behaves

  • Click a dimension in the menu to add it as the next level; click it again to remove it. Level order is click order (Odoo's own way), so to reorder you untick and tick again. The chip's ✕ goes back to Location alone.
  • Location first: today's rows, sets, subtotals and Total stay; a location (or a set's subtotal row, over its whole set) opens its next level instead of the drill-down. Location alone opens today's drill-down, unchanged.
  • Group rows: name, line count, sums of On hand, SO qty, SPO qty and PO qty; Available, Available for Project and Taken blank. Negative figures red, as today.
  • Groups A to Z, "No ..." last; locations in today's order; a group exists only when it holds a line. Lines inside a group keep the read's order (by due / expected date).
  • Groups start closed; Expand all / Collapse all open or close every level.
  • The last choice is remembered in this browser and used on all four screens. A table without the AutoCount read (Borrow dialog, or the read failed) shows no bar and today's table.
  • The Fulfilment Planning dialog's search keeps today's meaning: it narrows the document lines and opens the groups holding a match; group figures stay.
