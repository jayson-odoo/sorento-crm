Rules (behaviour card + owner answers, 2 Oct 2026)

  1. Got stock / no stock is a tick / cross: ✅ and ❌, never the words. Every line starts with "CODE x Q:".
  2. Has stock but less than Q, with Q within the category max: ✅ N available, nothing else (Q1 a). Above the category max: 🚫 "the quantity is more than what I can confirm here", no count (Q5 a; 🚫 added in v2).
  3. ETA ask: one compact line per product, CODE: ✅ ETA dd/mm/yyyy, or CODE: No ETA (owner hand test, 3 Oct 2026).
  4. Exact codes only: an exact code never brings its family; an unknown code gets the did-you-mean; a number on a list is that option (owner hand test, 3 Oct 2026).
  5. Pickers never offer "all", and refuse a bare "all" / "semua". The list stays open. Typing every number is a pick and is answered (Q4 b).
  6. Several codes in one message get one reply, in this order: answered lines in the order asked, then Couldn't find: X, Y., then at most one question. Every vague code gets its picker in the SAME message (Q3 changed to b in v2), numbered on from the previous list so no two options share a number. A code named twice is one line with the quantities added up (Q2 a).
  7. Full mode (staff) is unchanged. There is one parser prompt; every difference lives in the reply code.

Points to confirm

  1. v2: numbering when several pickers share one message (S21). Proposal: one running number across all the lists. SRTWC286 options are 1 to 10, SRTWC6022 options carry on at 11 and 12. A reply like "2 and 11" picks one from each, and "2 of 3" style quantities work the same way. The dealer may answer one list at a time: the answered code is answered, and the lists still open are asked again with their numbers unchanged (S21b). Alternative: letters per list ("A2, B1"). It is not recommended: the parser would have to learn a new reply shape, and the owner asked for one prompt.
  2. v2: "2 of 3" (S36 to S39) means quantity 2 of option 3. The number after "of" is always the option. The parser reads it into the same open-question answer it already returns for "the first one, I need 2". No prompt change is planned; if the live parser misreads "2 of 3", that goes to lane PARSER-PER-AUDIENCE as a prompt example.
