Ideas inside Sorento CRM: one mock per CRM screen

Lane IDEATION-IN-CRM, Option C (owner, 2 Oct): the CRM renders Ideas with its own components and calls the shared-service Ideas API through the CRM backend, so there is no iframe and no shared-service domain in the browser. Layout follows the approved IDEATION-COMMENTS mock v2 (vote box, comments, "Move to <next>" + Edit), rebuilt from existing CRM pieces: PageHeader, DataGrid, Badge, RecordNavigation, line tabs, DetailActions menu, Dialog, FileDropzone, Kanban, deferred-action countdown. Ideas, submitters, votes and dates are real dev data (shared-service dev tenant, as in the IDEATION-COMMENTS mock); comment texts are SAMPLE text, since dev has no comments yet. Dates use the CRM format (dd/MM/yyyy). Numbered notes mark what is new; yellow notes are open questions.

1 Ideas list (sidebar > Ideas, route /ideas)

Standard CRM listing: DataGrid with fixed layout and resizable columns, toolbar search, status filter (SearchableSelect, clearable), Columns menu, List / Board switch, one CTA "Capture idea" in the page header. Hidden columns and widths save per user in the CRM's own list preferences (fixes owner feedback 1). Each row leads with the vote box from the IDEATION-COMMENTS mock (orange = you voted); clicking it votes without opening the idea. Rows open /ideas/{id}.

7 Merge and promote

Both from the idea's "..." menu, both CRM Dialogs. Merge: pick the idea this one merges into (SearchableSelect over active ideas); its votes and comments stay with it, and the target lists it under "Merged ideas". Promote only works for a CRM user whose email is also a shared-service user with BR access; otherwise the shared-service message is shown (crew answer Q3).
