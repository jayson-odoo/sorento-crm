Both files are parsed in the browser (the existing parseExcelFile, as the Products / Stock compare tab does) and posted to the SAME compare route with a source per file; the server keeps only the summary on the pull, never the rows. A file dropped alone compares alone (the other group reads "not uploaded"). Re-dropping a file replaces its group.

Q3. Which fields count as a difference? Recommendation: lines: Qty, Location (as part of the key), Unit Price, Discount, Total (Ex); headers: Doc Date, Debtor Code, Cancel. Not compared: Created Time (AutoCount sends CreatedTimeStamp with seconds, the sheet a rounded time), Debtor Name (free text drift), Agent (the tracking sheet's Agent is often retyped), Total (Inc) (tax is not on the DO line in the sheet the same way). Say yes/no per field and the compare pins exactly that list.

Q4. May the checker Confirm with differences? Recommendation: yes, Confirm stays enabled and the headline says the differences change nothing (the Products / Stock rule, P11: compare is advisory). The alternative (Confirm disabled until zero differences, or a "Confirm anyway" tick) blocks the whole month on one retyped price in the sheet.

Q5. A DO in the pull that is NOT in the Excel ("Only in AutoCount") is shown the same way. Confirm still creates or adopts it (it is AutoCount's book). Agree?

Q6. Order Tracking's Overall Tracking sheet (transporter, driver, lorry, delivery date) is ignored by the compare because AutoCount has no such fields; the tracking upload stays the writer for those columns. Agree?
