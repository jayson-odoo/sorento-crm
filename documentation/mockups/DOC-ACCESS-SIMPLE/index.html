The rule (one sentence)

A WhatsApp contact reads a document when one of the contact's access types is ticked on the document's type AND is in the document's access levels, and the document is in one of the contact's companies or is shared. Staff (and a contact linked to an active CRM user) read every document of a type with Staff ticked, if they may view Resources. A contact with no access type reads nothing (owner W-Q5 (a)). Sending a file (Direct access, per-contact Document types) is not changed.
