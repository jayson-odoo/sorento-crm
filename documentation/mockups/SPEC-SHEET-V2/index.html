I. Owner answers (3 Nov), as drawn above

Q1. Which revisions?

Any quotation, including before it is signed or issued: the current draft is in the picker (section C). The sheet records what it was built from (R2, or "Draft after R2" + the time).

Q2. Template re-published?

(a) The sheet keeps its versions; "Use latest templates" moves it on purpose (section D).

Q3. Edit page?

(a) This sheet's page only, in the designer (section E).

Q4. New sheet starts from?

(b) Clean every time (section C).

Q5. #2103 settings?

(a) Today's set-up becomes SS1.
