0. Where each list comes from

Rows never come from a lookup set. A new or edited master record is picked up on the next turn and embedded by the next sync (every 10 min, on a model change, or Embed missing; a turn embeds its own misses meanwhile). An alias set is optional and keyed by the record's code.

2. Try a phrase (v2: spelling AND vector, per row)

Scored by the live span resolver code itself (head/list_resolver.py resolve, :344-420), fed the cached gemini-embedding-001 vectors. Each row is compared on EVERY word it carries (label, code, class, alias column, alias set, description words; best word wins), on three signals: spelling (exact = 1.000, else trigram similarity), partial (share of the phrase's words a row word matches) and vector (cosine). A row passes when any signal reaches its list's floor; the strongest passing signal is its score; rows within 0.03 of the best make the phrase ambiguous. Bold green = at or above floor. Scored against Category, File type and Sales channel rows only in this mock (the screen scores every list).
