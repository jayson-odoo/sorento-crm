Customer groups - mockup v1

Lane CUSTOMER-GROUP. Owner answers 2 Oct: a customer_groups table per company, each customer row points at at most one group, seeded from the name rule for the 796 families that hold a numbered account (527 in Sorento, 269 in Mocha; CASH / SHOPEE / LAZADA hold no numbered account so the filter drops them with no skip list), no auto-assign on import, a Customer Groups page plus the customer list / detail / form. All rows below are real rows from the shared dev DB (Sorento company). Every screen is a copy of the Sales Agents list / detail / Customers tab, which already do exactly this for customers.sales_agent_id.
