What changes from v1

  • Each account links only to contacts whose own row tags the account's company (new "Links to" column shows who).
  • Each contact is its own panel: every changed setting as Before → After, one item per line, added items marked "+". Nothing is truncated; the dialog body scrolls.
  • Unchanged settings are named in one "No change" line.
  • "Holds more than the template" lists what is extra, per setting.
  • Accounts already linked outside the row's companies are listed as an info line. Apply never removes them.
  • At 375px each setting stacks: label, Before, After.
