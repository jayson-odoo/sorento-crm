Behaviour card: rules and questions (answer on this page)

Rules
  1. Confirm (N) opens the guide instead of posting at once. Same count, same button.
  2. Three fixed steps: 1 Split, 2 Review, 3 Confirm. Back is allowed; Cancel or Escape closes the guide and writes nothing.
  3. Step 1 Split (required): one page per order in this Confirm, showing the read-only split sheet (saved split lines only) and one button "Split delivery <SO>" that opens today's edit sheet on top; after its Save the page refreshes. An order with no split line shows "No split lines" and the same button.
  4. Step 2 Review: what purchasing will get, per order, from the dry run Confirm already makes (nothing written). An order the dry run refuses shows its reason and is left out, as today.
  5. Step 3 Confirm is today's Confirm: same body, same result card, same toast.
  6. Never stuck: if the dry run fails, Review shows the error with Retry and Back; Confirm stays off.
  7. Unchanged: the board count, "Split edits to confirm", the gear items, admin Simulate confirm, Undo.
