9The owner's question: do item code and UOM sit under the description?

No. Mock v2 put them there; the repo does not.

CRM quotation view (Lines tab), QuotationLinesGrid.tsx:801-958 on main: item code is its own Product column before Description (ProductCell, :305), and UOM is its own UOM column right after Qty (:904-916, "the owner's hand test (UOM beside Qty)"). The Description cell shows only the description (DescriptionCell, :360-366).

Customer sign page, QuotationSignScopes.tsx:64-72 on main: Product code is its own column (after Brand), and there is no UOM column at all. Mock v3 keeps each view's own columns: the sign page's nine on the customer side, the Lines grid's ten on the staff side.
