FULFIL-SO-REMARK mock v1: a Remark per SO in the Confirm guide, printed in the purchasing email

Confirm (N) opens the guide. On each SO page a Remark field sits under the SO header row, prefilled with a default and clearable. It prints in the SO table of the purchasing email beside that SO. On an SO that mixes real and mockup units, the mockup lines show a Mockup badge on the split page and MOCKUP in the email's line REMARK cell. Data: dev copy, read-only (item codes and quantities real; contacts masked as [contact]). Yellow cells and NEW tags mark what is new.
