SO line deliveries and cancellations (mockup v2)

v2 (owner, 14 Oct: "put these in lightbox popup, opened by an icon"). On the Sales order screen's Lines tab, a truck icon on each line opens a lightbox titled "Deliveries · <SKU>". It lists what was delivered against the line (DO lines) and what was cancelled (Cancel SO lines). When the SO has several lines of the product, the DOs and cancels that AutoCount does not tie to one line show in a separate block for the product. Every figure is real, from the shared dev copy (sorento_cagent_stack, 14 Oct).
