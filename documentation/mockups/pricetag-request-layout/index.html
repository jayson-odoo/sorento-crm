3. Behaviour questions (recommendation first)

  1. Several customers: one request with N customers, or N requests?(a) one request holding N customers, one doc number, one approval, one PDF. (b) Approve splits it into N requests. Recommend (a): the tags do not print the customer name, so N requests would be N identical sheets to approve.
  2. Does the printed quantity multiply by the number of customers?(a) no, Qty (tags) is the total the salesperson types. (b) the sheet repeats once per customer. Recommend (a): the salesperson already types how many tags they need.
  3. Preferred default: LP / SP only, or a third "LP & SP" choice?(a) keep two (List price, Selling price); each line can still flip LP/SP, and LP & SP stays a template type marketing sets. (b) add a third header choice. Recommend (a): a mixed request already works line by line.
  4. Preview button vs Approve: same popup?(a) Preview opens it with Close only; Approve opens the same popup with Back to edit + Approve. (b) both show Approve. Recommend (a): Preview stays a safe look.
  5. Requests list and marketing's detail page with N customers.(a) list shows the first customer + "+2", search matches any of them; marketing's page lists all. (b) one row per customer. Recommend (a): lists stay one line per row.
