Decisions to annotate

Numbered like the notes above. Each is a yes / no / change for Lavish.

  1. Card content: customer + contact, Asked, Answered, datetime. Nothing else on the card: no counts line, no age label, no Open link.
  2. Done is the one CTA and sits in the card's top-right badge slot; Reopen replaces it on a done card. The rest of the card is the click target for the conversation panel.
  3. Groups: Needs attention (pinned, by day, oldest first), Today, Done today (greyed), Show done for history.
  4. Toolbar reused from the landing: Filter, Sort (Created default), list / cards. No New button.
  5. List view is the system DataGrid on both mounts, Done as the leftmost column, day groups as section rows, sort and columns remembered.
  6. Note: explicit Save note button and a Saved time; the note lives in the opened card, not on the list card.
  7. Opened card shows the WhatsApp conversation around the ask, the answering turn marked; dealer left, assistant right; "Show the whole day" for more.
  8. Done at the foot of the opened card closes it and clears the row.
  9. Filter fields: Customer, Answer, Asked (day), State.
  10. Sort remembered per user (CRM) / per contact (portal), on the listing preference row the DataGrids use.
  11. CRM opened card adds "Open in Conversations"; portal does not.
  12. Agent select: view_all sees everyone, a team leader their team, a salesperson none.
  13. CRM list columns: Asked at, Agent, Customer, Contact, Asked, Answered, Done by, action.
