3What "configurable, designable" means: form vs canvas Q2

(a) Form-based, as in section 2 (recommended)

Rows on/off, order, labels, letterhead on/off, title, intro and closing text, per design.
  • The cover's content changes length: an empty row is dropped, terms run from 0 to 20 lines and can spill onto page 2. A flowing page handles that by itself.
  • Prints through the same PDF builder as #2088; the sign link and the preview use the same rows, so the three cannot disagree.
  • Reuses the columns panel (tick + drag) and the rich text editor that staff already know.
  • Size L.

(b) Canvas designer like the price tag template editor

Boxes placed freely on an A4 page, fonts, sizes, positions.
Letterhead
Reference
Terms (fixed box: overflows or clips)
  • The price tag editor (TagCanvasEditor.tsx, 4,614 lines, mm positions) is built for fixed-size tags with fixed-length text.
  • Fixed boxes clip or overflow when the terms run long or a row is empty; page 2 spill has no answer.
  • Needs a second renderer for the PDF and another for the sign link. Size XL.

4Quotations already sent Q5

A sent revision re-downloads exactly as it went out. The design is copied onto the revision when it is sent, so editing or switching the design later never changes what a customer already holds.

Sent before #2088 (18 on the dev copy)Landscape only, no cover page, the free-text letter above the prices (none of them have one). Unchanged.
Sent with #2088 (1 on the dev copy)The fixed cover from #2088. Unchanged.
Sent after this follow-upThe design active when it was sent, copied onto the revision; the intro and closing text as typed on that quotation.

6Questions (also in the crew ask)

  1. Q1 Cover Letter tab. (a) It shows the live cover preview, and the free-text letter becomes the design's intro block (recommended: one idea, "the cover", and only 1 of 18 dev quotations has a letter); (b) preview on top with the old free-text letter kept below it, still printing on page 2 above the prices; (c) leave the letter tab and add a separate Preview button.
  2. Q2 Designable. (a) form-based in Quotation Templates as in section 2 (recommended: handles long terms and empty rows, one renderer, size L); (b) canvas designer like price tags (size XL, fixed boxes clip variable text).
  3. Q3 What the form controls. Letterhead on/off, title, rows on/off + order + printed label, intro and closing text with fields. Recommended: exactly these. Not included: custom extra rows with no field behind them, fonts and colours. Unticking Terms prints them after the price table instead.
  4. Q4 Per quotation. (a) the design comes from the template; on a quotation only the intro and closing text are editable (copied in, like terms) (recommended); (b) each quotation can also hide or reorder rows; (c) template only, nothing editable per quotation. Also: one active design per company, like terms (recommended), not a picker on each quotation.
  5. Q5 Already sent. (a) revisions keep exactly what they were sent with; the design is copied onto each new revision at send time (recommended); (b) a sent revision follows the current design when re-downloaded (not recommended: the customer's copy would change).
