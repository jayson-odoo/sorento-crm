6SO draft from the customer PO: the set explodes into its parts

Nothing converts a quotation into an SO today; the SO draft is built from the customer PO and priced from the quotation. AutoCount has no item for a set code, and today's real SOs are written as parts: the priced part carries the set price and the others ride at 0.00 (models/project_so.py:520-524). So a PO line "CWC1009-RL 1,046 SETS" that matches the set line drafts the three parts, the set rate on the pedestal (the set's driver member, product_set_service.py:426), the others at 0.00, qty = PO qty x part qty. 7Rules and owner answers

  1. A quotation line names EITHER a product OR a set, never both. A set line stores the set and a frozen copy of its parts at save (not shown on the screen; it is what the SO draft splits), like every other snapshot on the line (models/projects.py:1394).
  2. Picking a set fills the line's Complete set text with the part codes ("CWCX1009-RL + CWCY1009 + CWC1009-SC"); the parts are not listed anywhere else on the line.
  3. Picker: active sets of the company are offered with products; picking one fills set code, set name, brand of the pedestal, UOM SET, set list price, and the series price for the SET when the series names one.
  4. Standard: a set line is standard when the quotation's series has a row for that set (a family code on the sheet writes a row per set in the family). No series on the scope = standard, as for products today.
  5. Floor: the set's series row (selling price x (1 - max discount)) when both numbers are set; else the company default rule only, against the set list price. No product or category rule. Below floor flags the line and blocks Issue until approved, exactly as a product line.
  6. Parts are never priced on the quotation. The set's own price is the line rate.
  7. PDF / Excel / sign page: one row; code = set code, description = set name, COMPLETE SET = the line's Complete set text.
  8. SO draft: a PO line matching a set line drafts the parts, set rate on the pedestal, others 0.00.
  9. Old quotations quoted as component lines keep working unchanged.

Owner answers (14 Oct)

  1. Q1 Where the set's series price lives: (a) new "series sets" table, Sets card on the series page, filled by the sheet import.
  2. Q2 SO: (a) the SO draft splits the set into parts, set rate on the pedestal, others 0.00.
  3. Q3 PDF: (a) set code + set name, parts in COMPLETE SET.
  4. Q4 Floor when the series names no floor for the set: (b) company default only, against the set list price ("keep the logic simple").
  5. Q5 Set edited after quoting: (a) the line keeps the parts it was quoted with; re-picking the set takes the new parts.
  6. Line: no "not priced" part rows; parts only in the Complete set text box.
