A. One view: PowerPoint-style thumbnails on the left, every page editable where it sits NEW

No "Edit page" button and no separate screen. Click anything on any page in the scroll (photo, drawing, text, AREA, COMMENT, a logo) and it is selected right there, with the designer's own handles; drag to move, corners to resize, double-click text to type. The right panel is the designer's Inspector for whatever is selected (empty when nothing is). The thumbnail rail shows the real pages, small, like slides: click to jump, drag to reorder. Changes save by themselves (no Save button); the template and the other spec sheets are not touched.

A left-out page stays in the scroll greyed, with "Put back"; it is not editable until put back. Reset page (on an edited page) uses the 5-second deferred countdown. Text fields (AREA, COMMENT, marker) type in place exactly as today; product fields bound to the quotation (code, name, spec lines) stay data, not typed text, so a later revision still fills them.

D. How it stays fast with 40 editable pages

Every page looks editable, but only the pages near the screen are live: a page that scrolls into view swaps its picture for the designer canvas (one canvas per visible page, at most about 3), and a page that leaves the view goes back to a still picture. Pictures stay as now: thumbnails in the rail and on pages scrolled past, the 1024 px copy on the page being worked on, originals never. Each edit saves only that page (about 1 second after the last change, one request), and nothing refetches on focus. The rail thumbnails are small still pictures drawn from the same preview chunks the stack already loads, so the rail adds no requests.

F. Questions

Q1. Saving

(a) Each change saves by itself a second later, with Undo / Redo and a "Saved" mark. (b) A Save button for the whole sheet.
Recommend (a): like PowerPoint; nothing to forget across 40 pages.

Q2. "Edit all the pages at one glance"

(a) Edit any page where it sits; each change is for that page. (b) Also offer "Apply to every page of this sheet" for a selected layer (move the logo once for all 40 pages).
Recommend (b): (a) plus the one choice in the right panel, default "This page".

Q3. Phone

(a) On a phone the pages are view-only (the rail becomes a strip). (b) Editable on a phone too.
Recommend (a): handles and the inspector need a desktop width, as in Tag Templates today.
