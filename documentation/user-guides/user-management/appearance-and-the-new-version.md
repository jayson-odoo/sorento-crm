# Appearance and the new version of the app

Use this to set the company's brand colour for the new version of the app, and to switch between the new version and the previous one. The new version is a preview: only people who have been given the **Preview UI v2** permission can open it.

## Set the company brand colour

Only people who can edit settings see this tab.

### Steps

1. Open **User Management**, then **Settings**, then the **Appearance** tab.
2. Pick one of the five colours: **Sorento Blue** (the default), **Sorento Red**, **Teal**, **Graphite** or **Indigo**. Or type your own colour as `#rrggbb`, for example `#1a5fb4`.
3. Check the readout **Button text N:1, passes/fails**. It tells you whether the writing on a button in that colour is easy enough to read. If it says fails, pick another colour.
4. Look at the **Light** and **Dark** previews to see how the colour will look in each mode.
5. Click **Save**.

**Reset to Sorento Blue** puts the default colour back on the screen only. Nothing changes for anyone until you click **Save**.

### What it changes

* The colour applies **only to the new version**. Saving it does not change any colour in the previous version.
* An administrator can turn the preview off for everyone. While it is off, nobody sees the new version, whatever their permission.

## Switch between the new and previous version

Open the avatar menu at the top right.

1. If you have the **Preview UI v2** permission, click **Switch to the new version**.
2. In the new version the same menu item reads **Switch to the previous version**. Click it to go back.

Switching keeps you on the same page.

### Light, Dark or System

In the new version the light/dark control in the avatar menu has three choices: **Light**, **Dark** and **System** (follows your device). Your choice is remembered on your account, so it is the same on any device you sign in from.

### Pages not yet redesigned

Some pages have not been redesigned yet. In the new version they still work as before and show a small **Previous-version screen** marker.

### If a screen hits a problem

If a page of the new version has a problem, it says **This screen hit a problem.** Click **Open in the previous version** to carry on with your work on the same page.
