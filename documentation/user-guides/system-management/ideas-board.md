# Ideas board: feature requests and issues

Use the **Ideas** page to see every feature request and issue that staff and dealers have sent in, on the CRM or over WhatsApp.

## Steps

1. Open **Ideas** from the sidebar. Salespeople can now open it too.
2. Read the **Type** column. Each row is either **Feature request** or **Issue**. Click the **Type** header to sort.
3. To see only one kind, use the type filter (it reads **Any type** until you pick) and tick **Issue** or **Feature request**. Tick both to see everything. It combines with the search box and the other filters.
4. Click a row to open the idea page. **Type** is shown with the other details at the top.

An older idea with no type recorded reads **Feature request**.

## What's captured

* A **Feature request** is something new you would like the CRM or the assistant to do.
* An **Issue** is something wrong with the CRM or the AI assistant (for example, a screen that does not work or a wrong answer).
* A complaint about a product or an order is not an issue here. It goes through the complaint form.

## How you'll be notified

Dealers who file over WhatsApp get WhatsApp updates when the status of their item changes. See [The agent on WhatsApp](./chatbot-agent-on-whatsapp.md).
