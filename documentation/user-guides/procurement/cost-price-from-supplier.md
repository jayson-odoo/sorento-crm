# Procurement - Cost price uploads from a supplier

Upload a supplier's price list, review what changed against current prices, and apply the
lines you accept.

## Where

[**Procurement → Cost Price Uploads**](/procurement-management/cost-price-uploads).

## Notes moved from the screens

The screens themselves stay free of explanations (labels and field names only). The sentences
below used to sit inside the UI and were moved here instead.

* **Upload dialog, Valid from / Valid to dates:** leave both dates empty for a price that
  always applies.
* **A cost row's Valid from / Valid to dates** (on the supplier's Prices tab or a product's
  Suppliers tab): both empty means the price always applies; setting only the start date
  means it applies from that day on.
* **A set Submitted for verification:** a second Sorento person decides each line before
  anything changes.
