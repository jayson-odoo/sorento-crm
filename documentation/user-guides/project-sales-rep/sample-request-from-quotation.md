# Project Sales Rep - Start a sample request from the project's quotation

Use this when a customer wants samples for a project you already quoted. A new sample request
fills its item list from the project's quotation, so you do not type the products again.

## Steps

1. Start a new sample request for the project. Either:
   * in the CRM: open the project, **Samples Request** tab (or **Project Sales > Sample
     Requests**), and create a new one; or
   * from the sidebar: **MY REQUESTS > Sample Request**.
2. Pick the **Registered project**. The **Line items** list fills with every product line from the project's
   latest **issued** quotation revision (or the current draft, if it was never issued). Prices
   are not copied.
3. If the project has two or more quotations, a **Quotation** picker appears. Each option reads
   like `PRJQ-2026-0003 (R2)`, or `PRJQ-2026-0004 (not issued)`. Pick the one the samples are
   for; the items refill.
4. Remove the rows the customer does not need samples of, and change quantities. Once you edit
   the rows, your list stays as you left it and no longer refills.
5. Submit. The saved request shows the **Quotation** it came from.

## Lines that were not copied

A note under the items tells you what was skipped, for example *2 quotation lines were not added:
1 have no product, 1 products are inactive.*

## Rules

* Every item must be a product on that project's quotation. Otherwise: *Every item must be a
  product on the project's quotation.*
* A quotation from another project is refused: *That quotation is not one of this project's.*
* From **MY REQUESTS** or the portal you only see your own quoted projects.
* You need the right to create sample requests.
