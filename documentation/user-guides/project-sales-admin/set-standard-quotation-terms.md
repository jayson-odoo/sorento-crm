# Set the standard terms and conditions for quotations

Use this when every new quotation should start with the same terms and conditions.

## Steps

1. Open **Project Sales**, then **Configuration**, then **Quotation Templates**. You need the project setup permission to see the page; editing needs the edit permission.
2. Select **Add template**, type a **Name**, and write the clauses in **Terms and conditions**. Use the bold button for emphasis and the numbered list button for the clauses.
3. Select **Add template**. The first template you add becomes the active one.
4. To change which template new quotations use, find the inactive one in the list and select **Activate**. The previous one becomes **Inactive**.
5. To change wording, select the row, edit, and select **Save changes**.

## What's captured

* Each template keeps its name, its wording and whether it is **Active**. One template is active at a time.
* A new quotation copies the active template's wording when it is created.

## Good to know

* Quotations that already exist keep the wording they were created with. Editing or activating a template never changes them. Edit the terms on the quotation itself if that one needs a change.
* In the PDF, clauses print as a numbered list. Do not type the numbers yourself, the list adds them. Bold text prints bold.
