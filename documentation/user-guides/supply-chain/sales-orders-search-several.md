# Searching for several orders at once

Use this on the **[Project Sales Admin → Sales Orders](/scm/sales-orders)** list when you have several orders (up to 200) to find in one go, instead of searching them one at a time.

## Steps

1. Type a value in the search box and press **Enter** (or type a comma). It turns into a chip inside the box, for example `SO100001`.
2. Keep typing and pressing **Enter** to add more chips, for example `SO100002` or `Example Trading`.
3. The list shows every order that matches **any** of the chips. Each chip looks in the same places the search box always looked: the SO number, customer, project, customer PO number, product code or name, and sales agent.
4. To add many at once, paste a list. Put one value per line, or separate them with commas. Numbers separated by spaces are split into separate chips too, while a customer name with spaces (such as `Example Trading`) stays as one chip. You can have up to 200 values.
5. To remove a chip, click the x on it. Pressing **Backspace** in the empty box removes the last chip. The x at the end of the box clears everything.

If you type without pressing **Enter**, the list still searches live as you type, the same as before.

## Good to know

* When the chips do not all fit, the box shows **+N** for the ones hidden. Click the box to see all of them.
* The chips stay when you open an order and come back, when you use the record's previous and next arrows, and when you refresh the page. They are kept in the page address, so a copied link keeps them too.
* Export and the ticked rows follow what the list shows, so exporting after a multi-chip search gives you just those orders.
