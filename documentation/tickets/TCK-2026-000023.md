# TCK-2026-000023 — Orders: `delivery_time` → `pickup_time` rename + MCP response trim

> **Source ticket:** `TCK-2026-000023` (status: draft)
> **Priority:** high · **Category:** feature
> **Dependencies:** none, but DB-migration-heavy. Coordinate FE + BE + MCP deploy.

## Goal

Two changes:

(a) Rename column `orders.delivery_time` → `orders.pickup_time` everywhere — DB, BE models/schemas/services, FE types/forms/list/detail, MCP, alembic migration. No remaining `delivery_time` references after the change.

(b) MCP order-tools response trim: drop `estimated_delivery_date`; flatten `order_status` to the human-readable description (`"New"`, not `{status_code:"NEW"}`).

## Files to change

### DB

- New alembic migration: `ALTER TABLE orders RENAME COLUMN delivery_time TO pickup_time;` Idempotent guard (`IF EXISTS`). Downgrade does the reverse.
- Update `sorento_crm_backend/alembic/versions/017_add_order_tracking_columns.py:34, 91` only if you choose to also revise the historical create (recommended: leave history intact, the new migration is the source of truth).

### Backend

- `app/models/order.py:145` — `delivery_time` → `pickup_time`.
- `app/schemas/order.py:89` (OrderBase), `:128` (OrderUpdate).
- `app/services/order_service.py:802` (Excel import column map "Time" → `pickup_time`), `:1038–1043` (parsing).
- `app/services/entity_resolver.py:534` (drop `estimated_delivery_date` from select), `:536` (column rename), `:558` (`order_status` emit `status_name or status_code` as plain string), `:560` (drop `estimated_delivery_date` from display dict), `:562` (rename), `:922`, `:939`, `:940`.

### Frontend

- `app/(protected)/order-management/orders/types/order.types.ts:20, :91`.

- `app/(protected)/order-management/orders/components/OrderDetail.tsx:337`.

### MCP

- `sorento_crm_mcp/sorento_crm_mcp/server.py` — extend `_slim_orders_list_response()` to:
  - drop `estimated_delivery_date`
  - rename inbound `delivery_time` → `pickup_time` (in case any old caller still sends it)
  - flatten `order_status: {status_code:"NEW",status_name:"New"}` → `order_status: "New"` (prefer `status_name` else `status_code`).
- `sorento_crm_mcp/sorento_crm_mcp/catalog.py:580` — update tool description so the AI agent refers to `pickup_time` and not `delivery_time`.

## Rollback

- Run downgrade of the new migration; revert FE + BE + MCP commits. Coordinate with on-call before doing so since FE / BE schemas must match.
