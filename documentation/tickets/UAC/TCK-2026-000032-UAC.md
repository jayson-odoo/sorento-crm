# UAC - TCK-2026-000032 - Management KPI dashboard

Spec: [../TCK-2026-000032.md](../TCK-2026-000032.md). See [protocol](./README.md).

## Functional

- [ ] **AC-32-F1 [F] - Summary aggregates reconcile.**
  `GET /api/v1/sla/kpi/summary?scope=&from=&to=` returns counts (opened/responded/resolved/escalated), avg+median response/resolution, `% response met`, `% resolution met`, breach counts; numbers reconcile with raw `conversation_sla_event_logs` for a seeded window.
  **Validate:** `pytest tests/test_sla_kpi.py::test_summary_reconciles_with_raw`

- [ ] **AC-32-F2 [F] - Per-task drill-down.**
  `GET /api/v1/sla/kpi/tasks` returns one row per SLA entity with response time, resolution time, tier reached, escalation count split manual vs auto (via `trigger`), owner, and both met/breach verdicts; paginated.
  **Validate:** `pytest tests/test_sla_kpi.py::test_tasks_rows_shape_and_split`

- [ ] **AC-32-F3 [F] - Names, no UUIDs.**
  Leaderboard + per-task rows resolve `assigned_to_id`/owner to user names; no UUID in any response field shown to the UI.
  **Validate:** `pytest tests/test_sla_kpi.py::test_names_resolved` + Playwright snapshot has no UUID pattern.

- [ ] **AC-32-F4 [F] - Scope partition.**
  `scope=conversation` excludes `source_entity_type ∈ FORM_SLA_TYPES`; `scope=form` includes only them; `scope=all` is the union. No cross-contamination.
  **Validate:** `pytest tests/test_sla_kpi.py::test_scope_partition`

- [ ] **AC-32-F5 [F] - Met/breach definitions.**
  Response met ⇔ `responded_at <= due_at` (never-responded past `due_at` = breach); resolution met ⇔ `resolved_at <= due_at_resolution`. Verdicts independent.
  **Validate:** `pytest tests/test_sla_kpi.py::test_met_breach_split_clocks` (cases: met/met, met/breach, breach/ - ).

## Business

- [ ] **AC-32-B1 [B] - Management sees team-wide performance.**
  A management user sees aggregates + per-task rows across all assignees for the selected scope/window, matching seeded ground truth.
  **Validate:** `pytest tests/test_sla_kpi.py::test_team_wide_view` + Playwright MCP management walkthrough.

## Data

- [ ] **AC-32-D1 [D] - KPIs are stored, not computed-only (audit).**
  `response_time` / `resolution_time` / `duration` are written on the relevant events; tracking carries `responded_at` / `resolved_at` / `due_at` / `due_at_resolution`. Any gap found is fixed in this ticket.
  **Validate:** `pytest tests/test_sla_kpi.py::test_kpi_fields_persisted` (drive a response+resolution lifecycle, assert stored columns non-null).

## RBAC

- [ ] **AC-32-R1 [R] - Management-only.**
  `sla.kpi.view` gates all KPI endpoints + the sidebar entry; a regular user gets 403 and does not see the menu item.
  **Validate:** `pytest tests/test_sla_kpi.py::test_rbac_denied` + Playwright MCP as non-management user (entry absent).

## UX

- [ ] **AC-32-UX1 [UX] - All sections render via sidebar, empty states present.**
  Reachable by clicking through the sidebar; cards + trend + leaderboard + per-task DataGrid all render, each with an empty state; DataGrid uses fixed layout + resizable columns + `buildDataGridParams`.
  **Validate:** Playwright MCP - sidebar → SLA Management → KPI Dashboard → snapshot all sections + empty-state path; `browser_network_requests` shows `/api/v1/sla/kpi/*`; no console errors. Vitest for card/grid loading/empty/error/data states.

## Scalability

- [ ] **AC-32-S1 [S] - Set-based + paginated (XS2).**
  Aggregates are single set-based queries (no per-row N+1); `/kpi/tasks` is paginated. With ≥500 trackers + logs seeded, summary responds within budget and issues bounded queries.
  **Validate:** `pytest tests/test_sla_kpi.py::test_summary_query_count_bounded` + latency assertion.
