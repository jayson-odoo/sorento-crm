# TCK-2026-000027 — Orders MCP: search by `actual_delivery_date`, not `order_date`

> **Source ticket:** `TCK-2026-000027` (status: draft)
> **Priority:** medium · **Category:** bug
> **Dependencies:** none.

## Goal

Validate the current behaviour, then ensure the AI agent uses `actual_delivery_date_from`/`_to` when the user phrases the query in terms of DELIVERY (e.g. "orders delivered last week"), not `order_date_from`/`_to`.

The BE already exposes both date ranges (`catalog.py:580` documents `actual_delivery_date_from`/`_to`). The fix is primarily **tool description / prompt engineering** so the agent picks the right param.

## Files to change

| File | Change |
|------|--------|
| `sorento_crm_mcp/sorento_crm_mcp/catalog.py` (line 580, `crm_order_management_orders_list`) | Tighten tool description with explicit phrasing → param rules. Examples: "delivered last week / today / yesterday" → `actual_delivery_date_*`. "ordered last week / placed today" → `order_date_*`. Include 5+ examples. |
| `sorento_crm_mcp/sorento_crm_mcp/server.py` | Soft validator: if BOTH `order_date_from` and a `delivery_intent_hint` query param look conflicting, surface a warning in the response metadata (`agent_hint`). Non-blocking. |
| `sorento_crm_backend/app/api/v1/order_management/orders.py` | No behaviour change — keep both param families strict and passthrough. |

## Step-by-step

1. Rewrite the tool description with a decision table:
   ```
   User phrasing                       Param to use
   "delivered last week"               actual_delivery_date_from
   "delivered today"                   actual_delivery_date_from (==today)
   "delivered yesterday"               actual_delivery_date_from (==yesterday)
   "ordered last week"                 order_date_from
   "placed today / created today"      order_date_from
   "for delivery this week"            actual_delivery_date_from (range)
   ```
2. Update the existing E2E phrasing test set (if any) under `sorento_crm_backend/tests/` to cover these examples.
3. No DB / schema change.

## Acceptance

- AI assistant phrase "orders delivered last week" → resulting MCP call uses `actual_delivery_date_from`, NOT `order_date_from`.
- Phrase "orders placed last week" → uses `order_date_from`.
- 5 phrasings tested; agent picks correctly each time.
