## Implementation detail

```python
# excel_macro_stripper.py
from io import BytesIO
from openpyxl import load_workbook

def strip_macros_to_xlsx(file_bytes: bytes, filename: str) -> tuple[bytes, str]:
    wb = load_workbook(BytesIO(file_bytes), data_only=True, keep_vba=False)
    out = BytesIO()
    wb.save(out)
    new_name = filename[:-5] + ".xlsx" if filename.lower().endswith(".xlsm") else filename
    return out.getvalue(), new_name
```

`openpyxl>=3.1.2` already pinned (`requirements.txt:17`). `keep_vba=False` (default) drops macros on read.

Wrap every `load_workbook(BytesIO(file_data))` call site so the rest of the import pipeline never sees `.xlsm`.
