# TCK-2026-000015 — MCP attachment / catalogue chunking

> **Source ticket:** `TCK-2026-000015` (status: draft)
> **Priority:** medium · **Category:** feature
> **Dependencies:** none. Self-contained; can be picked up by a single agent.

## Goal

Route "catalogue" intents (catalog / catalogue / brochure / price list) to the existing `crm_master_product_attachments_*` (and `crm_marketing_promotion_attachments_*`) tools, and TRIM the response so the AI agent sees only fields the user cares about. No internal IDs, no storage internals.

Suppress in MCP layer: `full_directory_path`, `directory_id`, `storage_provider`, `uploaded_by` (id), `uploaded_by_user_id`.
Keep: `file_name`, public URL (presigned or CDN), `uploaded_by_user_display_name`, `description`, `created_at`.

## Files to change

| File | Change |
|------|--------|
| `sorento_crm_mcp/sorento_crm_mcp/server.py` | Add `_strip_attachment_internals(payload)` shaper analogous to existing `_strip_stock_hidden_fields()` (around line 566). Wire into `_sanitize_tool_response()` for attachment-returning tools. |
| `sorento_crm_mcp/sorento_crm_mcp/catalog.py` | Update `description` for `crm_master_product_attachments_list` (line 168), `crm_master_product_attachments_by_product` (line 187), `crm_marketing_promotion_attachments_list` (line 317), `crm_marketing_promotion_attachments_by_promotion` (line 337). Embed intent keywords ("catalog", "catalogue", "brochure", "price list", "spec sheet"). |
| `sorento_crm_backend/app/services/embedding_worker.py` | Extend `attachment` chunk text builder (around line 119–136) to include intent keywords + the linked entity-type label, so RAG `/api/v1/external/rag/tool-search` routes the user phrase to the right tool. |
