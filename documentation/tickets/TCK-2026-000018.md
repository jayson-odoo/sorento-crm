# TCK-2026-000018 - n8n SLA routing: technical drawing → marketing_product team

> **Source ticket:** `TCK-2026-000018` (status: draft)
> **Priority:** low · **Category:** other
> **Dependencies:** none. Change lives in n8n, not this repo.

## Goal

When the AI agent classifies an incoming SLA-bearing request as "technical drawing", route it to the `marketing_product` team instead of the default tier-1 IT support team.

## Scope

No CRM code change. Spec exists for traceability so the n8n change is tracked in our ticketing system.

## n8n change checklist

1. Locate the SLA classifier node in the `AI Agent - SLA Routing` workflow.
2. Add / update the classification rule mapping `category ∈ {"technical drawing","drawing","blueprint","cad"}` → `team_code = marketing_product`.
3. Confirm the downstream `Assign Team` node looks up by `team_code` (no hard-coded UUIDs).
4. Verify the AccessAgent `marketing_product` team exists in CRM: `GET /api/v1/external/access-agents/by-code/marketing_product`.

## Acceptance

- Trigger a test message classified as "technical drawing" → n8n workflow execution log shows team assignment to `marketing_product`.
- The downstream CRM ticket / form created via the n8n route carries assignee from the `marketing_product` team round-robin.

## Manual verification

1. In n8n execution history, replay a sample "technical drawing" intake.
2. Check the created entity in CRM has `assigned_to` from the `marketing_product` team.

## Rollback

- Revert the n8n classifier node to its prior version. No CRM data is affected.

## Close-out

Once verified, mark this CRM ticket `resolved` with a one-line note pointing to the n8n PR / workflow version.
